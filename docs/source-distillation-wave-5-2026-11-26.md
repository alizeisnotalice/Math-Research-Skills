# Google、OpenAI 与补充文献蒸馏

## Google Cogentic

用本机 Python 3.13.18 复算六份下载件的 SHA-256 与 274 个 PDF 物理页，并与 Google Research 固定提交的六份 PDF 对照。五份逐字节一致。双矩阵稿更新版仍为 41 页，所用物理页 8–10 的文本只有两处引文序号变动。为六篇原稿分别补充代数平方见证、Frobenius 不可约性、严格对偶分离、完全幂因子预检查、零单色矩形和等边卡组 Möbius 奇偶性。原文定位与实跑结果见 [Cogentic 来源索引](../skills/math-research/references/google-cogentic-2026-11-25.md)。

## OpenAI 与补充文献

- OpenAI 的 40 份剩余候选逐份整理。29 份接入限定参考，11 份保留原件位置与待补输入。763 份原件中，353 份有已登记构件、323 份有限定参考、3 份为候选、8 份待细化。另有 19 份版本记录、25 份邻近材料、32 份历史版本。[逐篇索引](../skills/math-research/references/openai-sources/README.md)。
- 补充文献共筛选 197 份本机原件，全部重算 SHA-256 及页数。44 份有可采用的证明接口。正式发表文献核对版本和引用，预印本沿实际采用的步骤记录依赖。增量写入 [无理性与超越性分册](../skills/math-research/references/supplemental-sources/collection-07.md) 和 [常数与丢番图分册](../skills/math-research/references/supplemental-sources/collection-08.md) 等分册。
- 19 个新增 Python 工具的验收覆盖分母、严格不等式边界、有限域大小、支撑条件和固定整数见证。各项技能列出数学结论的适用范围。
