# Scoped reference. Class VII intersection reduction

Source: OpenAI, *Global Spherical Shells on Minimal Surfaces of Class VII*, pinned [PDF](https://raw.githubusercontent.com/openai/math/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Global-Spherical-Shells-on-Minimal-Surfaces-of-Class-VII-September-24-2026/paper.pdf), SHA-256 `d441e45f773bce9fc3728c7de5f2cfb21fcb92849c9e8403561a787c335f4aae`, physical pp. 1, 4--5, 23, 28, 34.

For a connected minimal compact class-VII surface with `b1=1`, `b2=b>0`, and `kappa=-infinity`, the source records an integral basis `u_1,...,u_b` modulo torsion with

`u_i.u_j=-delta_ij`, `K_X=sum_i u_i (mod torsion)`.

For every curve `B`, it further uses `B^2<0`, `(K_X+B).B<=0`, and `K_X.B>=0`; in particular effective divisors have nonnegative canonical degree.  This may be used as a signed intersection-ledger check only after the surface class, minimality, curve data, and torsion convention are supplied.  It does not construct a global spherical shell.
