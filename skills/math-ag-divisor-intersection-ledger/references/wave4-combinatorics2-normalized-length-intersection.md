# Normalized-length parameter intersection interface

Source: *Positivity of Serre's Intersection Multiplicity*, SHA-256
`7985cfbc11547cf659efdd6abc076a0c0371e9a38e8026aa09b23cbb042af917`,
Theorem 2.5 (physical pp.7--8), Lemma 3.5 (p.15), and Lemma 5.1 (p.23).

For the stated complete generically separable base \(A\subset D\), Theorem 2.5
provides a \(D\)-algebra \(C_D\) with nonnegative normalized length satisfying
\(\lambda_DH_i(z_1^v,\ldots,z_h^v;C_D)=0\) for \(i>0\), and
\(\lambda_D(C_D/(z_1^v,\ldots,z_h^v)C_D)=v^he((z),D)\) for each parameter
system.  It applies only in the stated tower-length category.

Lemma 3.5 compares ordinary and normalized Euler evaluations after a finite
group action that is transitive on geometric fibres.  Lemma 5.1 reduces the
positivity problem to complete regular \(R\), complementary-dimensional prime
quotients \(D,E\), and \(P+Q\) primary to the maximal ideal, using the named
vanishing theorem.  This is a conditional ledger for those inputs, not a
general Tor-positivity decision procedure.
