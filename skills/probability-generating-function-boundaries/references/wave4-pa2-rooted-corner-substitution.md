# Rooted planar-map corner substitution

Source: OpenAI, *Brownian continuum random tree limits of finite Fortuin--Kasteleyn maps above four*, SHA-256 `0d730ea9a40f1505b3f3bb2fdd401859cae09c2a69b1bea5d4b6d9aa86d5c0af`, p. 15, Lemma 4.1 and (4.2).

If rooted blocks of size `m` have `2m` individually rooted corners, each rooted map decomposes uniquely as a root block with one rooted insert per corner, and the weight is multiplicative under one-vertex joining, then `T(z)=Phi(z T(z)^2)`, where `T=sum a_n z^n` and `Phi=1+sum b_m y^m`. The identity supplies neither positivity, endpoint bounds, finite variance, enumeration, nor a CRT limit.
