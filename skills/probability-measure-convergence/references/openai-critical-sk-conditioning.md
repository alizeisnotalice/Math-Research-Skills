# Critical-SK conditional-law references

For a square-summable Gaussian-coordinate variance profile with divergent trace and the draft's spectral representation, use the stated finite-deletion conditional densities for the centered square-series constraint. A caller must provide the finite nonzero tail density and its variance-tail/Fourier-integrability witnesses; the output is a compatible finite-coordinate law, not a universal conditional-law constructor.

Scoped reference. For the quench paper, use its stationary-conditioned measure and recovery package only when those inputs are explicitly supplied. Its finite-coordinate/cap statements do not on their own establish entrance, universality, or functional convergence.
