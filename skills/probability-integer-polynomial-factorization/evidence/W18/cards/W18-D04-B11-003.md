## Sparse cyclotomic-divisor criteria

- **Theorem 2 and Corollary 1 (physical pp. 2–4; printed pp. 1–3).** Let `f∈Z[x]` have `N` nonzero terms and suppose `Φ_n|f`. For distinct primes `p_1,…,p_k` with `2+Σ_j(p_j−2)>N`, and `p_j^{e_j}||n`, at least one `j` has `Φ_{n/p_j^{e_j}}|f`. Therefore, if `f` has any cyclotomic divisor, it has one `Φ_m` such that `2+Σ_{p|m}(p−2)≤N`; in particular every prime divisor of this `m` is at most `N` (physical p. 4).
- **Proof mechanism (physical p. 3).** Partition the sparse terms maximally into blocks whose evaluations at `ζ_n` are minimal vanishing sums. Conway–Jones’ cited theorem says a rational-coefficient minimal vanishing sum with reduced exponent `r` needs at least `γ(r)=2+Σ_{p|r}(p−2)` terms. If every selected full prime-power part occurred in some block’s reduced exponent, summing these block lower bounds would contradict the assumed `2+Σ(p_j−2)>N`. Thus for some prime all blocks have `p_j^{e_j}|d_i` in the exponent gcds; replacing `ζ_n` by the corresponding root of order `n/p_j^{e_j}` shows each block still vanishes, hence so does `f`. The minimal-vanishing-sum result is imported from Conway–Jones [1], not proved in this note.

## Divisibility test and its exact scope

- **Theorem 3 / Algorithm A (physical pp. 4–8; printed pp. 3–7).** Input is `f(x)=Σ_{i=1}^N a_i x^{d_i}∈Z[x]`, degree `n>1`, and a specified factorization `m=∏_{j=1}^s p_j^{e_j}` with distinct `p_j≤M`, `1≤e_j≤E`. If `φ(m)>n`, return “no.” Otherwise work in the quotient ring `Z[x]/(x^m−1)`: define `ω(g)=g mod (x^m−1)`, i.e. reduce exponents modulo `m` and combine coefficients; set `f_0=ω(f)` and recursively
  `f_j=ω(f_{j−1}(x)(x^{m/p_j}−1))`, `j=1,…,s`.
  Then `Φ_m|f` iff `f_s=0`. **Proof:** for `h(x)=∏_{j=1}^s(x^{m/p_j}−1)`, every proper-divisor cyclotomic factor of `x^m−1` divides `h`, while `Φ_m` does not divide `h`; hence `Φ_m|f` iff `x^m−1|fh`. The computed `f_s` is exactly the residue of `fh` modulo `x^m−1`. The full correctness argument is p. 6. It tests one proposed `m`; it does not find `m` on its own.
- **Theorem 1 / Algorithm B (physical pp. 2, 8–10; printed pp. 1, 7–9).** Combining Corollary 1 with exponent bounds `e≤⌊log(deg f)/log p⌋+1` yields a finite search over all possible cyclotomic orders followed by Algorithm A. For fixed term count `N` and bounded coefficients, the runtime is polynomial in `log n`; more generally the stated asymptotic bound, as `N→∞`, is
  `≪ exp(((2+o(1))√(N/log N))(log N+log log n)) log(H+1)`, `H=max_i|a_i|`.
  The exponential-in-term-count search and its input model are essential parts of the claim; this is a sparse-input algorithm over **integer** coefficients, not a polynomial-time algorithm in general dense degree.
- **Coefficient growth in Algorithm A (pp. 5–8).** Reducing exponents modulo `m` combines collisions exactly. After the `j`th multiplication the number of terms is at most `2^jN`, and coefficient magnitudes are bounded by `2^jNH`; the proof accounts for sorting/combining coefficient–exponent pairs. These are algorithmic bounds, not a mathematical replacement for exact equality in `Z[x]`.

## A175 interface and quotient-ring boundary

A175’s target mask `C` is a finite 0–1 polynomial in `Z[x]`, so Algorithm B can test whether `C` itself has any cyclotomic divisor when supplied sparsely, and Algorithm A can test any proposed order. A positive result only establishes `Φ_m|C`; it does not yield a positive convolution factorization. A negative result rules out cyclotomic divisors of `C`, not non-cyclotomic positive-real factors. Candidate probability factors in A175 need not lie in `Z[x]`, so these integer algorithms cannot be applied to them without a separate integrality proof. Also, the quotient ring folds exponents modulo `m`: `x^m≡1 mod (x^m−1)` although `x^m≠1` in `Z[x]`. Thus cyclic residue equality is only the certificate internal to this divisibility algorithm; it must not be mistaken for ordinary polynomial equality or for the no-wrap convolution identity in A175.
