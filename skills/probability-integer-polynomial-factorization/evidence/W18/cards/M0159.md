## Setting and results

A finite prototile family `P` consists of finite subsets of `Z`, normalized to have minimum 0. A tiling is encoded by the bi-infinite color sequence marking which prototile covers each position. The resulting shift-invariant system is `T(P)`.

Theorem in §2 (physical pp. 2–3): every **subscripted** tiling system is a shift of finite type (SFT), hence every ordinary tiling system is sofic, since forgetting subscripts is a factor map. In the subscripted alphabet, a symbol remembers both the prototile and the position within it. If `L` is the maximum tile length, a sequence belongs to the subscripted tiling system whenever every length-`L` word appearing in it occurs in a valid tiling: the local block around each symbol forces all other positions of its tile. The proof explains why `L−1` need not suffice, with `{0},{0,1}` as counterexample.

Main Theorem (physical pp. 2–5): for any SFT `σ:Σ→Σ`, there is a positive integer `m` and a tiling system `σ:T→T` decomposed into `m` closed components `T₀,…,T_{m−1}`, cyclically permuted by the shift, such that `σ^m` restricted to each `T_i` is conjugate to `σ^m` on `Σ`. The corollary says the set of tiling-system topological entropies is the set of **logarithms of roots of Perron numbers** (the SFT entropy set); retain the source's “roots of Perron numbers” wording.

Proof mechanism and parameters: present `Σ` as an edge shift with a `V×V` nonnegative integer adjacency matrix `A`. Choose `n>V` with `(V max A_{ij})^{13n}<(n+1)!`, and set `m=13n`. Each entry of `A^m` has a unique factorial-base expansion `Σ_{k=1}^n c_k k!`, `0≤c_k≤k`. Construct colored “barbells” and “racks”: rack heads/tails enforce matching vertex labels, and the rack center has exactly `k!` fillings by barbell arrangements corresponding to permutations of `k` labels. For each `c_k`, include that many racks for the ordered vertex pair; the induced edge graph therefore has adjacency matrix `A^m`. Head positions occur only in one residue class mod `m`, producing the cyclic components and conjugacy. The entropy corollary is a direct consequence of the main theorem and the known SFT entropy characterization.

## A175 use and gap

This paper is structural context for tilings by finite **sets** and symbolic encodings. It proves no claim about convolution of independent integer-valued random variables, probability-generating polynomial factors, coefficient positivity, or uniform distributions. In particular, sofic/SFT structure is not an arithmetic factorization result and is not a route from a real nonnegative polynomial factor to a set tile without additional lemmas.
