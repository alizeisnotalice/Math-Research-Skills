# 文献检索与下载

把研究问题或文献清单转成核验过的题录和真实可打开的全文。默认中文说明，保留原题名、完整作者、来源、版本、下载失败原因与补取路径。

## 确定范围

- 接受主题、关键词、DOI、arXiv ID、URL、BibTeX、表格或粘贴题录。清单保留原编号，不用相似论文替换指定条目。
- “找论文并下载”执行全流程；“查文献”只检索核验；“下载这些”按清单获取，不扩张主题。
- 主题检索未指定数量时，以约 15 篇高相关论文为起点，不设硬性年份限制；兼顾直接相关研究、综述和奠基论文。用户约束优先，结果不足如实交付。
- 只有缺少主题或关键歧义影响方向时追问。默认在当前工作目录创建独立 `literature-<主题>-<时间>/`，不覆盖旧结果。

## 工具与渠道

已有网页搜索、浏览器、学术 MCP/CLI 足够时直接用，不强制安装服务器。检索排名只是候选排序，不是推荐结论。

- 主题、学科及中文来源选择：按需读 [检索渠道](references/providers.md)。中文结合知网、万方、机构库和期刊官网；已安装 `cnki-search` 时可复用流程，缺失时通过现有网页工具检索。
- 无专用工具时，按 [命令与记录格式](references/cli-and-records.md) 用自带工具：Crossref/arXiv 检索，DOI 题录解析，有用户提供的联系邮箱时用 Unpaywall 定位 OA 副本。
- 需要扩展工具链时读 [GitHub 项目调研](references/github-projects.md)。项目宣称的能力不能写成本次实际调用结果。本技能可独立运行，不依赖另外两个已有文献技能。

## 检索、核验与版本

1. 将问题拆成对象、问题和方法，生成必要的中英同义词与检索式。按来源语法调整；用精确题名、DOI、引用线索补查，记录实际查询与日期。
2. 按相关性筛选并解释理由。摘要的结果写成“作者报告”；只读片段不能补造数值或方法细节。普通检索不宣称穷尽领域。
3. 打开出版方、会议库、可信学科数据库或机构题录，核对题名、完整作者、年份、发表来源和所选版本。DOI 可跳转不等于身份正确。核心字段确认且无冲突才标 `verified`，不足标 `pending_verification` 并写缺项。脚本始终生成待核验候选，需要代理检查。
4. DOI 标准化后找重复；同 DOI 元数据冲突先查证。无 DOI 用题名、作者、年份和来源联合确认。正式版、会议版和预印本须有官方交叉链接或内容证据才建立关系；实质扩展版保留区别，不移植不同版本的年份和页码。
5. 分别记录 `metadata / abstract / fulltext` 阅读范围与实际位置。下载不等于阅读全文。发现撤稿/勘误时提示，没查过就不声称不存在。

## 全文获取与验收

1. 优先用户直链、出版方 OA、arXiv/PMC/学科库、机构仓储和作者公开副本；再用 OA 索引定位。保持 TLS 校验，按当前证据诊断网络，不沿用旧环境假设。
2. API 的 `link`、网页链接和 OA 状态都只是线索。检查来源和版本后，将确认为该文献公开副本的 URL 加入 `pdf_candidates`；有机构权限时可用用户已授权会话，题录 API 凭据不等于全文权限。
3. 同链接遇到 401/403、验证码或登录挑战，停止脚本重试，改用已授权浏览器或另一公开源。429 尊重 Retry-After；超过当前等待窗口就记录稍后重试；5xx/超时有限重试。OA 索引无结果只能记“未发现开放全文”，不据此断言付费墙。
4. 不用盗版渠道或绕过访问控制；Wayback 仅作为已知公开副本的可选存档来源，保留原链接与快照时间，不作为突破权限的默认回退。
5. 下载写临时文件，检查 HTTP 状态、PDF 文件头、解析可读性、非零页数与 SHA-256，再移入 PDF 目录。自带下载工具要求 PyMuPDF 或 pypdf；优先通过 `load_workspace_dependencies` 找已有 PDF 环境，缺失时明确说明，不能把文件头检查当完整验收。
6. 逐篇看首页题名、作者、DOI/arXiv ID，必要时对照正文。解析通过只证明结构可读；身份未确认保留 `identity_status: pending`，不计入“已核验全文”。扫描件视觉核对，页数与出版页码只作提示，作者稿长度可能不同。
7. 明示正式版、接受稿、预印本或未知版本。拿到预印本不报告为拿到期刊正式版；HTML、损坏文件和错论文不混入已取得目录，保留失败记录。

## 交付与停止

默认交付 `00_文献清单与下载说明.md`、`papers.json`、`references.bib`、`search-log.md`，下载模式增加 `pdf/`。需要搬运时用 Python zipfile 打包 UTF-8 文件名；仅聊天请求不强制生成文件。

- 清单逐条列编号、原题名、作者、年份、来源、DOI/链接、推荐理由、核验状态、阅读范围、版本和本地文件。未取得列真实原因及官方入口、图书馆、馆际互借或作者索取等补取路径。
- 分别统计题录已核验、文件结构通过、全文身份已核验和未取得，避免混成一个成功数；编号可追到文件和出处。
- BibTeX 只导出已核验条目及确认字段；候选单列，不填占位符，不用其他版本字段凑正式版引用。
- 日志写实际来源/查询、日期、筛选去重、失败及局限，未执行计划单列。输出不含密钥、Cookie 或联系邮箱等凭据。
- 目标数量与相关性/核验足够即停；主要相关来源和一次针对性调整仍不足，交付现有结果。逐篇尝试有限的真实全文候选，不不断猜 URL。
- 最终说明结果数、主要缺口和可点击文件链接。翻译、深度综述及长期监控只在另有要求时进行。
