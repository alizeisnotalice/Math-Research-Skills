# Spinless modular-bootstrap certification

Use this skill when a candidate functional has already been proved to lie in the source class \(\bar A\) and has a global feasibility certificate.  It transfers those facts to the gap bound; it is not a method for constructing or numerically sampling a feasible functional.

Read [the source contract](references/anthropic-spinless-bootstrap-certification.md) before using the conclusion.  In particular, retain the source's central-charge threshold, spectrum assumptions, Fourier anti-eigenfunction condition, Cardy-weighted absolute integrability, and strict vacuum sign.
