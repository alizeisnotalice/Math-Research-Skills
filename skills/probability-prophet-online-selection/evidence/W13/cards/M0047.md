# M0047 — A statistical version of prophet inequalities

**Source.** David Assaf, Larry Goldstein, and Ester Samuel-Cahn, “A statistical version of prophet inequalities,” *The Annals of Statistics* 26(3) (1998), 1190–1197, DOI 10.1214/aos/1024691094. Read the complete eight-physical-page journal PDF; printed pages 1190–1197 correspond to physical pages 1–8.

## Model and exact transfer theorem

For (i=1,\ldots,n), let ((X_i,Z_i)) be independent random pairs with arbitrary known joint distributions, (E|X_i|<\infty), and suppose only the sequence (Z_1,\ldots,Z_n) is observed sequentially. Define the observable conditional reward (W_i=E[X_i\mid Z_i]). Let (V_p(X,Z)) be the prophet value when it sees all observations and chooses a reward, and (V_s(X,Z)) the optimal no-recall statistician’s stopping value under the observed filtration. Superscript (0) denotes the ordinary prophet/stopping values for the independent sequence (W_i).

**Theorem 2.1 (printed p. 1194; physical p. 5).** If a ratio- or difference-prophet inequality for independent (W_i) places the pair ((V_p^0(W),V_s^0(W))) in a set (A\subset\mathbb R^2), then the same set constraint holds for ((V_p(X,Z),V_s(X,Z))). In fact, the proof establishes the value identities
\[
V_p(X,Z)=E\max_i W_i=V_p^0(W),\qquad V_s(X,Z)=V_s^0(W).
\]
For an infinite sequence, the paper states the analogous result when (E\sup_i|X_i|<\infty). This does not say (X_i=W_i), nor that the prophet sees the hidden (X_i); the objective remains expected (X)-payoff and the observed signal is (Z_i).

**Proof mechanism.** Given all (Z_i), a prophet maximizes conditional expected (X)-reward by taking an index maximizing (W_i); conditioning gives the first identity. For any stopping time τ based on the (Z)-filtration, the tower property gives (E[X_\tau]=E[W_\tau]), so the statistician’s problem is an optimal stopping problem with observable conditional rewards. Independence of the pairs makes future (W_i)’s independent of extra past signal information; dynamic programming/nonrandomized stopping then identifies the optimal value with the ordinary (W)-sequence stopping value. The transfer therefore preserves whatever numerical inequality for independent (W_i) is already known; it does not create a new constant.

**Corollary 2.1 (printed p. 1195; physical p. 6).** Assuming (V_s(X,Z)>0): (i) if each (W_i\ge0), (V_p/V_s\le2); (ii) if the (W_i\ge0) are i.i.d., the ratio is at most the Hill–Kertz (a_n); (iii) if (a\le W_i\le b), the difference (V_p-V_s\le(b-a)/4). The paper says all three bounds are sharp, and extends them to the stated infinite-sequence setting. Nonnegativity of (X_i) is sufficient for (i), not necessary; noisy signals (Z_i) can themselves be negative.

## Use and limits

This is a value-transfer theorem under independent pairs and integrability. It does not apply directly when pairs are dependent across time, when stopping may recall earlier unchosen rewards, or when (Z) contains information about future pairs beyond the independent-pair model. The sharp constants in the corollary are imported classical prophet bounds on (W_i), not newly proved here.
