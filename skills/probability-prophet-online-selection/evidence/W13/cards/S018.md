# S018 — Simple and Optimal Online Contention Resolution Schemes for k-Uniform Matroids

**Source.** Atanas Dinev and S. Matthew Weinberg, arXiv:2309.10078v2, 24 November 2023, 27 physical PDF pages. The full title/authors/version were checked on PDF p. 1 and against the official arXiv record. Full physical pages 1–27 were read; theorem/algorithm pages were rendered.

## Model and adversaries

For a down-closed feasible family ℱ on a finite ground set and (x\in P_\mathcal F), independently activate element (e_i) with probability (x_i). An OCRS irrevocably accepts/rejects each arriving active element and must keep the selected set feasible. It is (c)-selectable when (Pr(e\text{ selected}\mid e\text{ active})\ge c) for every element and every allowed instance. The adversary model is essential: fixed-order chooses the full order from the known (x)/distributions before seeing active outcomes; online is adaptive to revealed history; almighty knows the realized active set and the algorithm’s random bits in advance. The theorem below is for fixed-order unless explicitly marked almighty.

## Fixed-order construction and guarantee

For the k-uniform matroid \(P_k=\{x\in[0,1]^n:\sum_i x_i\le k\}\), define the deterministic scaled routine Algorithm(d,x): accept active \(e_i\) iff
\[
|B_{i-1}|+1\le\sum_{j\le i}x_j+d.
\]
**Proposition 4.2.** If \(x\in(1-d/k)P_k\), Algorithm(d,x) always selects at most k elements and is \(1-2/(d-1)\)-selectable. The original OCRS at unscaled input is obtained by the standard \((b,c)\)-to-\(bc\) reduction, with \(b=1-d/k\). Set \(d=\sqrt{k}\) (for meaningful positive bounds, \(d>1\)); the guarantee becomes
\[
(1-1/\sqrt{k})\,(1-2/(\sqrt{k}-1))=1-O(k^{-1/2})
\]
selectability against fixed order. Algorithm(d,x) itself is deterministic conditional on actives; the original unscaled OCRS uses the reduction’s random thinning. Do not say every eligible active item is accepted with a coin in the scaled routine.

**Proof chain for Proposition 4.2.** Let \(S_i=|B_i|-\sum_{j\le i}x_j\); its increments are \(1-x_i\) on an active accepted element and \(-x_i\) if inactive or rejected. Let \(W_i=\sum_{j\le i}X_j\), where \(X_j=1-x_j\) when active and \(-x_j\) otherwise, so \(E X_j=0\). Then \(W_i-S_i\) is the number of active-but-discarded elements so far. An element \(i\) is discarded while active exactly when \(\lceil W_i\rceil>d\) and it is a new record integer height. For fixed order, the increments are independent. For target step \(m\), the reversed process \(Q_r:=W_{m-r-1}-W_{m-1}\), \(r=0,\ldots,m-1\), starts at 0 and has centered independent increments, hence is a martingale. The record event forces element \(m\) active and \(\max_r Q_r<1\), \(Q_{m-1}\le-(d-1)\); the bounded-increment optional-stopping lemma gives probability at most \(2x_m/(d-1)\). Conditioning on \(m\) active yields rejection probability at most \(2/(d-1)\). Separately, the invariant \( |B_i|\le\sum_{j\le i}x_j+d \) and \(\sum_jx_j\le k-d\) prove the capacity bound. Activity-adaptive order would break the independence/martingale step.

## Almighty upper bound

**Theorem 5.1.** If a \(c\)-selectable OCRS for the k-uniform matroid against an almighty adversary exists, then \(c\le 1-\Omega(\sqrt{\log(k)/k})\). The proof needs only the instance \(n=2k,\ x_i=1/2\). It symmetrizes an arbitrary OCRS over a uniformly random permutation; for a restricted almighty adversary class that commits to order before this symmetrization but knows active elements and reveals all active elements first, the selection probability of the (i)-th revealed active element becomes a sequence (g(i)). Feasibility forces Σᵢg(i)≤k and (g(i)) is nonincreasing. A binomial-weighted LP upper-bounds the common selectability; an extremal-shape argument reduces an optimum to a plateau, one intermediate value, then zeros, and binomial anti-concentration yields the asymptotic deficit. The theorem states only an Ω-order upper bound, not a sharp numeric constant. The restriction is a subclass of almighty strategies, hence an upper bound for the full almighty model.

For comparison, Theorem 3.5 states the naive greedy scheme is \( (1-\sqrt{2\log(k)/k},\,1-1/k) \)-selectable in its \( (b,c) \) form against almighty; the standard scaling reduction implies only \(1-O(\sqrt{\log(k)/k})\). This does not contradict the sharper fixed-order guarantee because the adversary power differs.
