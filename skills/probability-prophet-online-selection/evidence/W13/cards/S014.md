## Model and guarantees

A **k-matchoid** consists of matroids `M_h=(N_h,I_h)` indexed by `h∈H`, with `∪_h N_h=N` and each element in at most `k` local ground sets. A set `A⊆N` is feasible iff `A∩N_h∈I_h` for every `h`. The paper works with the efficiently separable relaxation `P_∩={x∈[0,1]^N: x|_{N_h}∈P(M_h) for all h}`, which contains the true feasible-set polytope. Its theorem instances are independent weighted Bernoulli activations `X_i~Ber(x_i)` and deterministic weights `v_i≥0`, with ex-ante benchmark `Σ_i x_i v_i`.

- **Theorem 1.1 / Theorem 4.3 (fixed adversarial order):** for every `x∈P_∩`, every nonnegative weight vector, and every arrival order fixed before activations are exposed, the coordinated-price algorithm returns a feasible set of expected value at least `(1/(k+1))Σ_i x_i v_i`. This is an ex-ante result, stronger than only comparing to the prophet's expected feasible optimum. Corollary 1.2 gives a `1/(k+1)` OCRS; for every `ε>0` the paper states efficient `(1/(k+1)−ε)` selectability.
- **Theorem 1.3 / Theorem 5.6 (uniform random order):** the residual-price prophet-secretary algorithm has expected value at least `((1−e^(−k))/k)Σ_i x_i v_i`. Corollary 1.4 gives the corresponding RCRS, with an efficient epsilon-approximation to the selectability value.
- **Appendix B / Theorem B.1:** an additional random-element OCRS guarantee applies when the input is divided into independent batches and at most one element in each batch is active. It does not establish the same result for arbitrary within-batch correlations.

The adversarial order is fixed independently of realized activations; this is not the almighty-adversary model. The random-order theorem assumes a uniformly random order. Neither theorem is a claim for arbitrary activation dependence. The factor is with respect to the stated relaxation, not a claim that `P_∩` equals the integral feasible polytope.

## Fixed-order proof: common surplus and coordinated principal partitions

For each local matroid, the proof uses the quadratic rank-support function `Γ_M(t)=1/2 max_{y∈B(M)}(t⊙t)·y`. Its subgradients have form `t⊙y` for a maximum-weight base `y`; positive price levels of `t` induce contracted-and-restricted local matroid blocks, and each block has a density bound `p(S)≤α_j r(S)` (Lemma 4.1, pp. 11–13). The key obstacle is that a separate local price vector must be coordinated across all k matroids.

**Proposition 4.2 and algorithm (pp. 9–14).** Minimize the convex potential
`Φ(t_1,…,t_k)=Σ_h Γ_{M_h}(t_h)+(1/2)Σ_i x_i(v_i−Σ_h t_{h,i})²`
over nonnegative local prices. At a minimizer, `τ_i=Σ_h t_{h,i}` and a common surplus vector `p=x⊙(v−τ)` satisfy `p≥0` and `p∈∂Γ_{M_h}(t_h)` for every h. Thus `x_i v_i=p_i+x_i τ_i`. The induced threshold algorithm accepts an element exactly when it is active, `v_i>τ_i`, and its addition remains independent in every modified local matroid. The modified matroids are direct sums of the principal-partition blocks and are submatroids of the originals.

For every realization, charge each positive-surplus unavailable element to one local block that blocks it. The block density inequality and closure rank give `p(C)≤τ(I)` (equation (28), pp. 14–15). Availability is determined before `X_i` is revealed, so `P(i∈I)=x_iP(i available)`. Consequently `E[v(I)] = P−E[p(C)]+E[τ(I)]≥P`, where `P=p(N)`. For each local matroid, its principal-partition price vector satisfies `t_h·x≤P`; summing over h and using the surplus identity gives `Σ_i x_i v_i≤(k+1)P`. This proves the `1/(k+1)` bound. The proof needs a matroid-polytope point in every local component and the per-element membership bound k; it is not just a generic threshold proof.

## Random-order proof: residual relaxation, exchange charging, and ODE

For accepted feasible `A`, contract each local matroid by `A∩N_h` and define the downward-closed residual polytope `P(A)` by these contractions, with coordinates in A set to zero. Let `R(A)=max{v·y:y∈P(A), 0≤y≤x}` and `Δ_i(A)=R(A)−R(A∪{i})` when `A+i` is feasible. The algorithm assigns independent uniform clocks to elements and accepts active feasible i at time t iff `v_i≥γ(t)Δ_i(A)`, with
`γ(t)=(1−e^(−k(1−t)))/k`, `γ(1)=0`, `γ(0)=(1−e^(−k))/k`, and `1−kγ(t)+γ′(t)=0` (equations (29)–(33), p. 16).

The matchoid-specific ingredient is Lemma 5.2 (pp. 16–18): for an optimizer y of `R(A)`, local matroid basis exchange gives feasible residual comparison vectors after deleting each candidate i. Combining the local comparisons over the at-most-k matroids containing i yields `Σ_{i∉A:A+i feasible} y_i Δ_i(A)≤kR(A)`. Lemma 5.1's exchange map is injective away from its `⊥` option and fixes common elements; the latter is needed so the exchanged vector has zero i-coordinate and belongs to the contracted polytope.

Let `r(t)=E[R(I(t))]`. The utility lemma gives `E[Util]≥∫₀¹(1−kγ(t))r(t)dt`; the revenue lemma, obtained by integration by parts over the finitely many residual-value jumps, gives `E[Rev]=γ(0)R(∅)+∫₀¹γ′(t)r(t)dt`. Since total value is utility plus revenue, the ODE cancels the integral and yields `E[v(I)]≥γ(0)R(∅)`. Because `x` is feasible in `P(∅)` and y≤x, `R(∅)=Σ_i x_i v_i`; this proves Theorem 5.6 (pp. 18–20). The uniform random order is represented by sorted i.i.d. uniform clocks.

## Scope notes

- The local-matroid parameter k bounds how many components contain a ground element; it is not the rank, capacity, or number of arrivals.
- The fixed-order theorem's construction uses coordinated weighted principal partitions and a common surplus; its factor is `1/(k+1)`. The random-order proof is a different algorithm and uses the factor `(1−e^(−k))/k`.
- Appendix B assumes independent batches with mutually exclusive activations inside each batch. Do not generalize that corollary to arbitrary negative dependence without another theorem.
