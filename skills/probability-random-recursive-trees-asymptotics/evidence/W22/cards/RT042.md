## Model and theorem/proof chain

1. **Base model (§1, pp. 1–2).** T_n is a rooted ordered Galton–Watson tree conditioned to have n vertices. Offspring ξ has critical mean Eξ=1, p_1=P(ξ=1)<1, and finite positive variance 0<σ²<∞; only admissible sizes are considered: for h=gcd{i≥1:p_i>0}, n≡1 (mod h). State space S={1,…,k} is finite. Every node has an independent U~Unif[0,1]; leaves get iid state f_0(U), and an internal node with ℓ children gets f_ℓ(V_1,…,V_ℓ,U)∈S. The target is the root state V_n. On a path, the recursion is an explicit finite-state Markov chain.

2. **Unconditioned fixed point (§2, pp. 2–3).** The root state W of the finite a.s. critical GW tree satisfies W =d f_ξ(W_1,…,W_ξ,U) with independent iid W_i =d W, but the paper explicitly warns this distributional equation may have more than one solution absent extra conditions. This is context; Theorems 1–2 use the spine chain, not uniqueness of this RDE by itself.

3. **Coalescent common-noise chain (Definition 1, §3, p. 3).** X_t=f(X_(t−1),U_t) on finite S is coalescent when using the same iid noise sequence for two copies makes them equal forever after a finite a.s. time, from every starting pair. This is stronger than merely having one irreducible class; the authors note unique irreducibility need not imply coalescence.

4. **Theorem 1, Kesten tree (§4, pp. 4–5).** The spine offspring law is size-biased: P(ζ=i)=i p_i, i≥1, and one of those children is marked uniformly; all unmarked children root independent ordinary GW trees. If the spine's Markov chain is coalescent, then the root value on Kesten's tree is a.s. well-defined and has exactly the stationary law of the spine chain; all spine states have that same marginal law. Proof is coupling-from-the-past along the infinite spine (classical Markov-chain argument).

5. **Theorem 2, conditioned trees (§6, pp. 5–6).** Under the base model assumptions and coalescent spine chain, V_n⇒W_∞, the stationary spine law. Proof dependencies, in order: (i) local convergence of fixed-depth conditioned T_n to Kesten's tree in total variation; (ii) Doeblin coupling of matching depth-k truncations, sharing node randomness; (iii) set ℓ=⌊k^(1/3)⌋ and bound the chance that a nonspine fringe subtree from the first ℓ spine levels reaches height k−ℓ:
   $$P(H\ge k-\ell)\le P\left(\sum_{i=0}^{\ell}(\zeta_i-1)\ge\ell^2\right)+\ell^2P(\operatorname{height}(T)\ge k-\ell)
   \le P\left(\sum_{i=0}^{\ell}(\zeta_i-1)\ge\ell^2\right)+\ell^2\frac{2+o(1)}{\sigma^2(k-\ell)}.$$
   The first term tends to zero by the weak law for size-biased ζ (finite mean 1+σ²); the second tends to zero for ℓ~k^(1/3) by Kolmogorov's finite-variance critical-GW height estimate. Finally, coalescence from level ℓ before the root makes root values agree with probability tending to one. This is not a generic tree recursion theorem: it uses finite-state common-noise coalescence, local Kesten convergence and the finite-variance height bound.

6. **Applications and counterexamples (§7, pp. 6–12).** The paper gives modulo-k examples for counting/leaf-counting (noncoalescent counterexamples), random path length, marked transversals, random-child values, minimax trees, Boolean functions, random binary subtrees, majority, and median. These are illustrations under each example's stated update, state and offspring conditions; they are not blanket extensions to continuous or unbounded states. Example 7 (random Boolean functions) further assumes binary critical offspring and finite Boolean-function state space.

## Source-internal path-length convention discrepancy (§7.3, pp. 7–8)

The recursion printed for a path sets f_0=0, f_ℓ=1+w_(1+⌊uℓ⌋) for ℓ>0, so its root value counts **edges**. The source then gives the ordinary-tree law P(W=i)=p_0(1−p_0)^i, i≥0, which is the edge-count geometric law with mean (1−p_0)/p_0, but the surrounding prose says the expected length is 1/p_0. It also states the Kesten limit as W+W′ for two independent geometric(p_0) variables. These formulas mix edge-count and vertex-count conventions.

Under the printed edge recursion, the independent derivation is: at each Kesten-spine node a uniformly chosen path child is off-spine with probability E(1−1/ζ)=p_0, so the number G_+ of edges up to and including the first off-spine edge has positive-support geometric law P(G_+=j)=p_0(1−p_0)^(j−1), j≥1; then the off-spine subtree contributes an independent zero-support geometric edge count W_0. Thus
$$L_{\mathrm{Kesten}}=G_++W_0=1+W_0+W_0',\qquad
P(L_{\mathrm{Kesten}}=n)=n p_0^2(1-p_0)^{n-1},\quad n\ge1,$$
and E L_Kesten=(2−p_0)/p_0. If counting vertices instead, add one to edge counts: the ordinary vertex count is positive-support geometric with mean 1/p_0, and the Kesten vertex count is a sum of two positive-support geometrics with mean 2/p_0. This reconciles the two expectation numbers in the prose but not the displayed edge recursion/distribution. The finite check uses p_0=1/2 and confirms the support/mass mismatch. This is a source-level convention/transcription caveat; Theorem 2's finite-state modulo-k claim remains distinct and is not refuted by this check.

## Reusable interface and limits

- **Input:** a critical finite-variance conditioned GW tree, iid node noise, finite node-state space, deterministic recursive update, and a proof that the induced spine common-noise chain is coalescent.
- **Output:** a unique stationary spine law and convergence in distribution of the conditioned-tree root state; a coupling-from-the-past sampler halting a.s. for that state.
- **Potential use:** only if a target observable can be represented as such a finite-state recursive function on a conditioned GW tree and all conditions are proved. The W22/A127 CTCS beta-splitting model is size-dependent and carries circular leaf order/gap labels; no such representation or fixed-gap two-leaf law is established here.
