# Method notes

## 1. Specify the directed network and flow convention

For a finite directed graph (G=(V,E)), specify disjoint terminal sets (S,T\subset V), capacities (c(e)\in\mathbb Z_{\ge0}), and the convention that a path starts in (S), ends in (T), and is simple (acyclicity is automatic for the up-right grid). Fulkerson (1959), Theorem 1, gives cut conditions for bounded net flow at source and sink sets; with integral data, its auxiliary max-flow construction yields an integral feasible flow. With unit edge capacities, flow decomposition identifies its value with the maximum number of pairwise edge-disjoint directed (S)-(T) paths. If designated edges have lower bound one and the target is a cover by at most k edge-disjoint S–T paths, add a super-source σ and super-sink τ, arcs σ→s for s∈S and t→τ for t∈T with capacity at least |E|, and a return arc τ→σ of capacity k. Put capacity one on each original edge and lower bound one on each required mark. Convert lower bounds to vertex imbalances and solve the standard auxiliary max-flow feasibility problem. In an acyclic original graph, every integral circulation decomposes into at most k unit S–T paths, and conversely any such path family yields a feasible circulation. This is a derived reduction—not the statement of Fulkerson (1959)—and should be checked for terminal overlap, zero-length paths, cycles and the desired count convention. If the question asks vertex-disjoint paths, split vertices and cap the split edge; do not silently switch Menger versions.

Ford–Fulkerson (1956), Theorem 1, is a distinct finite chain-flow/min-cut result with no integrality statement in that paper. Its multi-source reduction is valid only when any source may ship to any sink. Its topmost-chain/cut property is special to `ab`-planar networks. Do not use it as a directed integral-flow theorem or as a general path-cover result.

This theorem says nothing by itself about a smallest family of paths whose union contains a prescribed defect set. That family has a coverage constraint in addition to terminal routing. State it as a separate optimization problem.

## 2. A030 finite graph and the failed unrestricted path-cover identity

For the Aldous note’s square \(\{0,\ldots,n-1\}^2\), horizontal edges point right and vertical edges point up. The source and sink sets are

- `S_n = {(0,j): 0<=j<=n-2} union {(i,0): 1<=i<=n-2}`;
- `T_n = {(i,n-1): 0<=i<=n-1} union {(n-1,j): 0<=j<=n-2}`.

For independent open edges of probability (p), capacity is 1 on open edges and 0 on closed edges. The note defines (V(n,p)) as the edge-disjoint open path maximum, normalized by (2n), and (U(n,p)) as the minimum number of edge-disjoint (S_n\)-(T_n) paths whose union covers every closed edge. It states a fixed-(p) limit and conjectures (1-v(p)\sim\sqrt{2(1-p)}); its note does not prove the conjecture.

A proposed order on distinct directed grid edges is `e < f` when `head(e) <= tail(f)` coordinatewise. For one pair this says there is an up-right route that can traverse e before f. Dilworth applies to the resulting finite edge poset and computes its minimum chain partition from its width. **Do not assert that this width equals U(n,p): the unrestricted equality is false for the stated order and terminal convention.** R04 independently accepted an exact n=4 certificate with 11 closed/required edges, width 5, and minimum edge-disjoint terminal-path cover 6. This exact required-edge set has positive probability `q^11(1−q)^13` under iid closure probability `q∈(0,1)`, so the universal finite identity is false and equality fails with positive probability for each such `q`; it is not an almost-sure identity. The all-open configuration also has positive probability and gives `U=width=0`, so this does not say that failure is almost sure. It says nothing by itself about normalized expectations or the sparse asymptotic. A short lower bound uses `A={(0,0),(0,1),(0,2),(1,0),(2,0),(2,1),(3,0)}`: it contains all sources, each of its seven outgoing edges is a required closed edge, and it has only one entering edge, so an edge-disjoint path family needs at least `7−1=6` paths. Six explicit paths cover all 11. The full certificate is in `cases/edge_cover_n4_counterexample.md`. This disproves only the unrestricted finite identity, not A030's sparse asymptotic. Any amended finite/asymptotic bridge must explain the extra connector/capacity and boundary correction. Distinguish U's closed edges, which are required marks that routes may traverse, from V's zero-capacity closed edges, which cannot carry open flow.

For any proposed theorem under extra conditions, prove all of the following for the actual source/sink convention:

1. every chain can be extended to an (S_n\)-(T_n) directed path;
2. a whole family of chains can be extended simultaneously with no shared edges, including the connector segments;
3. all closed edges are covered and no hidden terminal/corner exclusion changes the objective;
4. the reverse implication maps each admissible path family to a chain cover without increasing count;
5. any boundary discrepancy is explicitly bounded at the asymptotic scale used.

A finite exhaustive check at n=2,3 found no mismatch, while the reviewed n=4 exact counterexample disproves the unrestricted equality. If one of these items is unavailable, keep the continuum poset argument and finite flow result separate. Pairwise comparability alone cannot supply a simultaneous path extension.

### Formal interface: width versus minimum edge-disjoint required-edge cover

> **Setup.** Fix a finite directed acyclic graph `G=(V,E)`, a source set `S`, a sink set `T`, and a required edge set `C ⊆ E`.
>
> **Path-cover number.** `U_G(C)` = the minimum number of pairwise edge-disjoint directed `S`–`T` paths whose union contains `C`.
>
> **Edge poset and width.** For distinct `e,f ∈ E`, declare `e ≺ f` iff `head(e)` reaches `tail(f)` in `G`. Let `w_G(C)` be the width (maximum antichain size) of that order restricted to `C`.
>
> **Prove only the safe direction `w_G(C) ≤ U_G(C)`.** Along a directed `S`–`T` path the required edges it meets occur in traversal order, hence lie in a chain; an edge-disjoint family allocates each required edge to exactly one path, so `w_G(C)` distinct paths are needed. This direction needs no simultaneous-extension hypothesis.
>
> **The converse is not available.** `U_G(C) ≤ w_G(C)` would require a *simultaneous*, edge-disjoint extension of a chain partition, with exact terminal and boundary preservation, including the connector edges between chain elements. Individual extendability of each chain is insufficient: connectors chosen chain-by-chain may overlap, so the union cannot be made edge-disjoint even though every chain extends separately.
>
> **Status of the converse.** It fails in general. The reviewed exact finite `n=4` counterexample has `w_G(C)=5` and `U_G(C)=6` on 11 required marks, a configuration occurring with positive probability `q^11(1−q)^13` under iid closure probability `q ∈ (0,1)`. That certificate is computational negative evidence with **zero source credit**; it refutes the unrestricted finite identity, and by itself says nothing about sparse `q→0` asymptotics. Any sparse bridge must bound the path-cover/width discrepancy at the target `n√q` scale *uniformly across joint `n,q` limits*; ordinary LIS asymptotics and fixed-box Poisson convergence do not supply such a bound. Do not claim an all-`n` edge identity or a sparse theorem here.

## 3. Finite Dilworth and the continuum Poisson chain benchmark

For a finite poset (P), Dilworth says the minimum number of chains in a partition of (P) equals its maximum antichain size (width). If the cost is phrased as a chain cover that may overlap, convert it to a partition by assigning each element to one chain; state that this does not change the minimum.

For a homogeneous planar PPP in a rectangle, condition on its count (M). Ordering points by their first coordinate makes the ranks of the second coordinate a uniform permutation. Coordinatewise increasing chains correspond to increasing subsequences. The width is the longest decreasing subsequence; reversing the permutation values identifies its distribution with LIS. AD95 Theorem 5(a) proves the unit-intensity square LIS constant (c=2). This yields the continuum Poisson point-chain-cover asymptotic with constant 2. It is a continuum point-set theorem, not a lattice path theorem.

BDJ’s RSK/Toeplitz/Riemann–Hilbert and de-Poissonization analysis supplies a sharper fixed-permutation and Poissonized distributional benchmark. Johansson's exact geometric **vertex**-LPP shape and asymmetric tail speeds provide another fixed-model comparison. Do not invoke the Tracy–Widom limit when only the leading constant is required, or transfer these results to edge-capacity flow without a proved coupling.

## 4. Scale audit and the two-limit obstruction

A PPP with intensity δ on a square of side (n) becomes unit intensity under coordinate dilation by √δ; the side becomes √δ n. If the continuum point-cover number is asymptotic to (c) times side length, the candidate count divided by Aldous’s (2n) normalization is

`c * sqrt(delta) / 2`.

For two directed edge orientations with closed probability (q=1-p), the unmarked mean defect intensity heuristic is δ=2q. With AD95’s c=2 this yields √(2q). This is a derived dimensional heuristic. Aldous’s note literally prints the inverse scale `delta^(-1/2)n` and coefficient c=1; the correction must be attributed to the independent PPP dilation and AD95 theorem, not silently quoted as the note’s statement.

To pass from a fixed-(p) limit to (p\uparrow1), one needs a comparison accurate relative to √q after normalization, along a volume regime that also tends to infinity. The estimate must handle: (a) horizontal/vertical defect marks and the chosen embedding; (b) dependent geometric effects in the boundary path cover; (c) edge-to-point discretization; (d) source/sink boundary and corner losses; and (e) concentration or expectation errors. Pointwise Poisson convergence on every fixed box is not a uniform-in-volume bound and does not justify interchanging the limits.

The local L04 scripts exhaust n=2,3 and give an exact n=4 counterexample. A second exact solver checks the derived lower-bound circulation encoding on that n=4 case: feasible exactly for k≥6, while the width is 5. The scale script checks algebra only. See the saved code, outputs, and R04 independent validation in `cases/` and `../evidence/raw/acceptance_reviews/6f75c03b2a480215_review.json.txt`.

## 5. Classical HAD versus A17

Classical Hammersley–Aldous–Diaconis dynamics: independent unit-rate spacetime Poisson events at x move the nearest particle strictly to the right of x leftward to x; stationary source and sink input laws can be added. Cator–Groeneboom’s theorem assumes its classical stationary source/sink setup; its second-class-particle speed is (1/\lambda^2) for source intensity λ and sink intensity (1/\lambda).

A17 adds deterministic coordinate drift (dX_i/dt=X_i(t)) to a finite-k Poisson-pull process. This changes the generator and stationary balance. A classical invariant law transfers only after verifying the new generator domain, boundary flux, non-explosion and marginal consistency. A17 remains unsolved by this source slice.

## 7. Undirected continuum-domain max-flow route (separate model branch)

If the task itself is an undirected iid edge-capacity network on a rescaled lattice approximating a regular bounded continuum domain, the Cerf–Théret papers provide positive max-flow tools, each with its own assumptions. W06-015 Theorem 1 gives an almost-sure surface-order limit and anisotropic finite-perimeter min-cut functional under an exponential moment. Its domain is bounded, open, connected and Lipschitz; the boundary is covered by finitely many mutually transverse oriented `C¹` hypersurface patches; terminal pieces are relatively open, positively separated, and have relative boundaries of zero `H^{d-1}` measure. Do not reduce this to “any Lipschitz domain.” W06-016 Theorem 1 gives a surface-order lower tail below the continuum cut under its exponential-moment and zero-mass threshold assumptions. W06-017 Theorem 1 gives a volume-order upper tail above a polyhedral threshold under its own piecewise-`C¹` domain, separation and exponential-moment assumptions. Use the lower-tail finite-cover argument as a union bound over localized cut events (not an independence product); use the upper-tail disjoint-layer construction only with its own independence conditions.

These are concrete methods for their undirected continuum-domain flow model. They do not become directed Menger path-cover, Dilworth, or sparse Bernoulli-to-Poisson theorems. The exact source page uses and model limits are in `sources.md` and the L04 source cards; R04 accepted the three concrete CT method uses for this separate model branch; none supports A030. Ford–Fulkerson (1956) is a finite undirected cut/flow router, while Fulkerson (1959) supplies the directed feasibility/integrality input for the derived bounded-cover test; R04 growth_batch_08 final v10 accepted both as scoped uses (cumulative 11/30, 19 remaining, publication unapproved), and neither supplies an all-size edge-poset identity.

## 8. New complete-read interfaces: demand cuts, matrix profiles, and random-order growth

**Gale (1957), finite real-demand cuts.** For a finite directed network with antisymmetric flow, nonnegative real (or infinite) capacities, and real node demands, the feasibility theorem is exactly `d(N\S) ≤ c(S,N\S)` for every vertex subset `S`. This is a demand-feasibility interface proved by terminal augmentation and max-flow/min-cut. Use it before a separate integer marked-edge path-extraction construction; the criterion alone does not cover prescribed edges by at most `k` edge-disjoint terminal paths. Its ordered-group integer remark is not an additional credited method. The binary incidence application supplies sorted row/column margin inequalities, useful as a finite profile check.

### Knuth matrix profile convention

Use ordinary generalized RSK for nonnegative-integer matrices, including zero-one arrays. The optional §5 dual construction is a separate convention: it requires distinct pairs and gives dual P and generalized Q with the same drawn shape; transposing P changes it to an ordinary tableau with conjugate shape. Ordinary row insertion gives the longest-nondecreasing first-row statistic. The dual graph relation in Eq. (5.3) is strict in the second coordinate, so the analogous first-row statistic is strict (derived from the §4 graph interpretation). The matrix-transpose P/Q symmetry in ordinary Sections 1–4 does not transfer to §5.

### Seppäläinen microscopic state and boundary limit

Before using the random-order hydrodynamic theorems, verify the microscopic state space Σ: Z∪{−∞,+∞} values, coordinatewise monotonicity, locally finite coordinate-hyperplane discontinuities on bounded cubes, continuity from above, and left-tail decay (6). Theorem 4.1 additionally assumes macroscopic u_0 is nondecreasing, locally Lipschitz and satisfies (11), while σ_n∈Σ has pointwise local LLN (12) and uniform tail bound (13). Theorem 5.1 requires both initial profiles in Σ, the same PPP coupling, σ_n≤ζ_n≤σ_n+h for fixed positive integer h, and the exact defect set A_n(t)={x:ζ_n=σ_n+h} with n^{-1}A_n(0) locally approximating a deterministic closed B by (28). Formula X(B,t)=W(B,t)∩W(closure(B^c),t) retains the closed complement. Its boundary conclusion (29) is one-sided local inclusion; under the added no-interior-overlap condition, (30) is local erosion/dilation convergence of the full sets. It is not a general boundary or set Hausdorff theorem.


## 9. Additional exact chain, tableau and classic-HAD methods

**Superadditive Poisson LIS versus exact constant.** Hammersley (1972), Theorem 4, proves a deterministic planar Poisson/fixed-size LIS growth constant by the superadditive rectangle inequality, Kingman, tail triviality, and monotone Poisson-total transfer; Theorem 7 only gives `π/2≤c≤e`. Its later arguments suggesting `c=2` are explicitly heuristic. Use AD95 for the exact value `c=2`; do not attribute it to Hammersley (1972). Seppäläinen (1996) has a separate one-dimensional stick process: Theorems 1–3 and the Appendix prove its attractive Feller dynamics, while Theorem 2 selects the minimal accumulated-flux weak solution (entropy uniqueness is asserted only for bounded initial density); §§8–9 identify `c=2` for this coupled Hammersley model by stationary exponential comparison. For the Feller continuity proof, use R02's quantitative same-PPP finite-window inequality repair, not the literal printed Eq. (4.32) equality; Eq. (5.1) uses the running particle index `η_j`. See the accepted R02 local review（本机附件：`evidence/raw/legacy_reviews/6ccababb4b6a05d9_review.json.txt`）. Neither paper gives a marked-edge boundary-path cover or a uniform sparse growing-box error.

**Finite RSK profile methods.** Schensted (1961) gives the insertion/recording-tableau bijection: for distinct entries the first-row length (number of columns) is LIS and the first-column length (number of rows) is LDS; Part II’s weak-row/strict-column convention gives LNDS and strict LDS. Gessel (1990), Theorem 16, combines bounded-row Schur sums and Cauchy–Binet with RSK; the row bound gives strict LDS≤k, while word reversal preserves content and yields strict LIS≤k. For permutations its series is `Σ u_k(n)X^{2n}/(n!)²`, with `b_i=Σ X^{2r+i}/(r!(r+i)!)`. These are exact finite enumeration/profile interfaces; they do not transfer a continuum chain cover to discrete edge-disjoint terminal paths or supply de-Poissonization error uniform in volume.

**Finite poset algorithm and model-specific particle coupling.** Pijls–Potharst (2011), Lemma 1, uses the original arcs of a finite DAG in a node-split min-flow/max-cut algorithm. Its minimum path cover visits each vertex at least once and may overlap at vertices; only after mapping to the reachability poset and assigning each vertex to one covering path do we get a partition into chains, which need not be a vertex-disjoint path family in the original DAG. This is not coverage of marked grid edges by edge-disjoint boundary paths and does not contradict the reviewed width-5/path-cover-6 counterexample. Atalik et al. (2021), Theorem 2.1, gives a finite-size distributional equality for longest decreasing-pattern-avoiding subsequences of a uniform permutation and a particular aligned-segment particle count. Its planar Hammersley variant simulations do not establish scaling exponents.

**Keep classical HAD distinct.** Cator–Groeneboom (2006) uses stationary source intensity `λ` and sink intensity `1/λ` in the classical rate-one Poisson-pull process. Its flux/exit-point identity, exit tail and cube-root-scale second-class estimates apply under that law and the paper's strict/weak NE conventions. They do not prove the invariant law or generator balance of A17's deterministic-coordinate-drift process. The 2005 Cator–Groeneboom work is a separate held source and was not reread in this batch.

## 11. Additional finite path-cover, RSK, circulation and Hammersley interfaces

**Temporal DAGs are a different path-disjointness model.** Chakraborty–Dailly–Foucaud–Klasing (2024), Theorem 2 (proof pp. 7–11), proves the path-cover/antichain-width equality for temporal oriented trees via the temporal-connectivity graph, path/clique correspondence, and weak chordality. Arcs have strictly increasing times. A path occupies each vertex on a closed interval between its incoming and outgoing times, so sharing an endpoint counts as temporal intersection. A path cover may contain overlapping paths; temporal disjointness is a separate same-time vertex condition. This is neither ordinary edge-disjointness nor a static-DAG proof: static DAG Dilworth is cited background, and general hardness proofs are deferred. Theorem 4 rooted/line results are separate (pp. 12–13). Do not use this to repair the A030 counterexample.

**Unified finite RSK profiles.** Dauvergne–Nica–Virág (arXiv v1, 2021), Theorem 1.1 and Proposition 6.4 (not Theorem 6.4), give the finite càdlàg RSK/LPP isometry and bijection. The inverse uses both `W_t f` and its Gelfand–Tsetlin pattern `G_t f`. The profile domain has no negative jumps, nonnegative initial values and `f_i(0−)=0`; continuous decreases are allowed, and the interval functional is only finitely additive on the finite unions used. Ordinary matrix RSK uses nonnegative integer jump profiles and same-shape `P,Q`. Dual zero-one matrices use piecewise-linear 0/1 slopes, strict-right/weak-up paths, `W` for the row profile of `Qᵀ`, `G` for `P`, and conjugate `P,Q` shapes. Exclude the §7 Bernoulli Gibbs proof branch; R04 flags an independence step after p. 33 Eq. (41), without claiming the theorem false. This finite transform is line-space data, not graph edge-disjointness or a sparse approximation.

**Hassin’s restricted grouped-circulation interface.** The literal Theorem 4 display omits a condition and fails on R04’s two-cycle example with one bounded arc and one uncovered free return arc. R10 then proved and R04 accepted a separate finite-real Farkas repair: with pairwise disjoint nonempty arc groups, finite real bounds `d≤Cx≤k`, and real circulation variables `Bx=0`, test node potentials/group constants satisfying `Bᵀt=Cᵀc`, which forces zero potential difference on each uncovered free arc. If the groups cover all arcs, this condition is vacuous. Any nonnegativity constraint must be encoded among the bounds; empty-group bounds are checked directly; one-sided infinite bounds are outside the accepted use. This derived interface gives no integer-flow result, path decomposition, edge-Menger theorem, or sparse transfer, and is not needed for ungrouped A030.

**Discrete Bernoulli Hammersley boundaries.** Basdevant–Enriquez–Gerin–Gouéré (2016), Theorem 3.1, gives finite-box stationarity and line-count identities for two distinct models. Model 1 uses strict increase in both coordinates; Model 2 uses strict increase in the first and weak increase in the second. In Model 1, `0<p,α<1`; the bulk, iid Bernoulli(`α`) sources, and independent iid Bernoulli(`β`) sinks are independent, with `β=p(1−α)/(α+p(1−α))`; the update sweeps crosses right-to-left and then updates sinks. In Model 2, `0<p<α<1`; the bulk and Bernoulli(`α`) sources are independent, as are the independent sinks with law `Geo(β)−1`, `P(K=k)=β(1−β)^k`, `β=(α−p)/(α(1−p))`; update sinks first, then sweep crosses left-to-right. The theorem preserves the specified row product marginals; it does not assert independence across time or independence between the top-row count and sink flux. Use only these finite Theorem 3.1/local-balance and line-count interfaces, not the unaccepted extremal-invariant or uniform-shape branches. Keep the discrete models separate from continuous classical HAD and A17's drift-plus-jump process; fixed-`p` results give no uniform `p↑1` error.

**Continuous sparse gap-chains and the remaining lattice gap.** Basdevant–Gerin (2019), Theorem 1.1, gives the exact continuous PPP gap identity. Theorem 2.4 gives a rare-intensity regime only for equal coordinate gaps `h_t=(h_t,h_t)`: for `a,b>0`, if `h_t√λ_t→0` and `√λ_t t→∞`, then `L^{h_t,λ_t}_{(at,bt)}/(√λ_t t)→2√(ab)` in probability. This is a sequential sparse result for the continuous PPP model, not a uniform-in-`p` Bernoulli diagonal estimate. The discrete theorem separately has integer `k≥0`, weights `P(W=r)=(1−p)p^r`, and the empty-rectangle convention `T=0`, CDF 1 when a shrunken coordinate is nonpositive; its fixed-`p` shape does not supply uniform error. Neither source embeds A030’s closed edges in a PPP while preserving simultaneous edge-disjoint boundary paths. The exact n=4 width-5/path-cover-6 counterexample stands; the corrected joint-limit bridge is unproved.
