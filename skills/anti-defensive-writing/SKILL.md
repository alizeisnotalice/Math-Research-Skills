# 反防御性写作

先明确文章的主张、证据与读者，再用直接、平静的语言说明做了什么、发现了什么以及理由。局部修改保持局部范围；按用户指定语言输出，未指定则沿用原稿语言。

## 改写

1. 找出段落的主要观点和每句的作用。对免责声明、自我否定、重复澄清与层叠保留语，判断它是否提供证据、适用范围、逻辑或必要概念区分；没有这些作用的内容删去。
2. 直接说明研究内容和条件。将泛泛的自我评价改为具体对象、样本、参数或结论；每段围绕一个任务展开，先说观点再给理由。
3. 用准确性替代含混保留。删去重复的“或许/可能/潜在”等词；真实不确定性应说明来源与范围。不能把相关性改为因果性，也不能为增强语气添加显著性、机制、数据或优势。
4. 只保留推进论证的对比。需要区分概念或解释差异时明确比较；无实际区分作用的“不是 X 而是 Y”“需要澄清的是”等框架删去。
5. 最后对照原文核对技术含义、必要前提、禁止事项、量词、数值和界方向，交付改好的正文。

## 论文与数学论证

围绕有证据的主要贡献组织摘要、引言、实验与结论；保留有助于解释贡献的其他成果。必要的限制在相关位置清楚说明一次；摘要或定理中省略限定会误导时，就在该处保留。数学论文的结构、符号和证明规范同时遵循 `math-paper-writing`。

保留决定命题真假的假设、维数依赖、定义域、量词、方法限制与未解决证明缺口。真实证据仅支持局部、有限网格或近似结果时，准确写出这一范围。语气修改不能扩大数学结论。

指标有升有降时，给出相同条件下的具体结果和取舍；不将单项下降泛化为整个方法无效，也不更换评价标准或隐藏影响核心结论的不利结果。原因未知则保持未知。证据不足时缩小或撤回相应主张。

实验应回答有效性、优势来源、替代解释或适用条件中的实际问题。缺少实验时定位因此缺乏支持的具体主张；重复展示可以合并，影响核心结论的反例和不利结果保留。模拟审稿区分已证实问题、待核验问题与可选增强，不把每个设想的质疑写成正文局限。

## 技术方案与 SOP

写清操作、参数、前提和目的；去掉说教语气。精简须保持必要条件、禁止事项和操作含义。只在原操作确实对应时使用“标定、解耦、淬灭、钳定”等术语，不为显得专业而替换技术动词。“不可互换”一类真实技术限制保留。

需要具体中英句式、指标取舍或 SOP 对照时，按相关章节读取 [中英示例](references/bilingual-examples.md)。示例提供写法，不提供用户论文中不存在的事实。
