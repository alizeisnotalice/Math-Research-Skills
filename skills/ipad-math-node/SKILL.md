# iPad 数学计算节点

本技能配合用户授权的 iPad Math Node 原生应用与 Mac 客户端，通过 USB 连接 iPad 执行数学任务。读取项目 `README.md` 并检查本轮实际版本；默认项目位置为 `/Volumes/data/CodexProjects/iPad-Math-Node`，也可由用户指定其他项目路径。项目或应用缺失时报告，不能假设已安装。

## 当前能力与边界

当前原型支持多项式与受限 JSON 表达式在有限区间上的 Simpson 浮点数值积分，以及非负整数区间（含两端，最高 2,000,000）的精确平方和 `--operation sum_squares`；不能执行任意脚本、MATLAB、Mathematica 或 GPU 任务。iPad App 需要前台运行，打开时自动启动服务，iPadOS 暂停、断线或退出可能中断计算。用户提出超出能力的任务时，明确缺少的功能，使用其他可用计算工具继续，或在用户授权范围内扩展软件。

## 调用

1. 根据实际任务固定系数、区间、偶数分段数、CPU 线程数、所需误差和运行预算。SSH、雷电 MacBook 和 USB iPad 是独立连接；在任务需要时才检查目标设备，不重复进行无关测试。
2. 在 Mac 的项目目录运行 `python3 mac/ipad_math.py --list`，将 iPad 通过 USB 连接并在前台打开已安装的 App，服务自动启动。无需应用配对码；iPad 的系统信任和开发者签名仍按系统要求处理。监听器绑定 iPad 回环地址，但这不是应用身份认证；连接设备的可信电脑或同设备上的本地进程可能提交任务。多台 USB 设备时通过 `--device` 指定。
3. 运行 `python3 mac/ipad_math.py --coefficients 0 0 1 --start 0 --end 1 --intervals 10000` 这样的任务，系数按常数项到高次项排列。表达式积分示例为 `--operation integrate_expression --expression-file examples/sin.json --start 0 --end 3.141592653589793`，支持算术、幂、三角及常见初等函数，语法和限制见项目 README。平方和例如 `--operation sum_squares --start 0 --end 1000`，结果以十进制字符串给出以保持整数精度。默认使用 `max(1, floor(设备活跃逻辑处理器数 × 0.7))` 个工作线程（最多 64），让允许的线程持续处理任务；`--workers` 可选更小值，超出设备上限的请求会被拒绝。它是线程并发的近似控制，不保证总 CPU 使用率、算力、功耗或温度精确保持在 70%；单逻辑处理器至少使用 1 个线程。当前实现限制系数数目、分段数与数据大小；不能以更改限制代替资源预算。
4. 保存任务参数、真实命令、客户端输出、任务 ID、软件版本及所用硬件；正式项目中的脚本、输入与最终结果放项目持久目录，临时产物遵守用户的数据盘约定。校验结果的任务 ID 和操作类型；独立检查解析结果、残差或误差。浮点求积不是一般命题的严格证明。
5. 连接失败、App 未安装或结果未返回时，记录实际状态并继续本机可做的工作；不要将设备识别、项目能解析、macOS 编译或模拟结果写成 iPad 真机运行。断线后先确认远端任务是否结束，避免重复执行；停止本次创建的进程。

## 构建与安装

需要完整 Xcode、iPad SDK、Apple 账户、有效签名及真实设备授权。打开项目中的 `iPadMathNode.xcodeproj`，按项目 README 处理签名；编译或安装失败时保留诊断。SDK 构建、签名、安装、USB 连通与 iPad 上返回计算结果各自独立核验。仅在对应步骤实际成功时报告成功。
