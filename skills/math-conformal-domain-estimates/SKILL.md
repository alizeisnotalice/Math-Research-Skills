# Conformal-domain estimates

Select the route from the input model.  Record its normalization before comparing energies or transporting estimates: rescaling, unfixed boundary components, and an unspecified inverse-map convention can change the statement.

## Circle-domain coordinate and trace-energy route

Use this route for a normalized circle-domain coordinate family with identified boundary components, compatible finite coordinate energies, and a trace/length-area ledger.  Pass to a compact limit only with the required coordinate compatibility, then state any extension or removability conclusion with its conformal-removability hypothesis.  This is not a generic planar-domain compactness theorem and does not manufacture boundary removability.

## Univalent inverse integral-means route

Use this route only for a normalized univalent disk map with the stated dyadic-annulus inverse first-power data.  Keep the inverse-map convention, strictness closure, and Brennan-domain model visible when transferring the strict inverse-first-power input to the inverse-square endpoint or disk-to-domain conclusion.  Do not apply it to an arbitrary holomorphic map, or infer the required integral data from univalence alone.

Read the circle-domain or univalent-integral-means reference that matches the route before use; their hypotheses are not interchangeable.
