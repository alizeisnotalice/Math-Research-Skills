# E06 · 在线度量惰性跟随

用于 k-server 问题中已经给定一个模拟配置轨迹 `C_0,...,C_H` 的情形。每个
`C_t` 是度量空间 `(X,d)` 中含重数的 `k` 点多重集，且在时刻 `t>=1` 包含已揭示
请求 `r_t`。本技能把它变成只在未覆盖请求时移动一台服务器的实际轨迹，并给出可逐步
重放的移动上界；它不负责产生 `C_t`，也不把该账本升级为任意算法的竞争比结论。

## 1. 先固定匹配和信息模式

把多重集临时标号为有序元组，定义

\[
  M(A,C)=\min_{\pi\in S_k}\sum_{i=1}^k d(a_i,c_{\pi(i)}).
\]

位置相同的副本仍是不同匹配端点。固定副本、服务器和排列的打破平局顺序。若模拟器在
看到 `r_t` 后以当前前缀确定 `C_t`，下述跟随者就是因果在线服务；若轨迹事后给定，
下述不等式仍只是逐路径比较，不应称作在线算法。

## 2. 最小匹配惰性跟随

从实际配置 `A_{t-1}` 开始。若 `r_t` 已被覆盖，不移动。否则选定 `C_t` 中一个等于
`r_t` 的副本，取从 `A_{t-1}` 到 `C_t` 的一组最小匹配，并把与该副本配对的那台实际
服务器移到 `r_t`；其余服务器不动。记这一步费用为 `m_t`，所得配置为 `A_t`。

同一组匹配在移动后使请求副本的边长变为零，故

\[
  m_t+M(A_t,C_t)\le M(A_{t-1},C_t).
\]

另一方面，拼接两组最小匹配给出多重集匹配距离的三角不等式

\[
  M(A_{t-1},C_t)\le M(A_{t-1},C_{t-1})+M(C_{t-1},C_t).
\]

相加并望远镜，得到任意有限路径的精确可用账本

\[
  \sum_{t=1}^H m_t
  \le M(A_0,C_0)+\sum_{t=1}^H M(C_{t-1},C_t).
\]

若输入另给每步模拟移动上界 `b_t>=M(C_{t-1},C_t)`，可将右端的匹配距离替换为
`b_t`。这是转换引理，不是对 `b_t`、模拟器成本或 `OPT` 的估计。

## 3. 审计清单

对每一步保存：模拟配置的带重数表示、选定请求副本、最小匹配、被移动的实际服务器、
`m_t`、移动前后的势，以及给模拟轨迹记账的数。仅凭数值匹配求解器找到的排列不足以
认证精确界；权重临界或正式证书使用精确有理距离、整数距离，或定向区间。

先运行 `python3 scripts/check_finite_lazy_following.py`。它以整数算术穷举五点线段上
`k=2` 的全部两请求短路径，检查一步势不等式、匹配三角不等式和望远镜账本。该测试是
有限实例核验，不替代理论证明。

## 4. 边界

本技能只采用两个预印本共同明确写出的 matching-potential/lazy-following 机制。它不
采用分层分配、随机分区、有限决策表的可计算性，或任何 `O(log^2 k)` 全局竞争结论；
这些都需要各自完整的额外假设和证明。来源的固定版本、页码与本技能的独立证明见
[来源与证明](references/pathwise-lazy-following.md)。
