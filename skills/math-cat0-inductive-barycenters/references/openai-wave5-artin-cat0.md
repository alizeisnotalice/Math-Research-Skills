# CAT(0) finite four-point diagnostic from an Artin-action obstruction

**Status:** conditional reference to the existing CAT(0) skill; it does not transfer the source's global obstruction without its affine mirror action.

**Pinned original:** *An Artin group with no geometric CAT(0) action*, SHA-256 `42a55e77bec64b365f0a37d92c7f0dd020a65a3418483cfc8b824d7d13ae8549`, [official PDF](https://raw.githubusercontent.com/openai/math/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/An-Artin-group-with-no-geometric-CAT-0-action-September-23-2026/paper.pdf), physical pp. 3–9, especially (2.3).

For four points `p,q,r,s` in a verified CAT(0) metric space, check the necessary comparison

`d(p,r)^2+d(q,s)^2 <= d(p,q)^2+d(q,r)^2+d(r,s)^2+d(s,p)^2`.

Use exact squared distances where available; a violation rejects CAT(0) for the supplied metric. Passing the test is only necessary: it does not certify CAT(0), a proper action, or the source's sector construction.
