# Generic subanalytic power preparation with fixed fibres

Source SHA-256: `dd294523779a9237a2ae4d5399e874bdfbfddbfe8c54a379240aeb2d2c75bf1b`; cached original has 65 physical pages. This is a conditional local-preparation interface.

Physical p.6, Lemma 2.2: a positive globally subanalytic `f(v,t)` admits fixed-parameter power bounds `t^N < f < t^-N` for small `t`; near a generic real parameter, any finite collection has convergent expansions in a common fractional power `t^(1/q)`, with uniform fixed-order parameter derivatives on smaller boxes. Physical p.7 converts a nonnegative definable residual `r(v,z)` on a compact fibre test box into a fixed-fibre correction bound `dist(z,C_v) <= r(v,z)^(1/N)`, explicitly warning that parameters must not move during a fibrewise correction.

Physical p.31 applies this to retain holes in one fixed continued divisor rather than changing the parameter domain while lowering a scale. Physical p.54 is a downstream relative-Albanese descent that relies on the prepared family. Input checklist: a finite definable/subanalytic family, positive functions or residuals, a compact test box, and restriction to one full-dimensional generic parameter piece. Do not infer a uniform threshold for a countable family.
