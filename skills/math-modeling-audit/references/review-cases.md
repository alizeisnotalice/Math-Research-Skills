# 易错情形与预期处理

| 情形 | 应检查或说明 | 不应做 |
|---|---|---|
| 汇总结果与论文完全一致 | 是否由相同错误公式生成；独立检查约束或特例 | 仅以一致性宣称模型正确 |
| 验收报告称有大量测试 | 测试框架是否实际发现用例；参数化数量、重叠及独立场景 | 把两组重叠测试数直接相加 |
| 同一批日志有 ZIP、tar 和解压目录 | 内容级去重与场景索引 | 计为三批独立实验 |
| 算法只搜索有限候选点 | 候选集完备性或最优性适用范围 | 写成无条件全局最优 |
| 检查超时、依赖缺失、文件不可读 | 未完成状态和影响 | 捕获异常后输出成功 |
| 外部系统无直接耗时字段 | 是否可用协议时间重建，并标明口径 | 编造界面时间或混用模拟时间 |
| 当前源码和旧输出同在目录 | 历史执行哈希、日志头、版本记录 | 用当前文件时间推断旧执行版本 |
| 用户问“用了什么数学工具” | 运行记录、脚本导入和实际调用 | 把已安装 MATLAB 或全部依赖写成实际使用 |
| 用户要求“检查，不要改” | 只读检查、问题与修复建议 | 顺手修复源码或更新 PDF |
| 需要官方规则但文件缺失 | 请求规则文件，或经允许查官方来源 | 将往届规则或个人偏好称为当前规则 |
