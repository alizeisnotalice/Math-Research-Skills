# Critical-SK support-profile interface

Scoped reference. For the draft's stationary conditioned SK measure, Gaussian localization/Dirichlet-form and edge-law package, retain the stated support-profile and cap-induction operations as a single coupled model contract. Input is the conditioned measure plus all localization and edge controls; output is the source's support/cap estimate. It is not a generic finite-chain mixing or log-Sobolev tool.
