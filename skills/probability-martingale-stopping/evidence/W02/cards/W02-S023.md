# W02-S023 — Single-jump processes and strict local martingales

## Source and reading scope

Martin Herdegen and Sebastian Herrmann, “Single Jump Processes and Strict Local Martingales,” arXiv:1510.03192v1, 12 October 2015. I read the complete original PDF, physical pp. 1–21 (including the appendices and references).

## Construction and filtration

Let \(\gamma\in(0,\infty)\) have cdf \(G\), with endpoint \(t_G=\sup\{t:G(t)<1\}\), and let \(F\) be locally absolutely continuous with respect to the Lebesgue–Stieltjes measure \(dG\) on \((0,t_G)\). Write \(\bar G=1-G\), and let \(f=dF/dG\) denote a local density. Define
\[
A^G_F(v)=F(v-)-f(v)\bar G(v),\quad v<t_G,
\qquad M^G_t(F)=F(t)1_{\{t<\gamma\}}+A^G_F(\gamma)1_{\{t\ge\gamma\}}.
\]
At an endpoint atom the definition assigns \(F(t_G-)\) when that limit exists; otherwise the endpoint convention is set separately. The natural filtration is \(\mathcal F^\gamma_t=\sigma(\{\gamma\le s\}:0<s\le t)\) (PDF pp. 3, 7–8). Every path follows deterministic \(F\) until the single random time and is constant afterward.

Lemma 3.1 (p. 8) proves \(M^G(F)\) is an \(\mathcal F^\gamma\)-martingale on the right-open interval \([0,t_G)\). Integrability follows from
\[
\mathbb E|M_t|\le |F(t)|\bar G(t)+\int_{(0,t]}|A^G_F(v)|\,dG(v)<\infty.
\]
For \(s<t<t_G\), the event \(\{\gamma>s\}\) is an atom of \(\mathcal F^\gamma_s\); conditioning there and using \(\int_{(s,t]}A^G_FdG=-F(t)\bar G(t)+F(s)\bar G(s)\) gives \(\mathbb E[M_t\mid\mathcal F^\gamma_s]=M_s\). This identifies exactly where the compensating jump value comes from.

## Endpoint classification and strict-local-martingale boundary

For the closed interval \([0,t_G]\), Theorem 3.5 (pp. 10–11) separates the endpoint atom from endpoint integrability. If \(\Delta G(t_G)=0\), then \(M\) is an \(\mathcal F^M\)-local \(\mathcal F^\gamma\)-martingale, with no assumption that \(M_{t_G}\) be integrable; the localizing sequence uses only stopping times in the smaller natural filtration of \(M\). The theorem's non-semimartingale conclusion is **only** the case \(\Delta G(t_G)>0\) and \(M_{t_G}\notin L^1\). If \(\Delta G(t_G)>0\) and \(M_{t_G}\) is integrable, then \(M\) is an \(H^1\)-martingale there: endpoint integrability gives \(A^G_F\in L^1(dG)\), the atom implies \(F(t_G-)\) exists and is bounded before the endpoint, and \(\mathbb E\sup_{t<t_G}|M_t|<\infty\) (pp. 10–11). Thus terminal nonintegrability alone does not imply failure of the semimartingale property when the endpoint has no atom.

When \(M_{t_G}\) is integrable, Lemma 3.7 (p. 12) computes the mass change
\[
\Delta\mu=\mathbb E M_{t_G}-\mathbb E M_0
=-\lim_{t\uparrow t_G}F(t)\bar G(t)\quad\text{if }\Delta G(t_G)=0,
\]
and
\[
\mathbb E[M_{t_G}\mid\mathcal F^\gamma_s]-M_s
=\frac{\Delta\mu}{\bar G(s)}1_{\{s<\gamma\}}.
\]
Thus, **under the integrability assumption of Lemma 3.7**, the process is an \(\mathcal F^\gamma\)-submartingale and strict local martingale when \(\Delta\mu>0\), a true martingale iff \(\Delta\mu=0\), and a supermartingale and strict local martingale when \(\Delta\mu<0\). The paper's terminology “strict local martingale” here is on the specified closed horizon and means local martingale but not martingale; it does not cover the distinct non-semimartingale case \(\Delta G(t_G)>0\) and \(M_{t_G}\notin L^1\).

The H¹ boundary is distinct from ordinary martingality. If there is no endpoint atom, Lemma 3.9 (pp. 13–14) says \(M\) is H¹ iff both \(F(\cdot-)\in L^1(dG)\) and \(A^G_F\in L^1(dG)\). In particular, an integrable martingale can fail H¹ (Corollary 3.10 and Example 3.15, pp. 13–16). If an endpoint atom is present, integrable terminal value already implies H¹ by Theorem 3.5(c).

## Bounded integrands can destroy true martingality

Theorem 4.2 (pp. 16–18) gives a concrete stochastic-integral counterexample. Let \(\gamma\) be uniform on \((0,1)\), so \(t_G=1\) and there is no endpoint atom. Suppose \(F\) is locally absolutely continuous, nondecreasing with \(F(0)=0\), and \(M^G(F)\) is a martingale on \([0,1]\) but not H¹. Define the deterministic bounded Borel integrand
\[
J(t)=\sum_{n\ge0}1_{(1-2^{-2n},\,1-2^{-(2n+1)}]}(t),\quad 0\le t\le1.
\]
Then \(J\bullet M^G(F)=M^G(F^J)\) a.s., where \(F^J(t)=\int_{(0,t]}J(u)\,dF(u)\), and the integral is a strict local martingale. Proposition 4.1 proves the identity for bounded deterministic Borel \(J\); the class of single-jump local martingales is closed under this integration. Since the original martingale is not H¹, \(F\notin L^1(dG)\); the alternating dyadic intervals force \(F^J\) to have a nonintegrable endpoint value. Lemma 3.4 then makes the stopped integral nonintegrable at time 1, so it cannot be a true martingale, although it is local (pp. 16–18).

This example sharpens the BDG boundary: bounded integrand plus an H¹ martingale integrator gives a martingale, but boundedness of the integrand plus a merely UI martingale integrator does not. The source gives an explicit instance where the stochastic integral is strict local (pp. 2, 16–18).

## Transfer limits

This is an example engine, not a general OST or stochastic integration theorem. Its proofs use a one-jump model, the natural filtration, local absolute continuity relative to \(dG\), and endpoint mass/integrability distinctions. The natural filtration \(\mathcal F^M\) need not be right-continuous or complete; the authors state that their martingale convergence arguments do not require the usual conditions (Remark 3.3(b), p. 10). Do not promote the example’s particular localizing sequence or endpoint formulas to arbitrary filtrations or multi-jump processes.
