# Scope of the Bachet-note recovery

The local note *An algorithmic proof of Bachet's conjecture and the Lagrange--Euler method*, arXiv:1310.5632v1, has SHA-256 `d50ec1d52ade4968dc0ac04740bc4576f47301af87b54d575cc8f9d4c3f30f6c` and four physical pages. Physical pp. 2--3 state its two descent lemmas and use Euler's four-square identity.

The note only sketches Lemmas 1--2 (physical pp. 3--4), so its claimed algorithmic existence/termination proof is not adopted. This skill replaces that unverified global step with a strictly weaker but exact input-specific certificate: direct equality checking, and a finite search that reports a witness only when one is found. It makes no assertion that the note's descent establishes existence.
