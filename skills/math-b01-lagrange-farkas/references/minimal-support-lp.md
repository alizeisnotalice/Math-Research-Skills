# 有限 LP 的齐次化与最小支撑证书

来自 OpenAI Family 380 的 *Strongly polynomial linear programming*，本机存档 SHA-256 96ac1c55365364382fa2eb8cb2b3c674400e24149a9ed781f2e4a6ed27000f68。本节使用其物理页 5、10–12 的证书构件。[固定版本](https://raw.githubusercontent.com/openai/math/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Strongly-polynomial-linear-programming-November-24-2026/paper.pdf)

对有理矩阵 A、向量 b，将 Ax≤b 嵌入线性子空间 C={(αb−Ax,α):x,α 任意}。若 C 中有坐标非负且 α>0 的点，则 x/α 可行。由直积内积可得 C⊥={(y,−bᵀy):Aᵀy=0}。若 C⊥ 中有非负点且最后坐标正，则 y≥0、Aᵀy=0、bᵀy<0，乘入 Ax≤b 立得矛盾。

需要稀疏证书时，在 C 或 C⊥ 中把最后坐标归一为 1。逐项尝试将其余坐标设为零，每次只有在仍存在非负且最后坐标为 1 的点时才保留新零条件。终态的支撑上，最后坐标归一截面只有一点：若还存在相同支撑上的非零齐次方向且其最后坐标为零，则可以沿该方向达到一个新增零坐标而保留非负性，与支撑极小矛盾。于是可使用精确线性代数恢复证书，再检查其符号和严格间隙。

测试 Ax≤b 取 x≤0、−x≤−1，y=(1,1)，则 bᵀy=−1，C⊥ 的见证为 (1,1,1)。判定每次置零后是否可行是一个单独的算法步骤；上述提取与核验不足以给出强多项式复杂性。一般目标函数、最优解和无界证书需对应的额外建模。
