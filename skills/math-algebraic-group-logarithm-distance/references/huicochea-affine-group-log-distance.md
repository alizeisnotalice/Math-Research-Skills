# Huicochea affine-group logarithm-distance theorem

Mario Huicochea, *Linear independence measure of logarithms over affine groups*,
arXiv:1511.09122v1 (2015), local physical pp. 1--4. No journal version was located in
the checked primary records; use this as a preprint theorem gate.

For a connected affine `G/K`, basis `B`, a `d`-dimensional `K`-defined linear subspace
`W` of `Lie(G(C))`, and a `K`-point `u` outside `W`, physical p. 4 defines `b_2(u)`,
the minors `Gamma`, `b_3`, and the explicit constant `c_4`. Theorem 1.1 then states
the displayed lower bound

```
log d_B(u,W) >= -c_4 log(b_3) b_3^(m+1) max(1,h_B(W)).
```

The source proof first treats the `GL_m` hyperplane case by height transfer and an
imported classical logarithmic-form bound (physical pp. 8--12, especially Proposition
3.1), then descends to a general affine group (pp. 16--18). Those imported bounds,
the chosen `K`-conjugator, and each height convention remain caller obligations. This
reference does not extend the result to non-algebraic points, arbitrary matrix logarithms,
or a subspace without a `K`-rational encoding.
