# Maximal coarse-assembly kernel interface

Source: OpenAI, *Failure of rational injectivity for maximal coarse assembly*, 5 October 2026, [pinned PDF](https://raw.githubusercontent.com/openai/math/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Failure-of-rational-injectivity-for-maximal-coarse-assembly-October-5-2026/paper.pdf), SHA-256 `30556c04280bf9879b341850260f92cdc7ea7d9e9412a995ba47fd08bed05bcf`.

**Scoped reference.** For a uniformly discrete bounded-geometry space `Z`, the source fixes
\[
 KX_q(Z)=\varinjlim_{r\to\infty}KK_q(C_0(P_r(Z)),\mathbb C),\qquad
 \mu_Z^{\max}:KX_q(Z)\to K_q(C^*_{\max}(Z)).
\]
It asserts a coarse disjoint union of finite connected bounded-degree graphs `X` and an infinite-order `alpha in KX_1(X)` with `mu_X^max(alpha)=0`, so rational injectivity fails. The operation uses the stated divisibility class, maximal Roe transfer, endpoint K-theory equality, and naturality. This does not transfer to reduced Roe norms or to an arbitrary coarse union. Locus: physical pp. 1, 3, 7--11, 17, and 22--23.
