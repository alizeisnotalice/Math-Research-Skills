# Mixed-determinant rank-one border identity

## Source

Suvrit Sra, *The generalized Lax conjecture holds for mixed determinants*,
v1, physical pp. 4--6, defines the mixed determinant as a sum over partitions
of the index set. Lemma 2.3 states the rank-one affine identity checked by this
tool for rational real-symmetric inputs.

## Scope

The checker evaluates the finite defining sum and the affine directional
updates exactly. It verifies only this algebraic identity for supplied data.
It does not supply Borcea--Branden real-rootedness, cone membership,
the exit-threshold lemma, or the induction proving a spectrahedral
representation.
