# Torelli 轨迹上的非典型交

Papas, arXiv:2201.11240v4, physical pp. 1--5, states Zilber--Pink-type finiteness for a supplied smooth irreducible Hodge-generic curve in the Torelli locus under the boundary and genus hypotheses of Theorems 1.1--1.2. The height mechanism uses a concrete variation of Hodge structure, a boundary degeneration and G-function period relations.

Record the curve, genus, Hodge-generic property, compactification boundary point, special-locus type and every height input. The source is not an algorithm for testing those hypotheses.
