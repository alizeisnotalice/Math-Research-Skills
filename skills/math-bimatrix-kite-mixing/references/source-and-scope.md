## 局部证明

若已有两个后悔均不超过 \(s\)，直接返回。两者不能同时大于 \(s\)，否则 kite 的任一凸加权和都大于 \(s\)。若行后悔 \(r_1>s\)，将行策略向固定列策略下的行最佳回应混合，权重 \(t=1-s/r_1\)。新行后悔为 \(s\)。列方每个纯动作的偏离收益随行策略线性变化，且在任何行策略下至多为 1，因此新列后悔至多 \((1-t)r_2+t\)。由 kite 不等式 \((1-s)r_1+s r_2\le s\) 得到该上界不超过 \(s\)。列后悔过大时交换两方。

## JSON 输入

```json
{
  "R": [["1", "0"], ["0", "1"]],
  "C": [["1", "1"], ["0", "0"]],
  "x": ["3/4", "1/4"],
  "y": ["1", "0"],
  "s": "1/5"
}
```

所有数字是整数或 `p/q` 字符串。矩阵必须同形并取值于 \([0,1]\)，策略必须
精确和为一。

## 有限验收

`--self-test` 枚举所有 \(2\times2\) 的零一矩阵对，及分母为 4 的策略格点。对每个
落入 \(K_{1/5}\) 的格点，脚本检查输出策略仍在单纯形且两个精确后悔都至多 \(1/5\)。
这是 Lemma 2.3(a) 在有限输入族上的独立回放，不是主定理的验证。

另一个负例采用匹配硬币型的零一博弈、两个玩家都选择第一纯策略，及 \(s=1/5\)。
该策略对不在 \(K_s\)，脚本必须拒绝作出 kite 证书。
