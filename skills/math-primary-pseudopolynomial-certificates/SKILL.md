# 主伪多项式证书

给定整数序列前缀时，运行[有限变换检查器](scripts/check_primary_pseudopolynomial.py)生成 binomial 变换并核对 \(P_n=\prod_{p\le n}p\) 对每个已给指标的整除性。

无限主伪多项式结论还需要一个封闭公式、递推加归纳证明或等价的全指标论证。详见[来源范围](references/primary-pseudopolynomial.md)。有限前缀通过不证明 Ruzsa 猜想、序列多项式性或生成函数代数性。
