# Hardy 积分算子的二次亏损证书

设 \(F(x)=\int_0^x f(t)\,dt\)，\(h=F/x\)。对有紧支撑的有理阶梯函数，\(xh^2\) 在所有正节点处连续，各段内有

\[
(xh^2)'=2fh-h^2.
\]

靠近零点的首段有 \(h=f\) 为常数，最后一段之后有 \(h(x)=F(b)/x\)，因此两个端点的 \(xh^2\) 极限均为零。在每段积分并消掉共有节点，得到 \(2\int fh=\int h^2\)。展开平方得

\[
4\int_0^\infty f^2-\int_0^\infty h^2=\int_0^\infty (2f-h)^2.
\]

Leng 在物理页 3–5 的 Theorems 1–2 证明了非负函数的 Hardy 亏损公式及二次特例。上面的独立二次推导适用于允许带符号取值的有限阶梯函数。离开这一输入类时，须重查端点积分以及目标距离或紧性所需条件。[Leng，arXiv:2606.15056v1](https://arxiv.org/html/2606.15056v1#S2)

给出有序的 `steps`，每项含右端点 `end` 与该段高度 `value`。首段从 0 开始，最后端点以后高度为 0。每个正端点段 \([a,b]\) 上，若高度为 \(c\)，则 \(h(x)=c+d/x\)，其中 \(d=F(a)-ca\)。平方积分分成有理部分和对数项 \(\pm 2cd\log(b/a)\)。全尾段的两个平方积分都贡献 \(F(b)^2/b\)，应计入亏损。程序返回精确有理常数和形如 \(q\log r\) 的符号项。

```sh
python3 scripts/check_hardy_quadratic_deficit.py examples/hardy-two-step.json
```

样例得到 \(\|f\|_2^2=9\)、\(\|Hf\|_2^2=18-4\log 3\)，以及亏损 \(18+4\log 3\)。这是等号方程的残差能量。若要推出有限对数区间上的距离，须明确区间并另用相应 Poincaré 不等式；全半轴上的虚拟极值函数还需核对可积性。
