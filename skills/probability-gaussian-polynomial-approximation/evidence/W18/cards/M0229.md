# M0229 — Latała, *Tail and Moment Estimates for Some Types of Chaos*

**Source/version.** Rafał Latała, *Studia Mathematica* 135(1) (1999), 39–53, DOI 10.4064/sm-135-1-39-53. The local D02 file has eight physical PDF pages, each a two-page scan sheet. I visually checked sheets 1 and 2 against the title/model and theorem statements, and read all eight sheets. The source hash and path are in `sources.json`.

## Model and exact gauges

Let (X_i) and (X'_j) be two independent sequences, with independent symmetric real variables and logarithmically concave tails. Define

- `N_i(t) = -ln P(|X_i| >= t)` and `N'_j(t) = -ln P(|X'_j| >= t)`, convex on `[0,infinity)`;
- normalize each by `inf{t : N_i(t) >= 1} = inf{t : N'_j(t) >= 1} = 1`;
- `Nhat_i(t) = t^2` if `|t| <= 1`, and `N_i(|t|)` if `|t| > 1`, with `Nhat'_j` defined analogously.

For `p>0`, the paper defines the vector gauge

`||(a_i)||_(N,p) = sup { sum_i a_i b_i : sum_i Nhat_i(b_i) <= p }`,

(and its primed version), and the matrix gauge

`||(a_ij)||_(N,N',p) = sup { sum_(i,j) a_ij b_i c_j : sum_i Nhat_i(b_i) <= p, sum_j Nhat'_j(c_j) <= p }`.

These are the two supremum gauges used in the main estimates; the Euclidean/Lp coefficient gauge is separately `||(a_i)||_p=(sum_i a_i^p)^(1/p)`.

## Main results

- **Theorem 1 (physical scan sheet 2, printed p. 40).** For a square-summable matrix `(a_ij)` and `X=sum_(i,j) a_ij X_i X'_j`, every `p>=1` satisfies

  `||X||_p ≍ ||(a_ij)||_(N,N',p) + ||(A_i)||_(N,p) + ||(B_j)||_(N',p)`,

  with a universal comparison constant, where `A_i=(sum_j a_ij^2)^(1/2)` and `B_j=(sum_i a_ij^2)^(1/2)`. Corollary 1 specializes to a symmetric zero-diagonal matrix and gives two-sided tail bounds.
- **Theorem 2 (physical scan sheet 2, printed p. 41).** For a square-summable sequence `(a_i)` and `p>=1`, `||sum_i a_i X_i||_p ≍ ||(a_i)||_(N,p)`, with universal comparison constants.

The results concern log-concave-tailed independent variables and degree-/distribution-specific gauges. They are auxiliary moment/tail inputs, not the standard-Gaussian Hermite-tail theorem or B167’s sharp sign-approximation constant.
