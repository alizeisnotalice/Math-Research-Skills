# 证据、附件与迁移边界

本仓库在 2026-11-14 汇集本机数学研究技能，导入旧 Math-Research 的 64 项方法。仓库根目录 `catalog/skills.json` 是规范入口清单，`provenance/` 记录原路径、版本差异与 SHA-256；本机详细盘点留在 `.local/`。

## 当前说明与历史记录

本次整理检查技能结构、文件完整性、内部引用、工具探测和安装行为，没有逐篇重读文献或重新证明各技能的数学断言。旧 `release-manifest.json`、冻结清单、review/status 和“已读/通过”等表述描述当时的来源状态，不代表此次独立数学验收。历史清单可能列出未随公开版分发的全文或归档，不能对公开子集直接运行要求完整原包的旧校验脚本并期待通过。

## 公开版包含什么

技能正文、必要参考说明、原创阅读/定理卡、来源题录与定位、示例及必要计算脚本按清单保存。论文 PDF、逐页图片、全文提取文本、原交付 ZIP、重复历史包与编译缓存留在原本机目录，不经本次发布上传；公开版通过题录、DOI/URL 和来源定位使用合法可获取的版本。本次整理不为第三方材料新增许可证。

某个文献结论需要核验时，先查来源卡和题录，再实际访问对应原文；只有摘要或局部文字时标明阅读范围。原文未取得则保留未核验状态，不以卡片、哈希、计数或下载链接代替原文审读。

## 旧 64 项证据包

旧方法技能的 `references/evidence-guide.md`、`portable-audit-access.md` 和来源索引保留其实际 resolver/registry 约定。只有当前问题需要对应文献/claim 时才读取该指南并定位已存在的包；不要假设仓库中自带完整证据包。旧绝对路径是来源线索，先验证存在性；失效后按指南找显式包根或从已核验来源获取，不能仅按文件名猜测替代品。

## 本机概率技能附件

标为「本机附件」的文件路径相对原安装包。先在当前技能目录查找；需要核对论文原文时，在 /Volumes/共享/Math_Research_Literature/01_Existing_Skill_Sources 的 02_Skill_to_Paper.csv 中按技能名、source ID 或题名查候选，再用 01_Paper_Index.csv 核对原文 SHA-256 及路径。相同题名的不同版本各有独立记录。若原文或证明依赖无法取得，保留待证状态。

## 本机安装

安装脚本只增补或更新公开清单中的文件，不删除既有附件和其他文件。替换前将旧字节及安装记录存于仓库 `.local/install-backups/`（可指定其他持久目录），因此原有证据仍可从已安装技能的同一路径读取。克隆到新电脑只获得公开子集；找不到可选附件应如实说明，不称完整原包已恢复。安装备份和 GitHub 推送均不代表“备份”磁盘上的备份已核验。
