# 重叠方法与证据选择

按当前要解决的数学步骤原地选入口，只加读能完成下一步的辅助技能。

| 问题 | 优先入口与边界 |
| --- | --- |
| 独立尾界、滤过下的条件 Bernstein、精确鞅展开 | 分别用 H05、I01、H03。正态尾相对误差用 H01，带前因子的鞍点展开用 H02。 |
| 条件矩界、正多项式证书、有限最优化 | B03 核对矩约束与弱对偶，C03 核对截断矩与 SOS。L03 复验证书，L04 调用求解器，L05 负责有限逻辑编码。 |
| 随机停止或在线选择 | Snell 递推用 E04。在线策略与离线基准用 probability-prophet-online-selection，涉及滤过或鞅时加读 probability-martingale-stopping。 |
| 跳跃补偿、退出结算或冻结坐标 | J01 检查生成元，J04 检查补偿及换序。J05 需要原项目提供私有字段契约。 |
| 随机场的局部尾、成对重叠、增量控制 | 分别核对 K01、K02、K03 的适用条件。K02 的成对重叠若缺一致界，明确指出待证步骤。K04 用于相应的反集中问题。 |
| Carleson 树估计与随机端点 | G05 处理已满足全子树装载条件的嵌入。I04 的有限 laminar 树分支可单独核验，随机 LlogL 端点作为研究问题。 |
| 有限搜索与证书 | L01 核查下界见证，L02 搜索对抗输入，L03 复验严格证书。有限阴性结果只覆盖已搜索的输入。 |
| 凸体极性、体积积、平移覆盖 | 支撑函数和直和体积积用 M02。由有限窗口构造周期覆盖、核对密度定义或传递下界用 N05。面法向量、直积与未极化投影体比值用 N06。 |
| 有限图的割度量 | M05 核对树分解上的局部割律拼接、共同标签下的嵌套割、实 Lp 距离的精确有限维离散化及列表直方图。 |
| 精确半定表示与无穷系数方程 | C01 核对附加变量的双向包含、值域条件与奇异边界。L03 认证有限逆、尾部范数及残差。 |
| 点配置的两体能量 | N07 核对中心窗口密度、Fourier 下界与正混合传递。 |
| 柱面扫掠有限化与凸势方差 | N08 选择冻结方瓦片或径向对齐三角逼近。N09 核对偶次软条带势。N10 用生存率估计凸域的 Dirichlet 条带能量。 |
| 有限前向概率流与确定性均值收益 | E01 用前向访问与反向命中两种矩阵递推。E05 用每条边的势函数差和简单环分解验证路径收益。 |
| 不可压缩 PDE 的局部化 | N11 根据方程选择截断向量势的受迫 Navier–Stokes 模式，或光滑母流上的 Euler 波包模式。 |
| 张量秩、矩阵求值与行列式尺寸 | L06 核对直接和与辅助秩，L07 区分非交换公式的三种矩阵测试，L08 核验简单极方程与系数极限。 |
| 在线度量服务与可逆链 | E06 以最小匹配势将模拟配置转换为惰性服务；谱扰动证书技能分别核对全链混合、可观测量时间平均和已核验转移的能量。 |
