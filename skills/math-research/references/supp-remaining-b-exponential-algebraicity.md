# Scoped reference. Exponential algebraicity and derivation closure

Source: Jonathan Kirby, *Exponential algebraicity in exponential fields*, local arXiv:0810.4285v2 SHA-256 `688733eea8fe38acae72e21fb6011aec0166d8cfd63ac982590993237a127cd1`, physical pp. 1--2 and 11.  The formal version was verified as *Bulletin of the London Mathematical Society* **42** (2010), 879--890, DOI [10.1112/blms/bdq044](https://doi.org/10.1112/blms/bdq044), with the same stated abstract-level results.

For a partial or total characteristic-zero exponential field `F`, the source states `ecl_F=cl_F`, where `cl_F` is closure defined by exponential derivations; this is a pregeometry.  If `C` is `ecl_F`-closed and `x` is finite, then

`delta(x/C)=td(x,exp(x)/C)-ldim_Q(x/C) >= dim_F(x/C)`.

It also gives `dim_F(x)=min_y delta(x,y/ecl_F(empty))`.  Use only after specifying the exponential-field structure, the relevant E-derivations, closure base and finite tuple.  This is a weak Schanuel inequality; it neither proves Schanuel's conjecture for `C_exp` nor licenses replacing `ecl_F(empty)` by the empty set.
