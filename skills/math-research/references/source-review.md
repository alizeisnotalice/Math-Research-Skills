# 现有技能来源核对

本表仅记录本批检查的陈述。辅助计算验证代数或有限实例，原文阅读核对具体定理和适用条件。正式发表版本只记录题录和所用陈述位置。

| 技能 | 论文及定位 | 当前使用范围 |
| --- | --- | --- |
| A01 | [Yang 等，arXiv:2510.16400](https://arxiv.org/abs/2510.16400)，Lemma 3.2、Proposition 3.1、Theorems 4.1–4.5 | 对正分母和非负分子，缩放给出放松与原问题的下确界相等。最优点集合相同需要更强条件。SOS 结论各自有凸性、Slater 或层级条件。 |
| B03 | [van Eekelen，arXiv:2401.00090](https://arxiv.org/abs/2401.00090)，第 8–10 页及第 14 页 | Theorem 1 依赖有界性、事件概率统一下界及矩向量内点条件。一般锥强对偶由外部结果承担。Proposition 1 的尾均值还须保留方差、阈值和不达到条件。 |
| C04 | [Dym，arXiv:2005.13728](https://arxiv.org/abs/2005.13728)，第 6–12、19–20 页 | 光滑立方体问题的 qBnB 下界对应含最优点的盒子，有限精度终止使用间隙模量和分裂规则。 |
| C04 | [Mohammadi–Peet，arXiv:1609.01019](https://arxiv.org/abs/1609.01019)，第 6–8 页 | 有限 SOS 阶数存在性需紧致性、误差与深度条件。论文未给出具体阶数上界，外引 SOS 证明链保持单独依赖。 |
| F03 | [arXiv:2609.30726v1](https://arxiv.org/abs/2609.30726v1)，第 9–11、19 页 | Lemma 2.1 的归一化 Bessel 与 Schatten 对偶针对指定范数范围。Theorem 4.1 限于径向频率局部化 Schrödinger 算子。层平方和最大包络仍需单独搭桥。 |
| G02 | [Fraccaroli，New York J. Math. 32 (2026), 321–348](https://nyjm.albany.edu/j/2026/32-14.html)，Theorem 1.3 | 正式版保留 p>a 与 p≤a 的区别，后一分支按外测度控制剩余 A∖B。 |
| N02 | 本机文献索引 P-8cdc5c07bc1a147e v2、P-e18a11290a5b731f v1 | 前者 Proposition 1.4 是带操作及集合增长假设的转移，Theorem 1.2 有离散非退化条件。后者 Theorems 1.2–1.3 的多输出结论有正支撑和可积性条件。两者的专题结论仅在对应模型内使用。 |
| N03 | 本机文献索引 P-34015312e4b564e0、P-b1a1dc66a1923470 | 前者 Theorem 2.6 有驻点、支撑、Hessian 非退化和导数控制。后者 Theorem 3.1 依赖实解析相位及指定非退化。通用振荡积分任务另选适用的定理。 |
| Boolean Fourier | [arXiv:2609.16401v2](https://arxiv.org/abs/2609.16401v2)，第 8–10 页 | 当前技能证据只支持单调有限字母表、均匀积测度下的编码和 coalition 回映。主迭代及连续 Borel 转移仍待另行核验。 |
| 信息论 | [arXiv:2503.02545v3](https://arxiv.org/abs/2503.02545v3)，Theorem 2、Corollary 3 | 核对了删除与代换计数的转移及顺序小误差的一阶渐近。独立审查尚未完成，保留为相邻方法。 |
| 整数多项式分解 | [arXiv:2607.14409v1](https://arxiv.org/abs/2607.14409v1)，Theorem 4.5 | 固定有序次数、严格正系数、归一化且两两互素下的局部稳定性。含零系数的边界须另证。 |
| 整数多项式分解 | [arXiv:2611.13593v1](https://arxiv.org/abs/2611.13593v1)，Theorem 1.4 | 有限循环群铺砌与给定混合分圆因子条件下的模多项式构造。无绕回普通 PGF 分解需要单独证明。 |
