# M07 · 平面整数电流与高度对偶

用于有限平面图上的 XY 自旋插入、整数 Fourier 电流或离散高度和。先固定嵌入、每条有向边的符号、哪些自旋变量实际积分、外部面是否固定，以及高度图的顶点是面还是对偶胞腔。边界约定改变时，先重新做一次有限电流守恒检查。

令每条未定边的相互作用为 \(e^{b\cos(\theta_x-\theta_y)}\)。Fourier 展开给出整数电流 \(j\)，其边权为 \(I_{j_e}(b)\)。以
\[
 p_b(k)=e^{-b}I_k(b),\qquad
 \sum_{k\in\mathbb Z}p_b(k)e^{tk}=e^{b(\cosh t-1)}
\]
重写时，两个配分函数的公共 \(e^b\) 因子抵消。每条无向边只计一次。

## 有边界的源项与高度

1. 在分母，对每个实际积分的自旋变量作积分，得到 \(\operatorname{div}j=0\)。插入 \(e^{i\sum_x q_x\theta_x}\) 时，得到带符号的 \(\operatorname{div}j=q\)。符号由预先选定的边方向决定，先用一个单源有限例检查。
2. 若边界自旋固定，边界上的变量不被积分。因此总电荷不必为零。给每个源选一条通往该边界的整数路径，取其和为 \(j_0\)，使 \(\operatorname{div}j_0=q\)。所有路径都必须说明端点与方向。
3. \(j-j_0\) 散度为零。旋转到对偶边后，它是闭的整数一形式。在无孔的平面矩形上，沿对偶路径积分得到高度 \(h\in2\pi\mathbb Z\)。有固定外部面时高度由该面确定。若常数没有被固定，只定义到共同 \(2\pi\mathbb Z\) 平移。
4. 固定电流 \(j_0\) 变成高度能量中的积分连接 \(\tau\)。两条源路径的差是无散度电流，因而对应的 \(\tau\) 相差积分梯度。以 \(h\mapsto h-\psi\) 的规范变换重标号高度和，扭曲配分函数不变。

对两个内点源，连接的环流分别为 \(+2\pi,-2\pi\)。对固定边界中心磁化，单个中心源可沿一条路径到边界，故连接只有中心周围的 \(2\pi\) 环流。正性来自 Bessel 权的逐项正性，不能从复相位表示单独推断。

## 有孔图和规范数据

删除包含电荷的面后，\(j-j_0\) 在保留区域仍闭。可收缩闭路的环流为零。围绕一个孔的环流等于孔中总电荷乘 \(2\pi\)。因此扭曲和只依赖指定周期。两个具有同一周期的积分平坦连接相差积分梯度，证明时从一个基点沿路径积分并用闭路周期为零检查路径无关。

绝对钉扎、相对差值和二次观测必须与同一个规范变换一起变换。硬零钉扎要求 \(\psi=0\) 于钉扎集。要求一组高度相等时，\(\psi\) 只需在该组上常值。混用未变换的观测中心会破坏该恒等式。

## 验收与范围

运行 `python3 scripts/check_current_height.py`。脚本在 \(3\times3\) 面的方形网格上以整数算术构造一条内点到边界的源流，加入由面高度旋转而来的零散度流，并逐边恢复该高度差。它验证本技能的有限链复形符号，并不计算 Bessel 配分函数或任何临界量。

本技能只蒸馏有限图对偶。Bessel 权的高斯比较、精度单调性、临界系数 \(8\pi\)、BKT 相变、相关指数和对数修正分别依赖额外的离散高斯比较、尺度极限或 companion 预印本，不能由上述电流—高度对应推出。
