# W12-018 — Pisier–Xu, noncommutative martingale square functions

- **Identity:** Gilles Pisier and Quanhua Xu, *Non-commutative martingale inequalities*, Comm. Math. Phys. 189 (1997), arXiv:math/9704209v1.
- **Read:** Full PDF pp. 1–43, including the main theorem and proof, interpolation/duality arguments, examples, Ito–Clifford application, and H1–BMO appendix.
- **Role:** Foundational auxiliary result for the noncommutative martingale endpoint clues B171/B172.

## Main inequalities (Introduction, PDF pp. 2–3; Theorem 2.1)

For a finite tracial von Neumann algebra with an increasing filtration and an (L_p) martingale (x_n), write (d_n=x_n-x_{n-1}). For (2\le p<\infty), the (L_p) norm of the martingale terminal value is equivalent, with constants depending on (p), to the maximum of the column and row square-function norms:
\[
\|x\|_p\asymp_p\max\left\{\left\|(\sum_n d_n^*d_n)^{1/2}\right\|_p,
\left\|(\sum_n d_nd_n^*)^{1/2}\right\|_p\right\}.
\]
For (1<p<2), the corresponding expression is an infimum over decompositions of the difference sequence into column and row parts. The theorem’s filtration, trace, and (1<p<\infty) assumptions matter.

The authors point out that the square-function definition changes across (p=2). This is an (L_p)-norm equivalence, not a weak-(L_1) Orlicz endpoint statement. It does not establish B171’s single common decomposition controlling every (t>0).
