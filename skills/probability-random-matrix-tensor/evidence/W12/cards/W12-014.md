# W12-014 — Tropp, matrix Freedman inequality

- **Identity:** Joel A. Tropp, *Freedman’s Inequality for Matrix Martingales*, arXiv:1101.3039v1 (2011), 8 pages.
- **Read:** Full PDF pp. 1–8. Theorem 1.2 and the rectangular dilation corollary are on pp. 2–3; the full proof, stopping argument, discussion, and references were also read.
- **Role:** Matrix-martingale concentration reference; auxiliary to W12’s tensor/type and NC-martingale endpoints.

## Theorem 1.2 (PDF pp. 2–3)

Let (Y_k) be a self-adjoint (d\times d) matrix martingale, (X_k=Y_k-Y_{k-1}), and assume (\lambda_{\max}(X_k)\le R) almost surely. Put
\[
W_k=\sum_{j=1}^k\mathbb E_{j-1}X_j^2.
\]
For (t\ge0,\sigma^2>0),
\[
\mathbb P\{\exists k:\lambda_{\max}(Y_k)\ge t,\ \|W_k\|\le\sigma^2\}
\le d\exp\!\left(-\frac{t^2}{2(\sigma^2+Rt/3)}\right).
\]
Only a one-sided increment bound is required for the self-adjoint theorem. The rectangular corollary uses self-adjoint dilation; it assumes (\|X_k\|\le R) and controls both predictable row and column variations, with dimension prefactor (d_1+d_2).

## Proof interface and limits

The proof uses Lieb’s concavity theorem to control the matrix moment-generating function and then a stopping argument. The result is a tail inequality for the spectral norm/largest eigenvalue with bounded increments. It does not give a type-2 estimate for the deterministic tensor family in C120, nor an Orlicz endpoint decomposition for B171.
