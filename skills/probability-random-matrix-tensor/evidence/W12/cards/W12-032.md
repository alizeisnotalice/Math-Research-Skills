## Checked theorem

Theorem 1 as printed in the local PDF (PDF p. 2) claims that if (X=(X_1,\ldots,X_n)) is any centered Gaussian vector, possibly degenerate, then for all positive exponents α(_i>0),
\[
\mathbb E\prod_i|X_i|^{\alpha_i}
\ge\prod_i\mathbb E|X_i|^{\alpha_i}.
\]
If every marginal variance is positive, equality holds iff the coordinates are independent. The proof normalizes positive marginal variances to a correlation matrix. For positive-definite R, it solves one nonlinear stationarity equation on each orthant, uses the principal-minor expansion of det(I+RΛ) to obtain branch weights satisfying Σ_b w_b=1 and Σ_b w_b d_b d_bᵀ=diag(c), then changes variables and applies Jensen to prove an inverse-square kernel bound. A Laplace/Gamma integral recovers all positive absolute moments. Singular R follows by approximation R_ε=(1−ε)R+εI and weak convergence. The strictness argument shows equality iff R=I when all variances are positive; zero-variance coordinates make both sides zero.

The verified v1 asserts a strong scalar-coordinate Gaussian product inequality. Each C205 random variable \(\det(X_{ii})\) is a nonlinear polynomial in the Wishart matrix, not a coordinate of a centered Gaussian vector; C206 is a lower-orthant event probability for those determinants. Thus the scalar-coordinate theorem does not by itself imply either Wishart claim.
