# Python 运算与核验

## 环境

执行器候选顺序：显式 `--python` 或 `MATH_RESEARCH_PYTHON`；否则依次检查工作目录 `.venv/bin/python`、当前 `VIRTUAL_ENV`、执行器自身解释器、用户已有 `~/.venvs/main/bin/python` 和 `~/.venv/bin/python`。这两个用户目录只是候选，不是安装保证。只选择实际能导入 `--require` 指定模块的解释器，报告路径和版本。

`--require` 填入实际导入模块名，如 `numpy`、`scipy`、`sympy`、`mpmath`。涉及项目自定义模块时在脚本中明确路径或包结构；不要为绕过缺失依赖修改全局 Python 配置。

## 精确与近似

- 输入可精确表示时优先整数、`Fraction` 或 `sympy.Rational`。避免先计算浮点 `1/3` 再包装为精确有理数。
- 符号变量声明实数性、正性和定义域；方程解代回并检查分母、分支与约束。`simplify` 的返回形式不说明所需定理假设已经满足。
- 浮点计算检查 `nan/inf`、尺度、病态性和消去；提高数组 dtype 的显示精度不产生新有效位。用高精度库时重新从精确输入构造计算。
- 数值积分/ODE 的误差估计、根残差、优化状态都与具体算法及模型相关；保留警告并检查容差稳定性。`scipy.optimize` 的数值极值不自动成为严格全局界。
- 随机或并行计算记录种子、采样模型、线程/并行设置及统计误差。有限枚举要说明是否穷尽了数学对象，而不只说明循环正常结束。

## 运行记录与内存

执行器先做模块导入预检，成功后才启动用户脚本。每次运行生成独立日志目录：`run.json`、`stdout.txt`、`stderr.txt` 和输入脚本快照。日志根优先显式参数或 `MATH_RESEARCH_RUN_DIR`，再使用 TMPDIR/TMP/TEMP/XDG_CACHE_HOME 指定的位置；本机未配置时使用 `/Volumes/data/CodexTemp/Math-Research-Skills`。data 不可用时不回退系统盘。

超时和取消只终止本次创建的进程组，写明结果可能不完整。普通任务由短命令行子进程执行，计算完自动释放进程内存；大型数组不跨无关任务保留在长期交互会话。读取 stdout/stderr 的实际内容后再解释结果，执行器的成功状态只代表脚本正常退出。
