# Python 数学计算

用本机已有 Python 环境完成计算，保留输入、实际输出与可复现脚本。按计算任务选择标准库或已有数学库；不把未执行代码和预期结果写成运行证据。

## 选择环境与算法

优先当前项目已有环境；否则检查当前解释器及用户已有数学环境。用 `scripts/run_math.py` 可按所需模块检查并选择已有环境，或用 `--python`/`MATH_RESEARCH_PYTHON` 指定。当前默认 `python3` 可能没有数学库，不因另一环境已安装就假定可以导入。找不到合适环境时报告缺失库，先完成可用的计算；额外安装遵循用户当前授权。

| 问题 | 可用工具与核验 |
| --- | --- |
| 精确整数、有理数、组合计数 | `int`、`fractions.Fraction`、`itertools`；核对完整枚举范围和判据 |
| 符号化简、导数、积分、方程 | SymPy；显式定义假设、定义域和分支，代回原式与边界核验 |
| 数组、矩阵与数值线性代数 | NumPy/SciPy；核对维数、dtype、条件数及残差 |
| 积分、ODE、根与数值优化 | SciPy；记录容差、区间/初值/约束和求解状态，改变精度或算法复核关键结果 |
| 高精度浮点 | 已有 mpmath 或 SymPy；从精确值/十进制字符串构造输入，检查精度稳定性 |
| 数据与研究绘图 | 已有数据处理/Matplotlib；图来自实际结果，保留单位、变换和源码；用户指定 MATLAB 图时用 `matlab-plotting` |

数值优化结果先独立代入目标与约束，区分局部解、可行下界、松弛上界与全局证书；算法成功状态不单独证明全局最优。高精度浮点本身不提供定向区间保证。严格数值证明另用 `math-l03-rational-and-interval-certificates`。

## 执行

1. 从实际材料固定公式、变量、假设、输入数据、目标精度和输出。随机实验设置并记录种子；短计算也标明关键范围。
2. 将代码存入用户当前项目的独立 `.py` 文件，重要输入和最终结果留在项目；下载件、stdout/stderr、缓存与可再生产物按当前目录约定放 data 的 CodexTemp。不向技能目录写用户运算文件。
3. 用现有解释器运行；推荐以下执行器，它记录脚本哈希、版本、模块、命令、日志及退出状态，不自动安装库：

```sh
python3 <python-math技能目录>/scripts/run_math.py \
  --require sympy --require numpy --require scipy \
  --workdir /absolute/path/project --timeout 120 \
  /absolute/path/project/calculation.py
```

显式解释器：在脚本路径前加 `--python /path/to/python`；脚本参数放在脚本路径后。需要指定日志位置时加 `--log-root /Volumes/data/CodexTemp/项目名/python-math`。默认逐个检查已有候选环境，所需库必须实际导入成功；显式指定环境失败时不静默换环境。
4. 读取状态文件、stdout 和 stderr，检查警告、非有限数、异常、残差和结果文件。非零退出或超时保留日志并定位问题；任务状态不明时先检查原进程与产物再重跑。
5. 核对结果是否回答了原数学问题，必要时提高精度、更换初值或使用独立工具。完成后让本次 Python 子进程退出，避免后台计算残留；不终止用户其他进程。

脚本依赖、算法选择与验证细节见 [计算与核验](references/computation.md)。`examples/smoke.py` 是工具链检查用演示，不能当作用户课题实验。
