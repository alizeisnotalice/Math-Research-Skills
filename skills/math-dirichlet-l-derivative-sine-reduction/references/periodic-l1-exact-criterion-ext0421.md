# Exact periodic \(L(1,f)\) criterion data

Source. Tapas Chatterjee and M. Ram Murty, *Non-vanishing of Dirichlet
series with periodic coefficients*, arXiv:1405.6982v1, physical pp. 1--5,
Theorem 3.  The local source SHA-256 is
`d987c981596ab038341aac26df6ee6f4df150033383a29ea572eb514f5729565`.

For a rational-valued function \(f\) of period \(q\) with
\(\sum_{a=1}^q f(a)=0\), Theorem 3 identifies \(L(1,f)=0\) with two
conditions.  Let \(M(q)\) be the monoid generated by the prime divisors of
\(q\).  For every unit \(a\pmod q\), it requires
\[
 \sum_{b\in M(q)}\frac{f(ab)}b=0,
\]
and it requires
\[
 \sum_{b\in M(q)}\frac{(f_b,\chi_0)}b\log b=0,
 \qquad f_b(a)=f(ab),
\]
where the inner product is over units modulo \(q\).

The checker represents multiplication by every prime \(p\mid q\) by the
finite operator \(T_p f(a)=f(ap)\) on residue classes.  It evaluates the
first sums by \(\prod_{p\mid q}(I-T_p/p)^{-1}f\).  The coefficient of
\(\log p\) in the second condition is evaluated with one additional
resolvent \((I-T_p/p)^{-1}(T_p/p)\).  All matrix operations use rational
arithmetic.  Rational linear independence of the logarithms of distinct
primes reduces the second condition to the vanishing of each displayed
coefficient.

This is an exact checker for the finite input to Theorem 3.  It has no
claim about non-rational coefficients, values at other points, numerical
evaluation of \(L(1,f)\), or a new proof of the source theorem.

Run the two fixtures with

~~~sh
python3 scripts/periodic_l1_criterion.py examples/periodic-l1-q3-nonzero.json
python3 scripts/periodic_l1_criterion.py examples/periodic-l1-q4-zero.json
~~~
