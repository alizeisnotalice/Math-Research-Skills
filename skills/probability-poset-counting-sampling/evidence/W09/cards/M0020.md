# M0020: Entropic Uniform Sampling of Linear Extensions in Series-Parallel Posets

Reader: W09. Reading status: fulltext_read.

Authors: Olivier Bodini, Matthieu Dien, Antoine Genitrini, Frédéric Peschanski; 2017.

Evidence: complete 19-page article read; the representative argument and sampling algorithms were rechecked against PDF pp. 5–12.

## Exact uniformity claims

The input is a series-parallel poset supplied through the paper's recursive series-parallel decomposition / associated SP DAG. Theorem 3 (PDF p. 6) defines an equivalence relation on topological sorts: two sorts are equivalent when deleting all auxiliary white nodes yields the same linear extension of the original poset. The representative is the sort placing white nodes as early as possible, with the specified leftmost tie rule for consecutive incomparable white nodes. There is exactly one representative for each linear extension, so a *uniform choice among representatives*, followed by deleting white nodes, is uniform on linear extensions. A uniform topological sort of the SP DAG followed by deletion is generally biased because the equivalence classes have unequal sizes.

Theorem 4 (PDF p. 9) proves that both recursive algorithms in the paper sample a uniform linear extension: Algorithm 1 constructs the extension bottom-up by recursively sampling each subposet and uniformly shuffling the child extensions; Algorithm 2 is the top-down dual, uniformly splitting available output positions between the two subposets. At each parallel composition, the interleaving must be chosen uniformly among the $\binom{p+q}{p}$ binary patterns with $p$ positions assigned to one child and $q$ to the other. The paper reports worst-case $\Theta(n^2)$ time when measured by memory writes.

## Random-bit accounting

Uniform shuffling/splitting uses `RandomCombination(p,q)` (Algorithms 3–4, PDF pp. 8–10). Theorem 5 states that this procedure samples each length-$p+q$ Boolean string with exactly $p$ true and $q$ false entries with equal probability, while using an entropic number of random bits in the paper's probabilistic Turing-machine model. Its proof handles both the sequential biased-Bernoulli stage (discard the first excess draw) and uniform insertion of the remaining symbols; a separate $k$-Bernoulli routine handles skewed Bernoulli parameters. The exact distribution and random-bit cost are distinct guarantees: exact uniformity does not follow merely from choosing each currently available poset element with equal probability.

## Transfer limit

This gives exact uniform sampling of all linear extensions for series-parallel posets. A finite square labeling with an exact-two-peak condition is a conditioned subset of extensions and need not have a series-parallel poset representation. Neither the uniform sampler nor its entropic bit bound automatically samples that conditioned subset; an exact conditioning/rejection or recursive decomposition argument with its own correctness and cost bound is required.

## Revision response (R05)

Clarified that Theorem 3 samples uniformly from one canonical representative per equivalence class; it does not sample a uniform topological sort and then strip white nodes. Stated Theorem 4's actual bottom-up/top-down algorithms, the required uniform interleaving patterns, input class, and worst-case complexity metric. Added Theorem 5's separate uniform-combination and entropy guarantees and their random-bit model. Explicitly withheld transfer to peak-conditioned square labelings.
