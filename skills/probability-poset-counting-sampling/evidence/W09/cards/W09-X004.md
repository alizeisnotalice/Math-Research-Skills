## Main results: two different graph parameters

Theorem 1 (PDF pp. 7–17; journal pp. 1663–1673) states that counting linear extensions (#LE) parameterized by the treewidth of the cover graph does not admit an FPT algorithm unless W[1]=FPT. This is a parameterized intractability result; it does **not** prove #P-hardness for posets whose cover-graph treewidth is bounded by a fixed constant. The paper notes an XP algorithm for that parameter.

Theorem 2 (statement PDF p. 17; proof ends pp. 23–25) proves that #LE is FPT parameterized by the treewidth of the incomparability graph. The cover graph and incomparability graph are distinct representations, so these conclusions cannot be interchanged.

## Theorem 1: equitable-coloring reduction

The source problem is Equitable Coloring[tw], parameterized by tw(G)+r and W[1]-hard. The reduction may assume |V(G)| is divisible by r, using the stated padding construction (PDF pp. 6–7). It first builds P(G,r), with

\[
|P(G,r)|=2(r-1)|V(G)|+(r^2-1)|E(G)|.
\]

For each sufficiently large prime p, it builds P(G,r,p), using r+3 anchor levels, p-1 element sticks, and (a,b)-flower gadgets (PDF pp. 9–15). Lemma 2 (PDF p. 8) supplies the modular filter: if one connected component has p-1 elements and the total extension count is nonzero modulo p, every other connected component has size divisible by p. The flower construction uses this fact to cancel, modulo p, configurations that do not put exactly b of a flower's a petals on its designated level. The surviving configurations encode proper equitable r-colorings; each contributing configuration has the same residual-poset extension count.

Claims 5–6 (PDF pp. 15–16) yield

\[
e(P(G,r,p))\equiv c_p\,e(P(G,r))\,\#EC(G,r)\pmod p,
\qquad c_p\not\equiv0\pmod p.
\]

Writing N=2r|V(G)|+r^2|E(G)|, the reduction searches primes N<p<N^2. If there is an equitable coloring, Claim 6 ensures that some prime in this polynomial range does not divide e(P(G,r))#EC(G,r), so the corresponding oracle answer is nonzero modulo p; if there is no coloring, every such residue is zero. Claim 7 (PDF pp. 16–17) bounds the constructed cover-graph treewidth by

\[
\operatorname{tw}(C(P(G,r,p)))\le r\bigl(\operatorname{tw}(G)+3\bigr)+6.
\]

Thus the number and parameter of oracle queries are bounded by a computable function of the source parameter times a polynomial in the input size. The FPT Turing reduction proves W[1]-hardness of parameterized #LE for cover-graph treewidth, hence the stated no-FPT consequence unless W[1]=FPT. It does not establish #P-hardness on any fixed-treewidth slice.

## Theorem 2: incomparability-graph decomposition and MSO counting

Let k=tw(I(P)). Fact 5 and Corollary 1 (PDF p. 6) give a width-k path-decomposition of the incomparability graph. Lemmas 3–5 (PDF pp. 18–21) normalize it into a blocked tree-decomposition: deleting a bag totally orders the remaining incomparability components, and the blocks are arranged so cover edges can be controlled. Cover-guards added to bags have size at most 2k+2 (Lemma 6, PDF pp. 21–22); Lemmas 7–8 then yield

\[
\operatorname{tw}(I_C(P))\le 3k+2
\]

(Corollary 2, PDF p. 23), where I_C(P) is the combined cover-incomparability graph.

For the counting step, orient each incomparability edge arbitrarily and label it as incomparable. A linear extension determines the subset E of such edges whose directions disagree with the extension; reversing E gives an acyclic digraph. Conversely, any subset E whose reversal leaves the graph acyclic has a topological order, which is a linear extension, and recovers E uniquely. This is the bijection in Claim 10 (PDF pp. 23–24). An MSO formula tests that the selected incomparable edges contain no directed cycle; the bounded-treewidth MSO counting theorem counts those subsets. This proves #LE is FPT in the treewidth of the combined graph (Lemma 9), and the combined-graph bound transfers it to incomparability-treewidth (Theorem 2, PDF pp. 23–25).

## Transfer limit

The results concern exact #LE for a single fixed poset. They distinguish an XP algorithm from W[1]-based evidence against FPT for cover-treewidth, and give FPT for incomparability-treewidth. They do not identify a bounded-treewidth poset decomposition for the free-boundary square exact-two-peak event; that event is not itself the linear-extension set of one fixed poset.
