# M0017: Optimizing Linear Extensions

Reader: W09. Reading status: fulltext_read.

Authors: Bridget Eileen Tenner; year: 2009.

Evidence location: PDF pp. 1–5.

## Result and location
Proposition 3.1 gives λ(n)≤⌊n/d⌋+d for the minimum number of poset elements needed to have exactly n linear extensions. Theorem 3.2 optimizes this construction and Corollary 4.1 gives a refinement under a factor condition (PDF pp. 1–5).

## Proof chain and assumptions
Build a family of posets Q_{i,j,m} whose extension counts are explicit products/binomial combinations; choose parameters i,j near √n and control the remainder with the recurrence for λ. This is an extremal-size result, not an algorithm for the actual extensions.

## Use and transfer limit
Useful for understanding the range of e(P) and for lower-bound constructions. It does not count peak-conditioned square labelings.
