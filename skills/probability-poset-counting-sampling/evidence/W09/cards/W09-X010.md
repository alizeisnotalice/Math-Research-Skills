# W09-X010: Generating uniform linear extensions using few random bits

Reader: W09. Reading status: fulltext_read.

Author: Mark Huber; 2025 preprint, arXiv:2506.14725v1.

Evidence: complete 16-page preprint read; deterministic-scan, CFTP, and complexity proofs checked against PDF pp. 2–10.

## Exact sampling guarantee

For any fixed finite $n$-element poset, first relabel so the identity is a linear extension. In the deterministic-scan version, each sweep visits positions $i=1,\ldots,n-1$ from left to right and uses a fresh fair bit $c$ at every position: swap the adjacent items exactly when $c=1$ and $\neg(\sigma(i)\preceq\sigma(i+1))$; otherwise hold. Thus an incomparable adjacent pair swaps with probability $1/2$, while a comparable pair does not swap. The paper first describes the random-scan Gibbs chain and its fair-coin update (PDF p. 3), then states that the fixed left-to-right scan with a new coin per position still preserves the uniform law (PDF p. 6). A bounding chain tracks active items and wildcard positions; the simultaneous update complements the coin precisely when $\sigma(i)=r(i+1)$, and Theorem 2 proves the bound is preserved (PDF pp. 4–6). The deterministic-scan CFTP construction and its reuse of past updates are given on PDF pp. 6–7; Section 3 bounds wildcard extinction and the resulting coalescence tail on PDF pp. 7–10. The sampler therefore returns an exactly uniform linear extension and terminates almost surely.

Theorem 1 (PDF p. 2) bounds the expected work by

\[
n(n^2-n+3)\lceil\log_2 n\rceil \le 2.75n^3\ln n
\]

operations and the expected number of i.i.d. fair bits by $1.83n^3\ln n$. Here $n$ is the number of elements of the input poset; the theorem is stated for an arbitrary finite poset. An operation evaluates one poset comparison for the adjacent pair and may swap it; each scan position uses at most one fresh fair bit. The operation and bit bounds are expectations for the CFTP algorithm, not worst-case running-time bounds; the implementation doubles the past horizon after a failed coalescence check. Section 3 bounds extinction of wildcards under deterministic scans and then uses a union bound over the wildcard symbols (PDF pp. 7–10).

## Transfer limit

This is exact uniform sampling from all linear extensions of a fixed poset. It neither counts extensions nor samples after conditioning on a peak-set event. In particular, no runtime bound for an exact-two-peak square labeling follows from this sampler without a separate state-space construction and conditioning analysis.

## Revision response (R05)

Corrected the base-chain update: every adjacent position uses a fresh fair coin, and a swap occurs only when the pair is incomparable and the coin is 1; legality alone does not force a swap. Distinguished the random-scan chain (PDF p. 3) from the deterministic left-to-right scan (PDF p. 6), located the bounding-chain invariant proof (Theorem 2, PDF pp. 4–6), and added the CFTP/coalescence construction and Section 3 wildcard-extinction analysis locators (PDF pp. 6–10). Stated the input size parameter and kept Theorem 1's operation/bit guarantees as expected bounds, not worst-case runtime. The result remains limited to unconditional uniform linear extensions.
