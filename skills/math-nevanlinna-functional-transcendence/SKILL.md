# Nevanlinna 增长分离与函数域超越次数

先固定定义域 \(\mathbb C^m\)、非恒定整函数 \(f_1,\dots,f_n\) 与超越亚纯函数 \(F:\mathbb C\to\widehat{\mathbb C}\)。提供每个 \(T(r,f_i)\) 的实际增长界和测度有限的异常集，再逐项比较 \(T(r,f_i)=o(T(r,f_{i+1}))\)。

满足所引用条件时，函数域 \(\mathbb C(f_1,\ldots,f_n,F(f_1),\ldots,F(f_n))\) 的超越次数至少 \(n+1\)。对于一元、所有 \(f_i\) 为有限阶超越整函数且 \(F\) 为正阶超越整函数的分支，原文给出 \(2n\)。数值采样和截断 Taylor 系数适合核对模型数据，函数增长条件由解析估计给出。特定点取值需其自身的算术定理。
