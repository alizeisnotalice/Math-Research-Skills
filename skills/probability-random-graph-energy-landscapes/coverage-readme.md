# Reading coverage

`reading_coverage.json` records one full physical-PDF read for each of the 31 source records. It preserves the original section/appendix summaries, page ranges, and rendered-page evidence; its file paths have been rebound to `sources/` inside this package. Every cited PDF and every listed rendered image is included locally.

The coverage records describe actual reading evidence accepted by R05. A complete page range does not imply that every theorem in a source is valid outside its own stated hypotheses; consult the card for the proof scope and source-level caveats. PGEL-040 is the complete 26-page contribution, not a complete read of the edited volume.
