# E-function exceptional-value admission

Source. Boris Adamczewski and Tanguy Rivoal, *Exceptional values of E-functions at algebraic points*, arXiv:1708.00217v1, local SHA-256 `a7bf883915d2718a8c909374218b493648d892a460656703d97262d225e7239c`, physical pp. 1--4 and 9.

The source defines its effective input as an explicitly supplied annihilating differential operator, enough initial Taylor data to specify the solution, and an oracle certificate that the function is an E-function. Under that input contract, its four-step procedure first obtains minimal homogeneous and inhomogeneous equations. Every nonzero exceptional algebraic point is then among the roots of the leading polynomial \(u_0\) of the minimal inhomogeneous equation. The final test uses the André--Beukers polynomial gauge matrix \(M(z)\) and the cokernel condition in (5.3).

Use this as an admission and routing gate for a supplied E-function. It does not infer that the Euler--Mascheroni constant is an E-value, give an E-function representation of \(\gamma\), or implement the source's E-function oracle and gauge transformation. Those objects must be supplied and independently certified before its exceptional-value conclusion can enter a linear-form argument.
