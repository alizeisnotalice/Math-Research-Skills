# Lucas-congruence function-independence boundary

Source: Adamczewski, Bell and Delaygue, `arXiv:1603.04187v1`; local SHA-256
`345b05351dd3d0d474379d31655673b5b8db0518ff101753e72b5fe9942265f6`.

Theorem 4.1 (physical pp. 4, 13--14) says algebraic dependence in the stated
Lucas class forces a nontrivial Laurent monomial in the functions to be
rational. Its proof needs localisation and Frobenius/Lucas congruences at an
infinite prime set; the analytic applications on pp. 17--23 rule out the
monomial relation in selected families. It is function-level only: special
values need a separate specialization theorem.
