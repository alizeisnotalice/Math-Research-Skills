# Random-subspace trace reference

Scoped reference. The regular-trace smoothing construction uses the draft's partial-deck smoothing, noncommuting row/column symmetries, random-subspace overlap tests, multiplicity weights and induction. Input must retain that representation model and test family; output is the stated trace-smoothing estimate, not an ordinary normal-operator bound.
