# Four-row permanent tensor interface

For independent coordinates whose laws each satisfy the same strict `p0` four-row permanent inequality with uniform marginals, use the source's tensorized bound for a declared product of four nonnegative functions. Require the supplied `p0` and strictness margin; this is not a standalone permutation-moment conclusion.
