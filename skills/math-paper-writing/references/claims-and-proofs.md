# 定理、量词与证明的编辑

这是写作中的数学一致性检查，不默认开展一轮新研究或重新认证整个项目。

## 一份定理要让读者知道什么

检查对象、允许输入、参数域、量词顺序、所证结论、常数依赖、边界情况和引用版本。可用内部简表记录主张与依据；论文中保留正常数学陈述。

特别注意下列容易改变结论的区别：

|区别|写作时必须保留的信息|
|---|---|
|固定测度 / 测度族上确界|结论在哪个测度下成立；族上的最优值是否由某个测度达到|
|中心 / 非中心、方体 / 矩形或球|见证几何与共同半径；同一个集合能否同时见证所有输入|
|固定维数 / 维数一致|常数是否依赖 n；有限 n 的计算不推出所有 n 的阶|
|逐参数 / 参数一致|起效阈值和 O、o 的常数依赖；固定阶矩不能任意代入增长阶数|
|子序列 / 全部整数|构造在哪些维数或长度存在；补齐其余索引需要证明|
|下包络 / 真正渐近式|liminf、limsup、极限存在和匹配上下界分别成立到哪一步|
|上/下界 / 精确值|两侧是否针对同一问题；等号是否可达或只能逼近|
|模型 / 原问题|松弛、局部化、正项放大或充分条件与原目标的比较方向|
|内禀权 / 外层权|平均、阈值、水平集和归一化分别使用哪种测度|

不能为了“行文流畅”把“对每个固定参数”改成“对所有参数一致”，把最终阈值改成显式阈值，或把 limsup 改成极限。

## 证明依赖

给关键引理标明其作用和实际输入：哪个定义、哪个域、哪种范数/测度、常数如何进入主估计。把“已证明新引理”与“已把新引理接回主定理”分开判断。把余项重新命名为待控能量、覆盖值或来源矩，只完成了归约。

主证明按依赖组织，检查循环：不能先用主定理建立关键性质，再把该性质作为主定理的独立证明。方法关系图中的反馈边不等于可循环使用的数学蕴含。

对于已知结论，写“采用文献 X 的定理 Y，在 H 条件下得到 Z”。改变核、权、滤过、端点或范数后，原结论不自动继承；写出新增条件与需要证明的改动。

## 分析证明的具体检查

- **可积性与换序**：非负项可用 Tonelli；有符号项说明绝对可积、支配、一致可积或共同有限截断等实际依据。齐次性本身不保证可积。不要在奇异集上写未定义的无穷量相减。
- **上确界与零集**：逐个参数的几乎处处结论，不自动给不可数上确界的共同零集。可用可数稠密参数与适当连续性，或证明合法的可测选择。
- **逼近传递**：原子、周期、紧支、有界输入推广至一般 L¹，需控制截断、平滑、质量与严格水平余量。选择构造参数与取极限的先后顺序应能复核。
- **全域与端点**：局部盒、固定尺度、正时间核或有限森林只覆盖其定义范围。短时、长时、奇异邻域、补集和终端项须在最终证明有归属。
- **符号与归一化**：核/生成元的正负号，Fourier 指数和逆变换常数，Jacobian、未单位化方向及时间尺度均需一致。不能把物理导数、对数导数和归一化变量导数混同。
- **非负上包**：实际余项可以有符号；存在非负上包不等于实际余项非负。取绝对值可能破坏抵消或改变可积性，须说明所得估计仍足够。

## 概率与随机过程

写明概率空间、滤过、条件化与倾斜测度；条件矩假设不能用无条件矩替代。停止时间是否有界、可选停止条件、补偿被积函数的可预测性、杀死后的质量和退出边界必须适合所用结论。

独立坐标/乘积参考模型的结论不能直接用于依赖来源和共同历史。若参数或选择器依赖未来信息，检查是否改变非前视条件或引入额外选择代价。

固定阶矩或中心极限定理描述典型概率，不自动排除指数稀少的极端输入；增长阈值、三角阵与相对尾误差需要对应的一致版本。下界构造与对所有输入的上界具有不同量词。

## 优化与全局闭合

固定是极小化还是极大化，再检查松弛、原可行点和对偶证书给哪一方向的界。松弛可行点通常不能回构为原输入；须额外证明可实现性。有限模型的最优解不能直接命名为原问题的最优解。

写参数选择时保留全部前因子与约束，最后才优化。局部省下的一个因子可能被核尾、选取参数或来源重用抵消。每层有界不等于全层有界；需可和权、质量分配、几何衰减或望远镜结构。

例如若得到
\[
X\le A(n)M+\theta X+R(n)M,\qquad X,M\ge0,
\]
闭合需要 \(1-\theta>0\)，最终为
\(X\le[A(n)+R(n)]M/(1-\theta)\)。若 \(\theta\) 依赖 n，还须保留吸收余量的维数价格。保留有符号补偿时，各项须位于同一合法测度和区域，同一负项不能在每个子分支重复扣除。

## 发现问题后的改稿方式

能够修正的记号、条件遗漏和准确引用直接修正并说明；尚无证明的主张降到有依据的范围，或明确列出缺失命题供作者处理。不要凭熟悉的标准公式静默替换作者有争议的公式。若只是核查问题，给出位置、原因和所需补充条件，避免直接重写整篇。

“数值支持”“原作者陈述”“本次检查了某步骤”“完整证明成立”分别表述。重要限制放在定理或首次相关位置，不要只藏在末尾；也不在摘要、引言和结尾反复罗列与主张无关的未完成事项。
