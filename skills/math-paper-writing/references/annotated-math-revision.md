# 从批注到双语数学定稿

本页取材于中心立方体极大算子论文的几轮修订。文中的符号、系数和章节安排属于该稿。迁移到其他论文时，沿用判断依据，重新核对具体数值和作者要求。

## 几轮修改分别解决了什么

| 修改过程 | 暴露的问题 | 下次改稿时的动作 |
|---|---|---|
| 从中英文 PDF 重建源码，整理结构和篇幅 | 初稿的主证明、原创引理和后加应用承担不同任务。只看页数容易误删证明 | 先圈定主定理的依赖，再删已明确取消的应用、预告和专用记号。保留原稿作对照 |
| 精简措辞后，作者指出 RS 序列的引入原因又被删了 | 一个段落可以同时含有冗余评价和不可缺的构造理由 | 把作者要求保留的理由定位到首次定义之前，逐句删冗语。下轮验收时重读这段 |
| 按手写批注修改，补入三页手写推导 | 划线删除、圈出替换、箭头移位和插页补证要求的是不同操作 | 对照批注所在的原版本辨认每一笔的对象，再在最新稿中定位同一句或同一步 |
| 作者再次要求严格遵照措辞、化简阈值、直接代入固定数值 | 上一版换了说法却保留了被划掉的引言段落；取消部分参数后仍集中定义了三个固定系数 | 把“段落是否消失”“原符号是否退出所有公式”“新证明是否已足够推出后文结论”分别查实 |

## 一、把批注转换为具体编辑

多版本稿先建立一份简短工作记录。每项写下“原句或公式 → 批注动作 → 落点 → 验收办法”。用段首或数学对象定位，避免重排后页码失效。例如，批注附件共 26 页，其中 3 页是插入的推导，比较篇幅的基线是 23 页论文。手写批注已压平时，逐页看渲染图；文本提取只能帮助定位印刷正文。

“删”作用到标明的文字或段落。整段被划去，就检查是否仍以同义表述保留。“用这个”结合箭头判断替换范围，保留作者指定的段落。“放证明里”要求把定义移到证明首次需要处，并重读定理陈述能否独立理解。“过程参考这个”要求恢复手写稿中的推导步骤，其中的数学操作还需逐步核实。尚未确认的术语或参数单独记录，等待有依据的解释。

## 二、压缩时追踪每句话的数学用途

本稿的 RS 动机包含两条相关的理由。频带长度随维数舍入，因而需要任意长度前缀在整个单位圆上的统一平方根界；只说明二进长度的递推性质，读者还不知道为何能选所需频带。区间平均带来频率分母，线性权重将它消去，使协方差出现可估计的 Dirichlet 型核；加权后还要保持密度为正，这一步由 Abel 求和把带权和归结为前缀和。按这个顺序写，读者在看到递推前已知道要从序列取得什么。

精简时可删重复预告和泛泛的优点评价。保留“哪一步产生困难、哪项性质解决困难”的因果句。不同位置各有任务：引言说明为何引入权重，预备知识在递推前交代所需的前缀性质，证明给出具体估计。作者已经点名要恢复的理由，列入下一轮复查项。

## 三、固定系数沿证明依赖逐处代入

先辨认数值用途。已取定的窗口比例、分界点可直接代入；后续需选择的网格间距参数仍须交代何时固定；局部引理若承诺对一族输入一致，保留表示输入依赖的符号。

本稿取窗口比例 1/100。窗口半径随之写为 K/(100u)，网格端点为 ⌊K/(100a)⌋，点对距离上界成为 K/(50u)。1/8 和 32 直接作为相邻区域的分界点，核对等号属于哪一区。再沿“网格点数 → 单点概率之和 → 并集测度 → 主定理常数”追到末式。对固定振幅 1/36，则沿“密度 → 平均 → 方差 → 标准差”核对，方差中的系数要平方。文字、下标、公式回引和源码说明中的旧定义也要检查。用本机有理数运算核对常数后，仍需人工确认替换对象，例如临界值 T 与环面符号的区别。

## 四、用后文需要的精度决定阈值

先找出下游真正使用的误差。本稿需要比较指数尾概率，所以单有 u²/log n → 1 还不够。由 |δₙ|≤2、Aₙ→∞ 和 u²=(log n)(1+δₙ/Aₙ)⁻²，在零点展开得到 |u²−log n|=O(log n/Aₙ)。代入 Aₙ 的量级得到 O((log n)³ᐟ²/√n)=o(1)，故 √n exp(−u²/2)→1。这条链给出了实际需要的加性误差，可以删去原来分别估计舍入两端点的最大值。

若需要在固定区间上让核误差小于一个固定正间隙，先说明收敛在该区间上一致，再选择足够大的 K。若区间随 K 扩张，回到误差界，检查区间长度如何进入估计。将数个条件合为“对充分大的 n”之前，逐项证明相应极限，写明先固定哪些参数，并核查常数对网格点或分布是否一致。四个距离区域用到不同概率界，因此应保留分区及各自的求和理由。中偏差引理本身承诺显式常数和适用范围，继续保留其阈值及证明。

## 五、在关键估计处补足被压缩的步骤

- **标准工具与原创步骤。** 引用任意前缀界时，核对文献的递推初值、前缀长度和相位范围。Bernstein 不等式写出实际使用的版本。引用完成后，本文怎样带入权重、估计协方差、合并误差仍需在正文证明。
- **连续核估计。** 按插页把积分区间分为 K 段。每段先用微积分基本定理估计复指数的差，再积分得到 O(H/K²)，求和得到 O(H/K)。随后取实部并在所需范围取上确界。这保留了批注要求的过程，也避免把实值函数的拉格朗日中值公式直接用于复值函数。
- **换测度与端点。** 先写清单变量及乘积空间上的密度。反向换测度时，在首区间上对事件积分得下界，将尾事件分解为互不相交的半开区间，在各段估计指数因子并求几何级数得上界。含原子的分布要核对端点归属。Berry–Esseen 的分布函数误差可结合正态分布连续性处理左右极限，由此直接得到区间概率界，省去反复引入分布函数记号。
- **结论强度。** 保留尾概率两侧的率函数余项、显式常数及适用范围。有限网格抽查可以发现漏平方、符号或端点错误；一致性来自正文的估计和量词。

## 六、逐项验收成稿

对指定删除的内容，检索原句后再读整段，确认同义改写也已删除。对指定保留的内容，在两版 PDF 中找到对应位置，读定义前后各一段。对常数改写，从定义抽查到最后一次使用，用本机数学工具重算受影响的系数。对证明移位，检查定义先于使用、陈述能独立理解，以及严格式与非严格式的端点。

双语共用数学源码可减少公式漂移，两个语言分支的连接词、定理措辞和删句仍需分别审读。以实际编译日志检查缺字、越界和未定义引用，再看最终页上的长公式、分页和孤立标题。源码包内的入口、说明、核验结果及页数对应当前交付版本。交稿时说明改了哪些数学表达，给出修订前后页数；如手写推导经数学修正，指出改用的依据。
