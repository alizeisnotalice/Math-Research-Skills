# 数学论文写作

把已有数学研究组织为读者可以理解、追溯和检查的论文。以数学依赖决定结构，以实际证明决定结论强度，以具体困难解释方法选择。默认中文；用户或目标稿件指定英文时沿用其语言。保留公式、术语、引文和作者的实质观点。

本技能以用户提供的六页 [写作规范 PDF](references/local-assets.md#asset-e4e986445439) 为写作标准。T 项目数学材料和 GitHub 项目仅提供辅助经验；与 PDF 有冲突时遵循 PDF。用户后续明确提出的修改要求优先。来源与阅读范围见 [sources.md](references/sources.md)。项目材料不能直接充当未来论文的已证前提。

## 先落实 PDF 的明确要求

- **整篇结构**：引言 → 预备知识 → 主要证明 → 应用。核心证明单独成章；多个独立主结果可分章；应用是最后的实质章节。除非用户明确另作要求，不因 GitHub 模板、旧稿安排或一般期刊习惯自行改变。
- **引言次序**：背景与对象 → 直接相关成果 → 具体问题 → 核心引理与主定理 → 意义及方法创新 → 全文安排。技术定义较多时，先交代核心引理的内容和用途，完整形式放后文。
- **定理编号**：前人成果用 A、B、C；本文结果用 1、2、3 或章节数字编号，统一全文及交叉引用。
- **引理和工具**：标准结果写所用版本、条件和出处，无须重证；原创引理完整证明；修改标准结果时证明修改部分。工具须交代来源、所需性质及它进入证明的具体位置。
- **应用**：保留独立“应用”章，先给确能推出的结论及理由。暂缺实际应用时，写与经典问题的具体关联及尚需补充的论证，不以空泛前景凑章，也不自行省略或改名。
- **改稿次序**：先列章节并写各章任务，再归位现有段落，然后补方法动机，最后修改语言和材料位置。只要求局部修改时在授权范围内执行，并简短指出涉及的结构问题。

## 按批注修订数学论文

遇到多轮导师批注、作者指出漏改或要求化简阈值时，读[批注修订案例与验收方法](references/annotated-math-revision.md)。其中按本稿的实际改动说明删段、保留构造动机、直接代入、渐近误差和双语验收。

- **先核对批注指向的版本。** 将手写增删、箭头、圈选和插页推导定位到原句或原公式，再与当前稿逐项比较。批注页码可能包含插页，优先用段首、公式内容或引理定位。区分指定替换、明确删除、参考写法和作者尚未确认的疑问。
- **照实落实文字删改。** 指定术语和替换句沿用作者措辞；划去整段就检查其内容是否又以改写形式出现在同处或别处。移动定义时同时核对首次使用位置。用户明确删去应用章时，连同预告和专用记号一并清理，主证明结束后直接进入参考文献。
- **保留作者指定的方法动机。** 压缩技术背景时，核对读者在首次看到定义前能否明白“这里需要什么性质、它解决哪一步困难”。例如，RS 符号的任意前缀界允许频带长度随维数舍入；线性权重消去平均公式中的频率分母，Abel 求和再用前缀界控制带权和，从而保持密度为正。若删去递推后的重复说明，保留定义前这条理由链。
- **固定数值直接代入。** 对已取定、后文也不再调节的简单系数，直接写入窗口、分区端点、误差和最终常数，约分后检查乘除顺序、指数与界方向。例如窗口系数取 1/100 时写成 K/(100u)，分区点取 1/8 和 32 时直接写端点。需要选择、优化或体现一致依赖的参数保留符号。
- **按结论选择阈值精度。** 若只要求对充分大的 n 成立，先固定其他参数，再列出真正用到的极限、收敛速度和一致范围。例如舍入给出 K=A_n+O(1)，在 A_n 趋于无穷时可直接展开相对误差；若误差还要乘以 log n，须证明乘积趋零。紧区间上的一致收敛可统一选取门槛。若定理承诺显式常数、有限范围或用户指定保留某引理的完整证明，则保留相应数值、条件与推导。
- **让删节服从证明依赖。** 标准工具给出实际使用的版本和出处；批注要求展开的推导写出关键中间步。换测度可直接按事件积分，分割时核对端点上的原子。手写推导若有数学疑点，保留其目标，改用成立的论证并向作者说明。只给后文确实回引的公式编号，删号后可引用引理本身。
- **双语稿分别验收。** 对照两版核查同一删句、术语、方法动机、固定系数、量词和公式编号。最终在编译出的 PDF 中定位批注涉及的段落，核对修改后的上下文和分页。修订前后页数按论文页计，单列批注附件插页。

## 开始时确定数学对象

从当前请求、稿件和已有材料识别研究问题、拟交付章节、语言、读者、目标期刊或导师要求。已有信息足够时直接工作；只询问会改变主结论或主要结构的缺项。

对于整篇或实质性改稿，先用简短笔记固定：

1. **对象**：空间、测度、算子、输入类、几何族、归一化及严格/非严格水平集。
2. **结果**：主定理及关键假设；这是上界、下界、等式、存在性、渐近阶、模型结论还是条件性命题。
3. **依据**：所用文献版本、作者提供的证明、原始结果文件及待解决缺口。
4. **结构**：每章的任务、关键引理的用途和主定理的依赖。

短段润色不强制生成这些表格。复杂多版本稿件可另存写作笔记，避免把核查标签、文件哈希和内部状态插入论文。

## 写作流程

### 先组织结果与证明

梳理“问题 → 已有结果及不足 → 本文定理 → 核心困难 → 所用性质 → 证明 → 后果”。围绕能完成主结论的一条清楚路线组织正文；失败路线或作用重复的方案只在确有解释价值时保留。

按上列 PDF 要求安排整篇及引言次序。若目标期刊另有强制格式，先说明具体冲突，尽量在保留四部分功能、独立应用章和既定编号的前提下兼容；用户没有明确改用另一套规范时，不擅自将 PDF 要求降为可选建议。局部改稿不擅自重排整篇。

### 再写方法动机与证明

引入重要工具时写清：构造需要什么性质，该工具为何提供它，采用哪个版本和出处，该性质进入哪一步估计。定义之外简述工具的常见用途，并说明所需性质为什么适合当前构造。方法来源和本文适配分别说明。标准结果写明所用形式、条件与出处；原创引理给出完整证明；标准结果的改动部分也需证明。

先说明一段证明的目标，再给实现目标的公式与理由。长估计保留关键常数来源、换序依据和闭合步骤。未知步骤用准确的待证命题记录；可以写已完成部分，不把缺口用“显然”“类似可得”遮住。

### 最后修改表达与核对全文

用具体结论和数学理由替换空泛评价；合并重复的边界说明。数学上必要的假设、反例和限制仍需在首次相关处说清。摘要、引言和主定理可有层次地重复核心结果，避免复制同一大段论证。

按稿件规模检查：定义与符号、量词及常数依赖、引理到定理的连接、应用是否确实推出、正文与证书/图表/引用是否一致。改变假设、界方向、极限或主张强度时说明理由；发现核心漏洞时先指出，不通过润色把它隐藏。

交稿前按 PDF 第 6 页复查：用户最终指定的章节结构是否落实；引言六项是否依次齐备；记号、标准引理出处和原创引理证明是否完整；方法有无动机、证明是否充分；应用是否给具体推论、联系或有根据的问题；空泛评价、重复防御和内部审核记录是否已处理。缺少实质内容时明确指出，不声称全文已完成。

## 数学与证据底线

- 不编造定理、证明、文献、DOI、数值结果或实验。旧稿写着“已证”或“审核通过”不能替代本次需要的数学依据。
- 固定维数与维数一致、固定测度与测度族上确界、局部模型与原始问题、有限样本与全域、下包络与真实渐近、典型概率与极值结论分别检查。不能在编辑中无声扩大。
- 写“最佳”“锐”“精确”“首次”时要求相应证明或可核验的比较；缺少依据时改成准确的上/下界或有范围的比较。
- 涉及推导、符号运算、数值计算、优化或结果验证时，主动选择可用本机工具辅助，例如 MATLAB、Python 精确整数/有理数、SymPy 或区间库。只把实际执行的结果记作运行证据，说明它检查的范围；一般证明仍须写出数学理由。仅改语言且未做数学计算时不强制运行工具。
- 数值搜索负责提出候选；严格结论还需有限判据、误差与全域覆盖、连续/一般输入传递及最终不等式。程序状态、哈希一致和两程序数值吻合各有用途，不能互相代替。
- 核查引文时按任务访问原论文、出版社或 arXiv 等来源。记录实际读到的范围；本技能列出的旧文献和文件路径是定位线索，不是自动核实过的引用。

## 交付

未指定格式时给可直接使用的正文或 LaTeX 片段，并简短说明实质改动和仍需核实的关键事项。点评给出准确位置、影响和改法。写作任务应交付文本，不能只交检查清单。

编辑现有文件时保留可恢复的原稿；按用户授权原位修改或另存修订稿。只有用户需要时才另建详细核查报告。正文保留数学内容，证明证书与必要数据放附录/补充材料，内部运行与协作记录留在工作笔记。

用户要求 LaTeX、Word 或 PDF 时完成相应格式的实际交付和检查。现有 LaTeX 项目保留其宏、编号和主文件设置；新项目放独立目录。只在实际编译成功后称编译通过；不得把正文审读、编译成功和数值认证混报。
