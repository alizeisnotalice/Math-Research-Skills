# 有限匹配开关的条件运行

给定有限完美匹配层、独立公平交换开关及若干卡片的整条暴露路径，先核对边相容、所要求的开关一致及路径无碰撞。该事件固定一组开关坐标，其余开关各自公平。按每个时间切面的自由槽排序重标，检查相邻区间置换核按时间顺序合成。自由标签的分布在两端均自由的边上平均，在单端自由的边上按暴露路线运输。

运行 [精确检查器](scripts/switch_cylinder_slot_certificate.py) 枚举有界剩余开关，并核对自由标签律、中心化平方能量和核合成。对象、输入示例以及三份原稿的共用有限接口见[来源和推导](references/switch-cylinder-slot-kernel.md)。
