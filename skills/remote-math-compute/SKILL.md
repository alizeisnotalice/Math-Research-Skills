# 远程数学计算

根据用户指定的设备与研究问题，把适合分割的计算交给远程机器运行，并核验结果。雷电线提供网络连接，两台设备的 CPU、GPU 和内存不会自动合并；只有程序及框架实际支持的计算才能跨机并行。

## 连接与认证

1. 明确目标机器和用户授权，检查本机网络接口、目标地址及 SSH 服务。Mac 上可用 `networksetup -listallhardwareports`、`ifconfig bridge0`、`arp -a` 和 `nc -G 3 -zv <目标地址> 22`。雷电桥地址可能变化；每次重新发现，不能把旧地址当作固定配置。
2. 首次 SSH 连接时，将 `ssh-keyscan` 取得的指纹与目标电脑本机 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 的输出通过可信渠道比对；仅在用户确认一致后保存对应主机密钥。主机密钥变化应停止并核验，不能关闭严格主机密钥检查。
3. 使用用户已有 SSH 凭据或经用户授权配置密钥认证。禁止索取、记录、打印或上传密码、私钥及令牌。认证失败时说明具体状态；交互认证需要用户在自己的终端完成。连接成功不等于已运行计算。
4. MacBook 如需启用 SSH，在“系统设置 → 通用 → 共享 → 远程登录”打开并允许对应用户。连接涉及 macOS 防火墙、睡眠或断线时先检查实际状态，不擅自修改系统设置。

## 已配置的连接

优先检查本机 SSH 配置中用户已有的 `macbook-math` 别名；通过 `ssh -o BatchMode=yes macbook-math` 轻量检查认证和可达性。该别名使用的雷电桥地址可能变化，失效时重新发现设备并核验原有主机密钥后更新本机配置。实际任务依据用户授权直接调用可用远端算力，只做任务必需的环境检查；不重复进行与当前任务无关的测试。配置和密钥留在本机，不写入公开仓库。

## 探测与选路

在已验证并登录的目标机上只读检查主机名、系统架构、处理器、内存、可用磁盘、Python 解释器与所需库、`wolframscript`、MATLAB 可执行文件和许可证状态。将“路径存在”“成功导入/启动”和“实际计算成功”分别记录；软件缺失时报告，不自行安装或修改许可。

适合优先分配给远端的任务包括参数网格、随机实验的独立种子、候选搜索及独立交叉核验。明确每个子任务的输入范围、资源限制和输出文件，避免重复计算；有共享状态或频繁通信的算法需先确认框架支持和通信开销。远程 MATLAB 使用该机已有许可，批处理优先使用 `-batch` 并在完成后退出。不能假定 MATLAB Parallel Server 支持远程 Mac worker，也不能把远端 GPU 当成本地 GPU 直接调用。

## 两机内存与任务分配

- 两台 Mac 的物理内存各自独立；雷电桥不会自动把远端内存加入本机内存，也不能把两机总容量当作普通本地 MATLAB、Mathematica 或 Python 进程的可用内存。任务运行前按各自实际可用内存和系统余量预算。
- 单个任务适合在一台机器上运行、且 MacBook 有足够可用内存时，可把脚本和必要输入发送到 MacBook，使用它自己的内存计算并取回结果；确认输入、临时副本和结果都能放入远端内存。
- 对可以拆分的参数扫描、随机实验、独立搜索或支持分布式的矩阵问题，按框架实际能力在两机分配任务或数据分块；计算每个节点的峰值内存，考虑序列化、输入副本、通信缓存、汇总和系统余量。总物理容量之和不等于进程可用内存，也不保证能运行同等大小的单一对象。
- 确实需要跨节点共享对象或单问题分布式处理时，先核对所选框架、算法与操作系统支持，再针对具体任务测试数据传输和结果汇总；不要假定常规脚本可透明跨机访问内存。Ray 等框架在 macOS 的对象存储可能使用磁盘，应核对实际版本与数据路径，遵守用户的缓存存储约定。雷电 RDMA 需要设备、系统和专门软件支持，不自动提供共享系统内存。
- 优先执行必要的内存预算和任务本身，不为每次研究重复开展无关的性能探测。远端不可达或内存不足时及时报告并调整分块或计算位置。

## 执行与回收

- 先固定问题、约束、精度、随机种子、软件版本与可复现脚本，进行一个小规模端到端试跑；数学任务根据需要分别使用 `python-math`、`mathematica-math` 或 `matlab-plotting` 的方法要求。
- 采用项目独立目录和唯一任务标识。脚本、最小输入和最终结果放用户指定的持久项目目录；临时输出与缓存遵守各机器实际的存储约定。远程路径必须先确认存在且有写权限，不假定 MacBook 挂载了 Mac mini 的 `/Volumes/data`。
- 通过 SSH/SFTP 或其他已验证的传输方式传送任务和结果；重要文件计算并比对 SHA-256。记录远端实际命令、主机、软件版本、参数、种子、容差、退出状态、stdout/stderr 和输出位置。避免传输凭据和无关私人文件。
- 异步长任务记录远端进程或任务 ID；断线后先查询状态和产物，确认原任务停止或结束才重试。只停止本任务创建的进程，不终止用户其他工作；及时回收计算进程及其资源。
- 校验结果的输入对应、残差、可行性、边界和必要的独立交叉检查。区分数值证据、猜想、严格证明及有效范围；有限搜索、浮点结果或哈希一致不证明一般数学命题。

不能连接、缺少认证/许可、计算中断或结果未取回时保留可复现材料并如实报告，继续能够独立完成的本机研究。不要将未运行的远程代码声称为已完成的计算。
