# 页码、计数与真实编译输入

在页码调整、正文页数核算、仅改页脚或多版本源码编译时读取。

## 三种页数概念

- **物理页**：PDF 中从第一张页面起计数的位置，与是否显示页码无关。
- **显示页码**：页脚或页眉印出的标签，可能从摘要起编号、续编、重置或隐藏。PDF 阅读器的页标签也可能不同，应说明采用哪一种。
- **计入正文的区间**：当前规则规定计入预算的内容起止及共享页面处理方式，不能直接用显示页码相减替代。

先制作简短映射：内容区段 → 物理页范围 → 显示页码范围 → 是否计入正文。摘要显示为第一页，并不意味着摘要计入正文预算；附录没有页码，也仍占用物理页。跨区段共用一页时明确计数口径，不能重复扣除。页数上限和排除项以当次要求为准，不把历史案例中的页数、字体、字号或坐标当成通用规定。

## 摘要起一、正文续编、附录隐藏页码

下例适用于已经确认采用 `ctexart`、且本次明确要求这一编号方式的文档，仅示范编号与作用域。保留实际模板的页码字体、位置、章节样式和摘要排版。

```tex
\documentclass{ctexart}
\begin{document}
\pagenumbering{arabic} % 只在摘要起始处设置，重置为 1
\begin{abstract}
摘要内容。
\end{abstract}
\clearpage
\section{正文}
正文沿用摘要后的页码，不再重置计数器。
% 其余正文与参考文献
\clearpage              % 先输出此前页面和浮动体
\appendix
\pagestyle{empty}       % 放在附录局部格式分组之前
\begingroup
% 此处放附录局部格式及内容
\section{补充材料}
附录内容。
\clearpage              % 在局部格式仍生效时输出末页
\endgroup
\end{document}
```

先检查模板中的 `\pagestyle`、`\thispagestyle`、`\pagenumbering` 和页计数器设置。若标题命令显式指定了单页样式，只对相应位置修正；不要盲目重定义全局 `plain` 样式或改用 `gobble`，以免改变正文、页码计数或交叉引用。`empty` 是否满足需求也要渲染确认：它会隐藏该页样式的页眉和页脚；若用户要求保留附录页眉，只创建或选择符合要求的附录样式。

`\clearpage` 必须先结束前一区段，避免在正文末页尚未输出时切换为附录页样式。页样式放在附录局部格式分组之外，可以避免分组结束后恢复原页样式而让尚待输出的附录页面重新带页码。仍须检查附录首、末页及模板中的单页样式覆盖。

## 隔离输出目录与输入证据

XeLaTeX 的输出目录会影响输入查找；相对路径与 `\IfFileExists` 条件不能仅凭源目录中的文件推断。若把编译产物写进含有旧 `.tex` 副本的交付目录，编译可能选中旧文件，同时正常退出。

每个验证阶段使用一个新建的、只承载构建产物的输出目录。源文件和依赖保持在可追溯的项目位置；从明确的项目工作目录运行，启用 `-recorder`，例如：

```sh
xelatex -recorder -interaction=nonstopmode -halt-on-error \
  -output-directory=build/isolated-pass main.tex
```

示例目录须先新建，不能把已有交付目录直接当输出目录。检查生成 `.fls` 中的 `PWD`、`INPUT` 与 `OUTPUT`：将相对输入解析成实际路径，核实主文档、被包含的 TeX、图片与结果文件来自预期版本，且没有从输出目录或历史副本误读源文件。必要时比较真实输入与指定源文件的哈希。保留该记录作为“本 PDF 确由此版本生成”的证据；编译日志无错误、文件名相似和 PDF 页数一致均不能替代此核验。
