# 数学建模论文排版与局部修订

核心原则：锁定基线与修改范围，以渲染后的 PDF 验收，不以“编译成功”替代版面检查。

## 确认规则与基线

1. 按当前比赛的已核实格式要求和用户最新指示，列出摘要、正文、AI 声明、参考文献、附录的页数计入口径与交付物。不要把往届项目报告当作本届规则。
2. 读取 `references/personal-profile.md` 仅作为这位用户可调整的偏好。指定 PDF/模板的已有格式优先保留；规则冲突时明确指出，不静默压缩或裁剪。
3. 查找与用户指定 PDF 对应的 TeX/Word、图片、字体和编译入口，核对章节、页数及关键页面；版本名相似不等于同源。找不到可靠源码时说明限制，不能偷偷换用旧版重建全文。
4. 输出授权范围清单：可改页面/对象/属性，不可改的文字、字体、行距、页边距、图表和公式。用户只要求局部改动时，不能顺便统一全文或润色内容。
5. 在新版本目录保存源码与修改记录，不覆盖旧版本或用户改动。有 TeX 源码时优先改源。是否先交审查稿或直接编译，遵守当前用户约定，不继承旧项目的审批门禁。

## 按需执行

重写摘要、规范术语与图题或重绘图形时，读 [内容编辑与图形适配](references/editorial-and-figures.md)。这些流程只在本轮授权范围内使用；对例图借用格式不借用结论。

- **摘要加粗**：读取 Word 的实际文字运行及继承样式，形成“来源加粗文字 → 目标文字”的映射。只匹配全文中的目标摘要，不全局字符串替换。文字不一致、重复出现或标注模糊时，展示差异并请求必要确认，不自行改写正文来凑匹配。采用字体实际可用的粗体或局部可靠替代，并在 PDF 中检查粗细是否可辨；不得为几个词全局启用伪粗体或替换字体。
- **表格紧凑居中**：优先调整列宽、列间距和单元格换行，不用多余空列、空格填满页面。短表按自然宽度居中，长表在可读字号下合理分栏/续表；不是所有表都应拉满版心。改变表格环境时检查行高、上下间距和后续段落位置，避免横向修正引发整页纵向漂移。
- **图表与伪代码顺序**：先在正文给出相应算法、结果或解释的引导，再放对象；对象内部的表题/图题/表注仍按模板规范。尽量靠近首次引用，不为强制顺序全局锁死浮动体。局部浮动约束、空间预留和自然分页须配合渲染检查。
- **空白与页数**：检查强制换页、过大的不可分页块、浮动体积压、孤立标题、重复占位和超宽对象。优先消除这些原因，不随意缩字号、压行距、改页边距或删正文凑页数。确需内容精简且不在授权内时，说明选项后等待决定。
- **页码与计数**：读取 [页码和编译输入](references/pagination-and-build.md)，分别记录 PDF 物理页、显示页码与计入正文的区间。摘要起始编号、正文是否续编、附录是否显示页码按本次要求处理，不能用隐藏页码推断附录已被移除或不计入预算。
- **附录**：默认放补充推导、适度长度的完整结果、关键伪代码与复现入口，核心答案仍在正文。正文和附录保持统一字体及标题系统，编号清晰。用户明确要求全部代码全文时，完整收录其指定范围，优先于默认适度附录；不混入未要求的重复日志和历史版本。按实际信息量决定长度，不设凑页目标。
- **结果与 AI 声明**：正文必须独立解释主要结果。Excel 展示、图表口径和详细 AI 使用 PDF 按 `math-modeling-delivery` 的对应流程处理；未获授权不新增统计结论或编造 AI 使用情况。

## 编译与验收

涉及 PDF、DOCX 或 LaTeX 时，使用当前可用的对应文档/编译技能完成渲染与核验；不要硬编码旧机器的解释器、字体或编译器路径。

编译到隔离输出目录，并按 [页码和编译输入](references/pagination-and-build.md) 核验 `.fls` 的真实输入，防止 `\IfFileExists` 等读取输出目录中的旧副本。

遵循 [PDF 验收](references/pdf-acceptance.md)：检查页数与章节边界、缺字/溢出/引用、所有页面总览及变更页面细看。仅改页脚时执行源差异、全页文字坐标和全页像素差检查；后续目录更新另设阶段基线，按允许的自然重排验收，不混用前一阶段的像素不变要求。

交付用户要求的 PDF 和必要的可编辑源码/依赖；不要只给 TeX 让无法查看源码的用户自行编译。记录基线、修改编号、实际修改范围、总页数和计入正文的页数、验证结果与残余限制。若发现页数突然大幅下降，先排查漏附录、漏表或版本错误，不能把更短等同于更好。
