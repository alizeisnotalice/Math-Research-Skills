## Notation and main results

The domain is (\mathbb F_2^n), the range is (\{-1,1\}), and Fourier coefficients are normalized under the uniform cube. Let (S=\operatorname{supp}\widehat f), (k=|S|), and for (\gamma\in\mathbb F_2^n),
\[
O_\gamma=\{(\alpha,\beta)\in\binom S2:\alpha+\beta=\gamma\}.
\]
Pairs are unordered distinct pairs. A parity decision tree queries a character (\chi_\alpha); its depth counts parity queries. The rank of the XOR communication matrix is (k), while Fourier dimension is (\dim_{\mathbb F_2}\operatorname{span}(S)), a different parameter.

- **Proposition 2.5 (physical p.4):** Parseval plus the nonconstant coefficients of (f^2=1) imply every pair (\alpha\ne\beta\) in (S) has another pair with the same sum, so (|O_{\alpha+\beta}|\ge2). This is necessary but not sufficient for a set to be a Boolean Fourier support; Theorem A.1 gives a counterexample.
- **Definition 2.11 (p.6):** (f) is ((\delta,\ell))-folding iff
  \[
  \left|\left\{(\alpha,\beta)\in\binom S2:\ |O_{\alpha+\beta}|\ge k^\ell+1\right\}\right|\ge\delta\binom{k}{2}.
  \]
  The count is a fraction of all unordered support pairs, with threshold (k^\ell+1); it is not merely (\delta k/2) pairs. Claim 2.12 then yields at least (\delta k/3) support elements participating in at least (\delta k/2) such directions for sufficiently large (k).
- **Theorem 3.2 (physical p.8):** for sufficiently large (k), choose each parity in (S) independently with (p=1/(2\sqrt{k})), obtaining (R\). There is a constant (c\in[0,1)) with \(\mathbb E[B(f,\operatorname{span}R)]\le ck\), where (B) counts nonempty Fourier-support cosets of the span. A Chernoff bound gives (|R|=O(\sqrt k)) with high probability. Recursively querying these parities and using the bucket-complexity restriction bound gives (\operatorname{PDT}(f)=O(\sqrt k)). The proof uses two independent samples (R_1,R_2), a two-case counting argument over parity-sum triples, and Observation 2.10.
- **Theorem 3.3 (p.8):** if (0\le\ell\le1-\Omega(1)), (\delta\in(0,1]), and (f) is ((\delta,\ell))-folding, set (p=4000\log k/(\delta k^{(1+\ell)/2})). A random (R\) then satisfies (B(f,\operatorname{span}R)\le k-\delta k/6) with probability at least (1-1/k). This is conditional on the folding hypothesis.
- **Corollary 3.4 (p.9):** if every sufficiently large-(k) Boolean function is ((\delta,\ell))-folding for constants (\delta=\Omega(1)), (\ell\le1-\Omega(1)), then (\operatorname{PDT}(f)=\widetilde O(k^{(1-\ell)/2})). **Conjecture 3.6** posits ((\delta,1/2-o(1)))-folding for all Boolean functions; only under this conjecture does the paper derive an (\widetilde O(\operatorname{rank}(F)^{1/4+o(1)})) XOR-communication upper bound. This is not an established general bound in the paper.
- **Theorem 3.7 (p.10):** for every Boolean (f) with (k>4), each (\alpha\in S) has some (\beta\in S\setminus\{\alpha\}) with (|O_{\alpha+\beta}|\ge3). The proof shows that if every such class had size exactly 2, the Fourier coefficient signs force one sign class to have odd size and (f) to be plateaued; granularity and Parseval force both sign classes even, contradiction.
- **Theorem 3.8 (p.10):** (i) an example exists with one exceptional partner for a chosen (\alpha), with all other (O_{\alpha+\gamma}) of size 2; (ii) in any such example the exceptional class has size (k/2). The construction modifies the addressing function. Appendix B proves the address function is ((1,1/2-o(1)))-folding but not ((\Omega(1),\ell))-folding for any (\ell\ge1/2).

## Proof and transfer details

Section 2.1 (pp.5–6) gives the restriction-to-affine-subspace Fourier formula: querying a span (G) partitions (S) into cosets; each restricted Fourier sparsity is at most the bucket count (B(f,G)). Observation 2.10 says if (h) support elements are identified with another element in the same bucket, then (B(f,G)\le k-h/2). Section 4 proves Theorem 3.2 by selecting triples from the Boolean identity and a two-round random sampling argument; Section 5 proves Theorem 3.3 using a degree-count cutoff, many sampled first partners, and a second independent sample to close a folding relation. Section 6 proves Theorems 3.7–3.8 from the zero nonconstant Fourier coefficients of (f^2), coefficient granularity, and Parseval. Appendix A constructs a non-Boolean-support set that satisfies Proposition 2.5’s pair condition, showing that pair condition alone is not sufficient.

## Scope boundary

The unconditional (O(\sqrt k)) theorem is about parity decision trees and Fourier sparsity. The improved exponent and (1/4+o(1)) XOR communication claim depend on an explicit folding hypothesis/conjecture. Neither the span dimension nor number of input variables may be substituted for (k), and the communication claim is specific to XOR functions.
