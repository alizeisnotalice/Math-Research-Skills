## Main results

On (\mathbb F_2^n) with uniform measure and normalized Walsh coefficients, distance (\operatorname{dist}(f,g)) is the **number of inputs** on which values differ. A Boolean function here has range \(\{0,1\}\); Fourier sparsity is \(|\operatorname{supp}\widehat f|\).

- **Theorem 1.1 (physical p.3 / printed p.60):** for any real-valued (f:\mathbb F_2^n\to\mathbb R), the number of (k)-Fourier-sparse Boolean functions at Hamming distance at most (d) from (f) is
  \[
  2^{O(ndk\log k/2^n)}.
  \]
  The distance parameter (d) is an integer count, not a normalized distance. The source gives affine-subspace indicators as examples attaining the order for some parameter choices.
- **Corollary 1.2 (p.3):** (O(nk\log k)) uniform independent random samples suffice to learn exactly the class of (k)-Fourier-sparse Boolean functions on (n) variables, with the paper’s stated exponentially high success probability. The proof groups alternatives by distance and applies Theorem 1.1 in a union bound. This is a sample-complexity statement; the paper explicitly does not obtain a fixed-polynomial-in-(n), arbitrary-function-of-(k) runtime.
- **Theorem 1.3 (physical p.4 / printed p.61):** a nonadaptive one-sided-error tester decides whether an input (k)-Fourier-sparse (f:\mathbb F_2^n\to\mathbb R) is Boolean using (O(k\log^2 k)) queries with constant success probability. There is no distance-from-Boolean parameter; every Boolean input is accepted with certainty.
- **Theorem 1.4 (p.4):** every nonadaptive one-sided-error tester for that Booleanity problem needs (\Omega(k\log k)) queries. This lower bound does **not** assert the same for adaptive or two-sided testers.

## Proof chain and exact assumptions

The uncertainty principle (**Proposition 2.1, p.6**) is ( |\operatorname{supp}(g)|\,|\operatorname{supp}\widehat g|\ge2^n) for nonzero (g). Thus distinct (k)-sparse functions differ on at least (2^{n-1}/k) points (Claim 2.2). Claim 2.3 applies the same principle to (f(f-1)), whose Fourier support has size at most (k^2+k+1), to lower-bound how many inputs a non-Boolean (k)-sparse function must have outside \(\{0,1\}\). Claim 2.4 gives that the indicator of codimension-(r) affine subspace is (2^r)-Fourier-sparse.

**Lemma 3.1 and Corollaries 3.2–3.4 (pp.7–9):** Parseval implies that a \(\{-1,0,1\}\)-valued function with Fourier sparsity at most (k) and input support size at most (d) has (\|\widehat f\|_1^2\le dk/2^n). Sampling signed characters from the spectral-norm distribution and applying Chernoff gives a short approximate description, then coefficient granularity/uncertainty turns that into the list-size bound. For a general real center (f), choose a Boolean sparse candidate (g_0) within distance (d), if one exists. Every other candidate (g) within distance (d) then differs from (g_0) on at most (2d) inputs by the triangle inequality. The difference (g-g_0) is \(\{-1,0,1\}\)-valued and has Fourier support contained in the union of their supports, hence size at most (2k); apply the three-valued support bound to (g-g_0). In general (f-g) is not three-valued, so that substitution is invalid. The learning corollary bins candidates by distance and union-bounds their sample-consistency probability.

**Booleanity upper bound (§4.1, pp.11–12):** Lemma 4.1 restricts a non-Boolean sparse function to a uniformly random linear subspace of dimension (r\ge\log_2(L/\delta)), where (L=(k^2+k+2)/2); it stays non-Boolean with probability at least (1-\delta). The tester samples (O(rk\log k)) points in that restricted cube and accepts iff a (k)-sparse Boolean candidate is consistent. Theorem 3.5 makes accidental consistency unlikely, giving (O(k\log^2 k)).

**Booleanity lower bound (§4.2, pp.12–13):** Yao’s principle uses sums (1_{V_1}+1_{V_2}) of two random affine subspaces of dimension (n/2) with one-point intersection. A nonadaptive query set whose two query-induced affine spans are disjoint is consistent with a Boolean alternative (1_{V_1}+1_{V'_2}); the event has constant probability when (q\le c n2^{n/2}\), yielding (\Omega(k\log k)\) for the paper’s chosen (k\asymp2^{n/2}\).

## Scope boundary

This source studies Fourier support cardinality and testing/learning; it does not assert a quadratic support lower bound from nonzero singleton coefficients. Keep Fourier (\ell_0) distinct from the spectral norm (\ell_1), Fourier dimension, algebraic degree, and number of nonzero **input** points. The tester’s runtime is not shown efficient for the stated best query bound.
