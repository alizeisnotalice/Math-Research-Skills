# 周期网格与分母误差

若 \(f\) 是 \(2\pi\)-周期的 \(C^1\) 函数，\(\|f'\|_\infty\le L\)，把积分按 \(P\) 个长度 \(h=2\pi/P\) 的区间分割，以各左端点代替。平均绝对误差至多 \(Lh/2\)。若 \(f(x,y)\) 的导数界对参数 \(x\) 一致，则同样得到一致的网格误差。

对归一化核，先在连续和离散两边给分母的共同正下界 \(a>0\)。若两边分子分母分别为 \(x,y\) 和 \(x',y'\)，
\[
|x/y-x'/y'|\le |x-x'|/a+|x'|\,|y-y'|/a^2.
\]
对数在 \([a,\infty)\) 上有 Lipschitz 常数 \(1/a\)。应用于正核的嵌套归一化时，从内到外给网格误差和正性，最后用严格积分余量验收离散式。若只是要近似固定精度的连续导数有界积分，可先定一个与 \(P\) 无关的有理网格，再用上式为所有足够大 \(P\) 传递。任何特定原始积分不等式仍需独立余项证书。
