# Rogers--Ramanujan algebraic root branch

Campbell, arXiv:2402.02546v1, proves selected radical evaluations of the
Rogers--Ramanujan continued fraction from icosahedral and modular relations.
For example, physical pages 6--8 derive a polynomial for a parameter attached to
\(R(e^{-\pi\sqrt{26/5}})\), then use the modular relation and a real-domain argument to
select the intended root. A certified use must retain the exact polynomial, its isolating
root interval or monotonicity argument, and the modular identity linking that root to the
requested continued fraction. A computer-algebra root guess is insufficient.
