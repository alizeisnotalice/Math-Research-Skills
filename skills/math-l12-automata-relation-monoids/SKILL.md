# 自动机关系幺半群接口

用于把有限状态自动机的局部计算压缩为有限代数对象，或审计由“字词在一切上下文中不可区分”导出的关系幺半群满射。适用对象是明确给出的有限状态集、有限关系字母表、关系积方向和接受约定；先固定这些约定，再开始推导。

本技能只认证两个可独立使用的有限代数核：角限制同构，以及全关系字母表下的上下文分离。它**不**认证任何全局指数状态下界、嵌套幂等元损失链、Brauer/partitioned-diagram 的完整表示，或固定字母表下的结论。固定来源、页码和审计状态见[来源与界限](references/sources.md)。

## 关系积与角限制

令 `R_H` 为有限集 `H` 上所有二元关系，采用路径顺序

```text
(x,z) ∈ AB  ⇔  存在 y，使 (x,y) ∈ A 且 (y,z) ∈ B.
```

令 `I_F={(x,x):x∈F}`。给定幂等关系 `P²=P` 与 `F⊆H`，若

```text
I_F P I_F = I_F,
```

则定义 `Q=P I_F P`。此时 `Q²=Q` 且 `PQ=QP=Q`，并且限制映射

```text
θ: Q R_H Q → R_F,      θ(Z)=I_F Z I_F
```

是以 `Q` 和 `I_F` 为单位元的幺半群同构；逆映射为 `A ↦ P A P`。

完整证明如下，使用时不要只写“角同构显然”。

1. 由 `P²=P` 和 `I_F P I_F=I_F`，
   `Q²=P I_F P P I_F P=P(I_F P I_F)P=Q`，并立刻有 `PQ=QP=Q`。
2. 若 `Z=QZQ`，则 `PZP=Z` 且
   `Z=P I_F P Z P I_F P=P I_F (I_F Z I_F) I_F P`。故 `I_FZI_F` 唯一决定 `Z`。
3. 对任意支撑在 `F×F` 的 `A`，`PAP=Q A Q`，并且
   `I_F(PAP)I_F=(I_FPI_F)A(I_FPI_F)=A`。所以 `A↦PAP` 与限制互逆。
4. 若 `A,B` 都支撑在 `F×F`，则
   `(PAP)(PBP)=P A (I_F P I_F) B P=PABP`。限制两端即得乘法保持，且 `Q` 限制为 `I_F`。

运行 `python3 scripts/check_relation_corners.py` 作有限精确回放。脚本以位集整数实现关系合成，完全穷举 `|H|=1,2,3` 的幂等 `P` 和全部可行 `F`，逐例检查上述幂等、双侧吸收、双射和乘法同态；它是有限模型的实现/约定核验，不替代任意有限 `H` 的四步证明。

## 从上下文分离到满射

当字母表就是全部关系 `R_H`，某个有限表示 `d(w)` 满足：`d(u)=d(v)` 会使任意上下文 `x,y` 的接受判定相同，便可定义候选映射

```text
φ(d(w)) = r(w),
```

其中 `r(w)` 是字母关系的积。为验证良定义，若 `(i,j)` 只在 `r(u),r(v)` 之一中，取两个上下文字母 `I_{ {i} }` 与 `I_{ {j} }`。恒等式

```text
I_{ {i} } A I_{ {j} } = {(i,j)}  当 (i,j)∈A；否则为空关系
```

使两条包围字词的 nonzero-product 判定不同，矛盾。因此 `r(u)=r(v)`；连接给出乘法性，空词给出单位元，而单字母已覆盖每个 `A∈R_H`，故 `φ` 为满射。

该步骤的保障边界很严格：必须有全部 singleton identity letters，表示等号必须在**所有**左右上下文下保留接受判定，且所判语言确为“关系积非空”（或先给出等价的 pair-testing 规约）。若字母表是固定子集、只有 promise 输入、或测试上下文未被表示允许，不能宣称满射。

## 自动机接口与交付纪律

- 对局部计算模型，明确状态集合、端标记、初始位置、接受是否包含初始配置、stay move、缺失转移与无限不接受计算的语义。局部 diagram/path 对象只有在逐段拼接与有限路径展开都已证明时才可作为表示。
- “有限关系表示”与“字母表大小无关的状态复杂度”不同：`R_H` 有 `2^{|H|²}` 个字母。任何结论应显式标注是随 `H` 增长的有限字母表，还是固定字母表结果；不得互换。
- 输出时分别标注：`已逐行证明的局部引理`、`精确有限核验`、`条件性推论`、`来源声称/待核`。完整下界还需独立审计表示度数、满射的域/单位、幂等角降维、每一步损失预算和递推闭合。
- 报告来源的固定 PDF SHA-256、页码、关系积方向，以及实际运行的精确测试命令和输出。不要将有限穷举或一条局部同构包装成全局状态下界。
