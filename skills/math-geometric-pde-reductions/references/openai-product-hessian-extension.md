# Product-Hessian extension test

Source 1. OpenAI, *Smooth anisotropic uniqueness in the Calderón problem from one boundary patch*, physical pp.13–15, SHA-256 `1ec46ed64206d12d8fdca42ae7454db52571c0ba1eb458aaf234a6ddea061d39`.

For supplied factor gradients, Hessians, and orthogonal directions, test the strict inequality (3.7) on the prescribed product data. The source then separates the finite PSD dual tests to obtain the displayed `P1⊕P2`, `K`, and quadratic-gap witness. Record every strict margin; numerical near-positivity is not a witness.

This conditional local extension criterion is not a global anisotropic uniqueness theorem.
