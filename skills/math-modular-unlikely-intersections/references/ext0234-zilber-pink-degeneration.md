# Zilber--Pink from multiplicative degeneration

arXiv:2208.06338v4, physical pp. 1--3, Theorem 1.3, proves the stated
Zilber--Pink finiteness result for an irreducible non-special curve in
\(Y(1)^n\) over \(\mathbb Q\) that meets the all-infinity boundary. The proof
uses multiplicative degeneration, André G-function height bounds, Galois
orbits and Pila--Zannier counting. All four inputs belong to the theorem's
scope.
