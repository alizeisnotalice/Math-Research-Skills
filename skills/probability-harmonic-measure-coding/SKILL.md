# Harmonic measures, tree boundaries, and coding comparisons

Use this skill when a proof concerns a probability flow on a rooted tree, the boundary law of a random walk, a symbolic or geometric coding of that boundary, or the measure class of two coded laws. Start by identifying the tree, the actual probability measure, and the target space. Do not use “harmonic measure” for every boundary set function: some nonlinear potential theories define nonadditive capacities rather than probabilities.

Use the G25 entry selector（本机附件：`references/entry-selector.md`） to choose a theorem route and verify missing conditions. The exact 30-use index（本机附件：`references/accepted-use-index.md`） distinguishes R13-admitted source uses from the current numbered-method map; G25.05/.07 and A147 remain gaps as described there.

For a comparison problem, write both measures as

`ν₁ = π₁# μ₁`, `ν₂ = π₂# μ₂`

and state explicitly that both are Borel probability measures on the same standard Borel space `E`. Record how endpoints, overlapping cylinders, and any multiple coding of a point are handled. See [the method checklist](references/method.md), [source map](references/sources.md), and the checked [positive](examples/positive.md) and [negative](examples/negative.md) examples.

The main proof routes are distinct:

- **Flow and dimension:** derive cylinder masses from a consistent flow or conductance recursion; establish a stationary ergodic process for the boundary ray; identify information per step and metric contraction per step; then prove exact dimension with integrability and cylinder-to-ball control.
  - For transience on a rooted locally finite tree with positive symmetric conductances, use a finite-energy unit flow from the root to infinity (root flux `1`, zero divergence elsewhere); an arbitrary nonzero edge function or cycle circulation is not a unit-flow certificate. The Lyons card（本机附件：`evidence/source_cards/PR-74fd338eee39-LYONS1990-G25-ELECTRICAL-FLOW.md`） gives this G25.01 preflight. To identify a last-exit boundary law, separately prove the descendant-subtree current equals its cylinder mass.
  - A finite-type example is the LPP 1997 Fibonacci-tree calculation（本机附件：`evidence/source_cards/PR-018d39e77a31-LPP1997-G25-FIBONACCI-FLOW.md`）: for its stated `0≤λ<φ` model, the selected ray is a two-state Markov chain, and its stationary entropy rate gives exact dimension in the common-prefix metric. The transition weights are escape probabilities. This does not establish a general Galton–Watson dimension monotonicity theorem or a coding-map separator.
- **Symbolic IFS or rescaling dimension:** define the shift-invariant symbolic law and coding map before using projection entropy; verify conformality and the Lyapunov denominator for an exact IFS dimension formula. For local-entropy projection arguments, first construct the required ergodic CP-chain or state the weaker nonergodic conclusion, then keep the finite-scale entropy loss. These tools bound or compute dimension; they do not compare measure classes.
- **Measure comparison:** prove equivalence or singularity on the common space by a common Borel full-measure set, a valid Radon–Nikodym derivative argument, or a likelihood/Hellinger criterion whose filtration and product assumptions actually hold.
- **Base-change coding on a common interval target:** a digit-frequency separator can distinguish two tree-walk harmonic measures when the two bases code the same compact set, the target digits are unique and Borel, and the source proves different iid digit frequencies. Benjamini–Peres Example 6 is a scoped example only; it supplies no finite-type transducer theorem and does not decide A147. R13 accepted this restricted base-change use. See the source card（本机附件：`evidence/source_cards/EXSRC-ef8f977a8e39168a-BENJAMINI-PERES-BASE-CHANGE-SINGULARITY.md`）.
- **Common hyperbolic-group boundary:** if both laws are random-walk harmonic measures on the same non-elementary hyperbolic-group boundary, test the cross-Green equivalence criterion for symmetric finite-support walks, compare both to the same Hausdorff reference under the entropy–drift equality, or compare exact dimensions on one common Floyd metric. Different exact dimensions imply singularity on that boundary only when both exact-dimensional theorems apply there. Tanaka’s Theorems 1.1–1.2 give exact local dimension under their proper/bounded-growth hypotheses; Theorem 1.3 is transcribed but excluded from proof use because its physical p. 23 counting step was not independently closed. R13 accepted only the first two. Le Prince’s 2008 Theorem 3.1 gives a measure-box-dimension formula under proper, quasi-convex-cocompact finite-growth hypotheses; it does not assert exact local dimension. Le Prince 2007 Proposition 2.1 supplies an accepted, guarded upper pointwise-dimension bound `h/(l log a)` on its matched visual hyperbolic boundary, not an exact-dimension or measure-class result. Le Prince’s 2005 Hausdorff-singularity result is existential, not a theorem for a specified walk. Equivalence and absolute continuity pass through a common measurable map to E; singularity need not, so also prove a Borel isomorphism on the relevant full-measure sets or an E-level separator. See the conditional comparison card（本机附件：`evidence/usage_cards/G25-hyperbolic-boundary-comparison.md`）; its premises are not established for A147.
- **Boundary completeness, exact dimensions, and singularity examples (wave09; three restricted uses accepted).** Nandi’s constructed reversible walk on a Groves–Manning cusped graph has an exact-dimensional harmonic measure on the Bowditch boundary under its virtually-nilpotent-parabolic and metric hypotheses. Kaimanovich’s entropy, ray, and strip criteria test whether a specified boundary is maximal/Poisson; they are not dimension or measure-class criteria. Kaimanovich–Kifer–Rubshtein treat stationary random transition kernels over an ergodic base, not iid increments by default. Randecker–Tiozzo separate a hitting measure from Lebesgue by average cusp excursions; Kosenko–Tiozzo and Bogachev use current/Fourier or von Neumann-dimension contradictions in their stated Fuchsian/lattice models. These results do not compare two arbitrary coded measures. The Randecker–Tiozzo, Kosenko–Tiozzo and Bogachev results are retained as supplementary-only with zero numbered-method credit; their methods are not cylinder-likelihood/Hellinger or renewal proofs. See the wave09 use card（本机附件：`evidence/usage_cards/G25-hyperbolic-random-walk-criteria.md`）.
- **Capacity and nonlinear set functions:** first prove countable additivity and total mass one before importing probability tools. A set function that fails additivity is not an ordinary boundary probability measure.

Equal Hausdorff or exact dimensions do not imply equivalence. An entropy formula requires a stationary process; a pointwise entropy rate generally requires ergodicity, or conditional treatment over the invariant sigma-field. A dimension formula also needs a valid metric-scale exponent and control that relates cylinders to metric balls. For Galton–Watson boundaries, use branching-measure local-dimension and joint-spectrum results only for their stated offspring law, measure pair, metric, and moment assumptions; the forward child-uniform visibility law is not undirected simple-random-walk harmonic measure. A theorem for a random Galton–Watson tree does not by itself answer a question about two deterministic coding trees mapped to one Cantor set.
