# Separated-index selection from a vector rank bound

Source: Stéphane Fischler, *Distribution of irrational zeta values*, arXiv:1310.1685v1, physical pp.2 and 4, SHA-256 `a7a65f753f00b6583e6dbec30c17fdf6fd6687e235b9181d746662bba0918194`.

Theorem 1.3 combines a vector linear-independence rank lower bound with Proposition 4.1 to select odd indices `sigma_i` in `[d,a]` separated by more than `d`. Given a finite ordered candidate index list and an independently supplied rank certificate, greedily retain a separated subfamily while preserving the applicable rank lower bound.

This reference does not build the zeta linear forms or verify their integrality/saddle-point asymptotics.
