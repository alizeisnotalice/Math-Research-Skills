# Positive example — the fixed-k Poisson event at k=1

For `k=1`, an invariant set exists exactly when there is at least one 1-cycle. The fixed-`k` limit has `Z_1~Poisson(1)`, so

`p(1)=P(Z_1≥1)=1−exp(−1)`.

This is a direct event probability, not the expected number of representations. The finite-state saturation rule has one count coordinate with two states: zero and at least one. It illustrates the exact fixed-`k` Poisson model only; it says nothing about `p(k+1)≤p(k)` for all `k`.
