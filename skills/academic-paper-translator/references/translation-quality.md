# 学术翻译质量核查

翻译与复核时读取本文件。目标是保留原文的论证、限制和信息量，不补写推导，不把翻译改成摘要或教材讲解。单元映射与覆盖要求遵循 [records.md](records.md)。

## 句义与逻辑强度

- 检查否定词的作用范围：not all 与 none、not necessarily 与 necessarily not 不可互换；留意双重否定和否定嵌套。
- 保留全称、存在、唯一、至少、至多、恰好、几乎处处／几乎必然等量词与限定；不要省略量词顺序。
- 区分 if、only if、if and only if、unless、provided that 和 without loss of generality；条件不能变成无条件结论。
- 保留 may、can、must、suggest、conjecture、approximately 等表达的可能性、强度与不确定性；实验支持不能译成证明。
- 明确代词、从句和比较对象所指。长句可以拆分，但要保留因果、让步、转折及逻辑依赖。
- 逐项核对比较方向与基准，例如提高了多少、提高到多少、相对于哪个方法、在哪些条件下成立。
- 原文疑似错误或表述不清时，保留其可核实内容并记录疑问；不得无提示修正原作者的结论。

## 术语与领域语境

- 使用主 agent 发布的术语表；首次引入的重要概念可保留英文或缩写，以便核对。
- 依据上下文处理多义词，尤其是 field、normal、regular、state、kernel、order、sound、complete；不要只凭词频统一译名。
- 同一概念在同一语境保持一致；不同概念不要因中文相近而合并。术语调整交由主 agent 裁决并检查前文。
- 保留定义中限定的对象、取值域、索引范围和约定；不要用常见定义覆盖作者自己的定义。
- 物理术语注意参考系、符号约定、边界／初始条件、守恒条件和近似适用范围。
- 计算机术语注意 soundness 与 completeness、hardness 与 completeness、并发与并行等区别；保持论文对算法和系统的具体定义。

## 数字、单位与代码

- 对照原文核查数值、正负号、小数点、指数、百分比、范围、上下界及统计区间；重点检查 OCR 中的 `0/O`、`1/l/I` 和负号。
- 保留单位、前缀、有效数字及科学计数法含义，不自行换算或“规范化”数值。排版空格调整不得改变单位组合与量纲。
- 表格逐行列核对表头、数值、缺失标记、加粗所指和脚注；不能因正文已提到结果而省略表中信息。
- 代码、变量名、函数名、API、命令、路径和输出示例保持原文。说明性文字在代码外翻译，避免改动可执行内容或引用标识。
- 保留复杂度表达和渐近符号的区别，例如 `O`、`o`、`Ω`、`Θ`，以及期望、最坏情况和高概率等限定。

## 定理、证明与推导

- 保留定义、假设、引理、命题、定理、推论和证明的类别、编号及相互依赖。
- 检查假设是否完整保留，结论是否仍作用于原文指定的对象与范围；“充分”“必要”“充要”不可混用。
- 证明中的分类讨论、归纳基、归纳假设、反证假设、存在性与唯一性论证分别对应原文；不得跳步概括。
- 保留“由……可知”“根据式……”“取极限”“交换积分与极限”等推理关系及其条件，不自行补足作者省略的证明。
- 区分等式、近似式、恒等式、渐近等价和不等式；不要因为结论看似合理而修正中间符号。
- 若原文证明疑有缺口，在工作记录中标明位置及理由；译文本身不得伪造缺失论证。

## 公式保真

- 优先保留来源公式。公式以图像保留时，核查裁切完整、分辨率可读、编号与正文引用对应。
- 必须重建可编辑公式时，逐符号对照原文或页面图像；自动提取的 LaTeX／OCR 结果不是最终依据。
- 检查上下标、粗体／向量、希腊字母、正负号、分式、根号、括号层次、矩阵维度、积分／求和上下限和分段条件。
- 不翻译变量，不重命名符号，不改变公式内部的既定标签。公式中的说明文字如需中文解释，可在相邻文字中提供。
- 保留独立公式与行内公式的数学含义及原编号；留意换行造成的关系符丢失、公式拆断或编号错配。
- 对无法可靠辨识的公式保留可读原图并标记待核查，不猜测缺失符号，也不让替代占位符被当作已完成公式。

## 引用与图表联系

- 保留文内引文编号、作者年份、脚注标记及交叉引用；逐项确认其指向的参考文献、章节、公式、图或表没有改变。
- 按默认范围保留参考文献原文；不得凭记忆修补作者、标题、年份、页码、DOI 或 URL。
- 图注与正文对图的解释都应对应来源。保留原图，图内英文的中文对照应标明标签或位置，避免把译注误认成原图内容。
- 核对图例、坐标轴、子图标记、颜色／线型和单位之间的对应关系，避免翻译对照把曲线或实验条件配错。
- 不把引用过的他人结论译成本文作者自己的发现，也不把相关性、观察结果或经验规律强化为因果或定理。

## 验收方式

- 先按单元清单检查完整性，再对照来源核查语义；仅通读中文是否流畅不足以验收。
- 对否定／量词密集句、核心定义和定理、关键实验结果、OCR 低置信内容及跨块依赖进行重点复核。
- 复核意见指向具体单元或来源位置，说明原文依据及建议译法；避免仅给“更通顺”而改变含义的修改。
- 术语冲突、来源不可辨识、无法确定的逻辑关系等未解决项返回主 agent；不得只为满足覆盖校验而填入猜测。
- 内容核查通过后，仍需检查最终 Word 与 PDF 中公式、脚注、表格、引文标记是否在排版中丢失或错位。
