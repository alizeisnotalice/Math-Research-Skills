# 英文学术文献翻译

将用户提供的英文文献译为忠实、通顺的简体中文，保留原文结构与科学含义。用户当次指定的范围、术语、模型和格式优先。

## 默认行为

- 面向数学、物理和计算机；完整翻译标题、摘要、正文、脚注、图表说明和已提供的附录。作者姓名、变量、代码、标识符与参考文献条目保留原文。
- 中文单栏重排，保留章节层级、定理及证明、公式编号和交叉引用。保留原图，图内英文另附中文对照；表格重建并翻译文字。
- 公式优先保真，复杂公式可使用清晰原图；不将图片声称为可编辑公式。不要把源文已有的正确原生公式无故转成图片。
- 默认交付同名 `.docx` 与 `.pdf`。用户仅要求聊天或其他格式时遵从，不强制制造文件。默认不附加综述、精读解说或检索报告。
- 使用当前会话模型；用户明确指定 DeepSeek 才切换到相应 MCP 路由。可以调用多个 subagent，但不为短文强制拆分。

## 工作流程

1. **确认来源与范围。** 从输入和上下文提取材料、学科、范围、输出要求及指定术语。能从材料确定的事项直接处理；只有缺少原文或关键歧义阻碍翻译时追问。输入提取与网页处理阅读 [输入与来源](references/inputs.md)。
2. **建立可核对的原文。** 检查页数、章节、双栏顺序、断词、脚注、公式和图表；生成有序内容单元清单，每项标为翻译、原样保留或缺口。提取失败不等于内容不存在。长文、并行或续译按 [记录与校验](references/records.md) 保存记录，短文可保持轻量清单。
3. **统一术语并翻译。** 先从全文标题、摘要、定义及方法建立术语表，再按完整语义分块。遵循 [专业翻译与复核](references/translation-quality.md)，不增删结论，不弱化条件。首次出现的关键术语附英文，同一含义保持同一译法。
4. **分工与续译。** 使用多个 subagent、选择 DeepSeek 或恢复中断任务时，阅读 [协作与模型路由](references/collaboration.md)。主 agent 管理任务与术语，子任务各写独立结果；上下文不计入本块输出。先验收再合并。
5. **对照复核。** 将译文逐单元对照源文，重点检查量词、否定、假设、单位、数字、公式与引用。并行结果统一术语后，回查受影响的已译章节。使用覆盖校验脚本检测记录错误，但不能以脚本通过代替语义复核。
6. **制作并检查文档。** 阅读 [文档制作](references/documents.md)，复用环境中的 documents、pdf 技能和运行时依赖。Word 为唯一排版源，PDF 从同一版本导出；逐页检查最终渲染，修改后重新导出。
7. **交付真实结果。** 提供最终 Word、PDF 链接，简述翻译范围及实际缺口。未译项、未识别字符或缺失页须明确说明；未完成或未通过渲染验收的结果不能称为完整终稿。

## 文件与边界

- 遵守当前任务目录约定。中间原文、术语、分块、渲染页和检查记录放在 `work/` 等工作目录；最终文件放在任务指定的交付目录。不要向技能安装目录写入用户文献。
- 同一任务续译复用已验收且来源未变的块；新文献使用独立工作目录。保留输入原件，未经要求不覆盖旧译文。
- 不自动寻找未提供的补充材料。只有部分原文时只处理实际获得的部分；仅有摘要不能推断全文。
- 用户指定模型不可用时报告具体阻塞并保留进度，不静默换模型；依赖不可用时先诊断，未实际完成的导出或翻译如实报告。
