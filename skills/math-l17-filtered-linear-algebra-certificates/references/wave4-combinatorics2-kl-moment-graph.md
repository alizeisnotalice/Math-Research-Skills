# Finite-rank moment-graph comparison boundary

Source: *Combinatorial invariance of Kazhdan--Lusztig polynomials*, SHA-256
`7e1be2107a85e28d9ec339b4ee62d4efeb909968df6768368e2779710624e331`,
Section 2.1 and Theorem 2.2 (physical pp.5--8).

The source first restricts a Bruhat interval to a finite-rank reflection-faithful
real realization and equips its moment graph with a reflection order.  Its path
formula reconstructs each edge label from the ordered interval data, then the
full upward-kernel sheaf is formed over the symmetric algebra of that
realization.  The usable comparison boundary is: preserve the finite interval,
reflection order, real realization, and the labelled directed moment graph
together; an abstract poset isomorphism alone is not the input to this finite
linear-algebra calculation.

Theorem 2.2 supplies the reflection-order path description used by the later
dihedral reconstruction.  It is a route to a filtered-kernel/sheaf comparison,
not an independently executable KL-polynomial algorithm for arbitrary Coxeter
data.
