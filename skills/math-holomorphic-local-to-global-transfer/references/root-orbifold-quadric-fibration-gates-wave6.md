# Root-orbifold quadric-fibration gates

Source SHA-256: `d017fae040e20002b012b8636d9a757cb4471728d3e06d6b80cca60970602c32`; cached original has 14 physical pages. This Wave 6 read treats the original statement as given.

Physical p.5, Proposition 3.1 gives the transfer endpoint: a connected smooth projective `g:Y -> X` with `g^*D=2E`, a smooth connected-fibre open part with trivial relative cotangent, ordinary/root-chart submersions over every base divisor, and special `X` produces special `Y` and a surjection

`pi_1(Y) -> pi_1(X\D)/normal_closure(gamma^2)`.

Physical pp.7--9 specify a constructive gate for this endpoint. In each root chart, form four `2 x 4` coefficient matrices `C_j(x)` for two diagonal quadrics. Require generic smoothness/no stabilizer, rank two after deletion of any one column outside a codimension-two exceptional set, and (on the good open) every `2 x 2` minor nonzero. The source then obtains four smooth connected genus-one complete intersections with trivial cotangent, submersive root-chart points, and even divisor pullback. Physical p.12 shows the quotient-chart operation preserves smoothness when the indicated stabilizer negates one exceptional coordinate.

This is a proposed category because existing skills do not contain root-orbifold parity plus quadric-fibre rank gates. It does not decide specialness or virtual abelianity: those remain source assumptions/external inputs.
