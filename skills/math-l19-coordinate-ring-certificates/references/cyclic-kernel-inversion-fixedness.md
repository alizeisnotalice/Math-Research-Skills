# Cyclic-kernel cyclotomic inversion certificate

**Scoped reference.** This is a finite algebraic checker for whether an
explicit integral expression in a chosen root of unity is fixed by inversion.
It does not decide first-order definability in an arbitrary exponential field.

## Source, edition, and exact locus

Jonathan Kirby, Angus Macintyre, and Alf Onshuus, *The algebraic numbers
definable in various exponential fields*, arXiv:1101.4224v1 (21 January
2011), local 8-page manuscript, SHA-256
`f3477db400ba70f9531bdead06c0b6537806086fffeaecb8adbdf859f7e61efe`.

The source assumes an exponential field of characteristic zero with infinite
cyclic kernel generated by `tau` up to sign.  Physical p. 2, §2.1 identifies
the canonical involution on `Q^ab` by
`sigma_0(u)=u^(-1)` for every root of unity `u`, and defines the real abelian
numbers as `Fix(sigma_0)`.  Physical pp. 3--4, §§2.2--2.7, defines the
sign-independent cosine expression.  The proof of Theorem 1 on physical p. 4
uses, for

\[
 \alpha=\sum_j r_j E(s_j\tau)\in\mathbb Q^{ab},\qquad
 \sigma_0(\alpha)=\alpha,
\]

the finite identity

\[
 \alpha=\frac{\alpha+\sigma_0(\alpha)}2
       =\sum_j r_j\frac{E(s_j\tau)+E(-s_j\tau)}2.
\]

## Exact finite use

For a fixed positive integer `n`, write an integral expression as
`P(zeta_n)` with `P(X)` supplied by its coefficient list.  In the quotient
`Z[X]/(Phi_n(X))`, inversion sends it to `P(zeta_n^(-1))`.  If `M=deg P`,
the checker tests the equivalent polynomial divisibility condition

\[
 \Phi_n(X)\mid X^M\bigl(P(X)-P(X^{-1})\bigr).
\]

Thus a zero remainder is a finite certificate that the listed cyclotomic
expression is fixed by the source's inversion action.  It also prints the
integral cyclotomic polynomial and the exact remainder.  This is a certificate
for the supplied expression only; it neither constructs an exponential field
nor turns a fixedness check into a definition formula.

```sh
python3 scripts/check_cyclotomic_inversion_fixed.py examples/fixed-real-abelian.json
python3 scripts/check_cyclotomic_inversion_fixed.py examples/not-fixed.json
```

The first fixture certifies `2+3(zeta_5+zeta_5^(-1))`; the second certifies
that `zeta_5` itself is not inversion-fixed.

## Scope boundary

Theorem 2 of the source (physical p. 2) is a converse only for Zilber fields
and uses their extension/automorphism theory.  The present finite checker does
not invoke that converse, Schanuel-type assumptions, CCP, or any claim about
the standard complex exponential field beyond the displayed finite
cyclotomic identity.
