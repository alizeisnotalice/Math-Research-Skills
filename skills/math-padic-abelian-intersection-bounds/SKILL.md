# p-adic abelian intersection bounds

Use this route after a smooth curve, abelian variety, prime and unramified p-adic model have been specified. Require \(p>2g_X\). Record genus, degree data, the reduction set and whether the source property \((*)\) has been proved.

The source theorem bounds reductions of the codimension-at-least-two subgroup intersection. Its full p-adic count additionally assumes property \((*)\). It does not construct the model, verify property \((*)\), analyse a ramified disc or compute the jet-space image.
