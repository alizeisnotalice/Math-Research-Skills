# K06 · 随机贪心的优先级独立展开

用于有限简单图的三角形删边过程。给每个三角形一个独立连续优先级，按优先级顺序接受仍有三条边的三角形并删除其边。这个技能提取的是有限递归测试和独立展开的比较接口。它不认证任意随机贪心过程的终态、浓度或渐近常数。

## 输入与先决条件

- 图是有限简单图，任意两个不同三角形至多共用一条边。优先级独立且连续，因此几乎处处互异。
- 每个候选调用都有有限候选表。若改为无限图，须单独证明递归在每个阈值下几乎处处终止。
- 有限过程和独立展开使用相同的候选规则。有限过程中的同一三角形共享同一个优先级，独立展开中的每个**出现位置**有自己的新优先级。
- 若要声明二者误差小，必须给出候选表重复的耦合事件和对该事件的定量上界。有限图内的存活事件本身通常不分解为乘积。

## 有限的成对存活测试

根调用为一个边 (e) 与阈值 (t)。候选为包含 (e) 的所有三角形。非根调用由三角形 (T) 内的一对边 ({f,g}) 和阈值 (U_T) 组成，候选为接触该对边的三角形，排除 (T) 本身。候选 (S) 恰含一条焦点边 (e(S))，其子调用的焦点为 (S\setminus\{e(S)\})，阈值为 (U_S)。

每次调用先按固定顺序暴露**全部**候选优先级，再以低于阈值的优先级递增顺序考察子调用。第一个返回真值的子调用令当前调用返回假值，若没有则返回真值。即使一个候选因高于阈值或较早成功而未被访问，它也已经被暴露。

严格递减的优先级沿任一递归路径不重复三角形类型，故有限测试终止。对阈值以下三角形数归纳可得：根调用为真，当且仅当 (e) 在扫描到 (t) 前未被删去。成对调用为真，当且仅当 (f,g) 都在 (U_T) 前未被删去。排除的父三角形仅从这一个候选表中移除，因为它的优先级正好是当前阈值。它仍可出现在其他后代候选表中。

## 独立出现树与精确乘积式

对每个根类型先建所有可能调用的确定树。每个候选出现位置分配一个独立 (U[0,1]) 变量，作为它在父表的优先级和它子调用的阈值。若候选表长度至多 (M)，深度为 (j) 的递减路径至多 (M^j) 条，每条严格递减的概率为 (1/j!\)。因此 (M^j/j!\to0)，每个可能调用的依赖树几乎处处有限，截断递归稳定并给出可测输出。

设 (q_e(t)) 为完整单边根在阈值 (t) 返回真的概率，(q_{e,T}(t)) 为只从根表排除 (T\ni e) 的版本。对 (T=\{e,f,g\})，置
\[
 I_{e,T}(t)=\int_0^t q_{f,T}(v)q_{g,T}(v)\,dv.
\]
父三角形排除后，两个焦点边的候选出现树不交，因此成对调用返回真的概率为
\[
  q_{f,T}(t)q_{g,T}(t).
\]
同一根表中不同候选及其后代也不交，故
\[
 q_e(t)=\prod_{S\ni e}(1-I_{e,S}(t)),\qquad
 q_{e,T}(t)=\prod_{\substack{S\ni e\\S\ne T}}(1-I_{e,S}(t)).
\]
这是独立出现树的恒等式。它不能写成有限共享优先级过程的乘积恒等式。

## 从独立模型返回有限模型

用同一候选表顺序耦合两种递归。只要已暴露候选中没有同一个实际三角形类型在两个出现位置重复，有限测试与独立出现树逐次给出相同返回值。重复包括从未访问的、却已经暴露的候选。

要估计该失败事件，可把两条祖先调用路径编码为一张形式图，再寻找两个非邻接形式顶点间在原图中存在的额外边。首次标签重复也会生成更早的这种额外边。后续计数必须分别证明：

1. 带额外边的形式图嵌入数足够小。
2. 到达所选调用路径所要求的较早候选失败具有可乘的概率预算。
3. 对所有路径长度求和后的失败概率小于目标事件的尺度。

这些是特定图族的模板、度数和谱条件承担的工作。没有这些输入，只能得出“碰撞外两模型相同”的条件结论。
