# W14-003 — Foss, stationary-ergodic multi-server convergence

**Reading:** Partial, arXiv HTML §1.1 only (local `data/foss_html.html` / `.txt`; the PDF text extraction is unusable). No PDF page numbers; citations below use the HTML section.

For FCFS G/G/1 with stationary-ergodic paired input and \(E\sigma_1<E t_1\), the paper gives the Loynes/time-reversal construction. With reversed increments \(\tilde S_n\), define \(M_n^{(x)}=\max(0,x+\tilde S_n,\tilde S_{n-1},\ldots,\tilde S_1)\) and \(M=\sup_n\tilde S_n\). The strong law gives \(M<\infty\) a.s. and a finite last crossing \(\nu(x)\); after that coupling time \(M_n^{(x)}=M\). The coupling inequality yields total-variation convergence.

For FCFS G/G/m, \(m>1\), the Kiefer–Wolfowitz recursion is \(W_{n+1}=R(W_n+e_1\sigma_n-\mathbf1 t_n)^+\), with \(R\) sorting coordinates increasingly. Under stationary ergodic input and \(E\sigma_1<mEt_1\), starting from zero yields an a.s. monotone limit with the minimal stationary distribution, but the paper states that this gives only weak convergence. IID/regenerative mixing supports total-variation convergence via Harris/renovation methods.

**The open conjecture, HTML §1.1:** under only stationary ergodicity, the load condition, and initial state \(0\), does the G/G/m queue converge in total variation to the minimal stationary law? The source explicitly labels this a conjecture and reports unsuccessful attempts. The finite coupling-time proof for \(m=1\) does not transfer automatically to the vector recursion. This is not a result for JSQ or arbitrary routing; the text calls those separate questions open.
