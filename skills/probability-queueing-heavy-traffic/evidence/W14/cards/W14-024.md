# W14-024 — Schönlein, Lyapunov construction for positive Harris recurrence

**Reading:** Full paper, PDF pp. 1–11. Local fulltext: `data/lyapunov_positive_harris12.pdf` and `.txt`. Identity checked against arXiv:1209.1554v1.

Assumptions (A1)–(A3), PDF pp. 2–3: IID mutually independent arrival/service/routing sequences; finite means and routing matrix spectral radius below one; interarrival laws unbounded and spread out. The model is a head-of-line multiclass network with infinite buffers and a strong Markov state including residual interarrival/service times. Stability means positive Harris recurrence.

Theorem 1.1, p. 5: if the associated fluid network is stable and its level-process set satisfies the regularity properties (a)–(f) (global Lipschitz bound, scaling, shift, closedness, concatenation, and lower semicontinuity), then the stochastic network is stable. Theorem 2.1, p. 7, supplies a continuous fluid Lyapunov function \(V_L\) with class-\(K_\infty\) lower/upper bounds and integral negative drift.

The explicit stochastic Lyapunov function is \(W(x)=w_2^{-1}(V_L(q))+\|u\|+\|v\|\), where \(u,v\) are residual interarrival/service vectors. The proof establishes a variable-step Foster drift

\[
E_x W(X(cW(x)))\le \max\{W(x),\kappa\}-\varepsilon W(x),
\]

then applies Theorem 3.1 (pp. 7–9), a sampled-time Foster criterion, and shows the sublevel set is closed and petite (pp. 9–10). Theorem 3.1 bounds expected return time by \(\varepsilon^{-1}\max\{W(x),\kappa\}\). The conclusion requires all listed fluid regularity and spread-out assumptions; “fluid model stable” without those interfaces is not enough for this exact theorem.
