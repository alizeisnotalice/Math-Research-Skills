`math-l16-prime-sieve-certified-transfers`. It admits one finite
group-theoretic implication from the deterministic-factoring manuscript. It
does not admit either manuscript's factoring, quadratic-nonresidue, or running
time theorem.

## Source claims kept as claims

The first manuscript states a zero-error Las Vegas complete factoring theorem
at physical pp. 1--2, Theorem 1.1. Its overview on pp. 3--5 explicitly
depends on a custom smoothness weight, randomized polynomial descent,
Stark--Chebotarev square certification, and a recursive complexity argument.
Its p. 5 post-hoc output check uses AKS primality and direct multiplication,
which only validates a supplied factorization.

The second manuscript states deterministic factoring, order splitting, and a
prime quadratic-nonresidue construction at physical pp. 1, 4, Theorems
1.1--1.3. The claimed construction depends on its multiquadratic order test
(p. 13, Lemma 3.1), quadratic/biquadratic enumeration (pp. 15--18, Lemma
4.2), character extension and positivity (pp. 20--21, Lemma 5.1), and the
quadratic-field Burgess bound (pp. 23--28, Lemmas 6.3--6.4). Those chains were
not independently closed here.

Accordingly, neither source supplies a dedicated factoring procedure in this
skill library. A primality-and-product verification routine is a verifier for
an already supplied factor list and cannot be presented as a procedure that
finds that list.

## Accepted finite index/exponent implication

The elementary terminal step of the second manuscript is physical p. 55,
Lemma 11.1. Use it in the following stripped, fully stated form.

Let \(N=\prod_j p_j^{a_j}\) be odd, and suppose every \(p_j>K\). Let
\(\mathcal P\) be a finite set of rational primes coprime to \(N\), and let
\(M\ge1\) satisfy

\[
  \ell^M\equiv1\pmod N\qquad(\ell\in\mathcal P).
\]

For each \(p_j\), write \(G_j\) for the subgroup of
\(\mathbb F_{p_j}^{\times}\) generated by the reductions of
\(\mathcal P\). If the separately certified index bound

\[
  [\mathbb F_{p_j}^{\times}:G_j]\le K
\]

holds for every \(j\), then

\[
  p_j-1\mid M\operatorname{lcm}(1,2,\ldots,K).
\]

Indeed, the modular congruences make the exponent of \(G_j\) divide \(M\),
and each \(G_j\) is cyclic, so \(\lvert G_j\rvert\mid M\). The displayed index divides
\(\operatorname{lcm}(1,\ldots,K)\), and
\(p_j-1=\lvert G_j\rvert[\mathbb F_{p_j}^{\times}:G_j]\). The manuscript
derives its index bound from additional size and cardinality hypotheses on a
prime set in \((B/2,B]\). Those arithmetic hypotheses are outside this accepted
finite implication and must be supplied independently by a caller.

This belongs in L16 because it transfers a certified finite subgroup-index
bound to a prime-factor exponent divisibility statement. It adds no search
method for \(\mathcal P\), \(M\), a factor of \(N\), or a quadratic
nonresidue.

## Exact finite replay

The finite replay used Python 3.13.18 with integer
arithmetic. It fixed \(K=100\),
\(\mathcal P=\{11,13,17,19\}\), enumerated 231 squarefree products of two
distinct primes in \((100,211]\), computed the exact common multiplicative
order exponent \(M\) modulo each product, and checked both divisibilities
\((p-1)\mid M\operatorname{lcm}(1,\ldots,100)\). Every instance passed.
This is a finite regression check for the elementary implication, not a proof
of the paper's parameter schedule or asymptotic theorem.

For a reproducible example use \(N=101\cdot103\) and the four generators above. The orders modulo \(101\) are \(100,50,10,25\), and the orders modulo \(103\) are \(102,17,51,51\). Thus both generated subgroups have index \(1\) and one common exponent is \(M=5100\).
