# 删除信道秩矩与局部比较

用于已知长度 `n`、保留率 `p`（`q=1-p`）的独立删除信道，且所用统计量是完整 trace 的指定秩位比特乘积（trace 太短时取零）。先固定比特编码（`0/1` 或 `±1`）、秩集、是否完整观察 trace，以及比较是两个定字还是一个正半定截断矩泛函。不要把本技能用于带插入、替换、未知 `p`、部分 trace，或直接声称一般重建的样本/时间复杂度。

本技能的三份固定来源与校验状态在 [来源与状态](references/sources.md)。它们均为本机 OpenAI 预印本档案中的 `scholarly_review: pending` 条目；本文仅把下列有限代数核验作为已独立完成的依据。

## 已核验的秩矩传输

令 `I={ℓ₁<⋯<ℓₖ}`，令 `T_I(X)` 为 trace 的这些秩上比特之积的信道期望。对任意线性差分泛函 `Δ`（可为两个候选字之差，也可由经过单独正性核验的矩泛函给出），定义

```text
F(Z₀,…,Zₖ₋₁)
 = Σ_{i₁<⋯<iₖ} Δ[X_{i₁}⋯X_{iₖ}]
     Z₀^{i₁} Π_{r=1}^{k-1} Z_r^{i_{r+1}-i_r},

G(u₀,…,uₖ₋₁)
 = Σ_{ℓ₁<⋯<ℓₖ} Δ[T_{ {ℓ₁,…,ℓₖ} }]
     u₀^{ℓ₁-1} Π_{r=1}^{k-1}u_r^{ℓ_{r+1}-ℓ_r-1}.
```

逐个固定输入位置元组计数其前缀及各内间隙中被保留的未选位置，便得到多项式恒等式

```text
(Π_r Z_r) G(u) = p^k F(Z),       Z_r = q + p u_r.
```

这在 `Z_r=0` 时也由多项式等式延拓成立。它是把输入坐标的加权差分转为可观测 trace-rank 矩的正确接口；它本身不给出可检测下界。

- 任何使用此式的推导都应写出 `k`、`I`、`p`、`q`、`Δ`、两个多项式和每个未选位置的二项式计数。
- 运行 `python3 scripts/check_rank_identity.py` 可重做两个使用 `Fraction` 的有限精确实例：`(n,k,p)=(5,2,2/3)` 与 `(6,3,3/5)`，输出必须都是 `exact difference=0`。这只检测实现的计数/指数约定，不替代对一般式的证明。
- 若改用 `±1` 编码、条件 trace 事件或局部块统计，重新推导系数；不要把此 `0/1` 完整-trace 公式直接搬过去。

## 正性、平滑与 TV 的边界

可将错误前缀与正半定 Boolean 截断矩数组分离的论证分成两步：先独立验证矩阵正性确实允许所用的 Cauchy–Schwarz/Gram 操作，再以本节的恒等式转到 trace 统计。一个可行数组不必来自真实概率分布；不可把“可行”改写为“存在分布”。

若任务需要 Prouhet–Thue–Morse 有符号平滑、Hellinger 或 TV 下界，只采用已逐行检查的局部引理，并在结果中标记其证明状态：

1. 先由有限差分乘积证明所选符号多项式在 `1` 的消失阶，再在明确的二项分布/其平移反射、范数和 Fourier 归一化下证明卷积界。
2. 对独立样本，仅在已给出单-trace Hellinger/TV 误差与共同核（如同尾部 padding）的条件下，使用张量化和三角不等式。写出误差是 `√m` 型还是线性 `m` 型以及核替换误差。
3. 若上述局部证明尚未复核，记录为“来源声称，待证明检查”。尤其不能从 Prouhet 消失矩或某个有限数值直接宣布 `n^{Ω(log log n)}` 的一般下界。

## 三篇预印本如何使用

- **Uniform quasipolynomial-time trace reconstruction** 的 Eq. (4.14) 是本技能已核验恒等式的来源。它的多尺度分离、PSD 松弛可行性和完整解码器仍是条件性来源路线；要引用样本或运行时间结论，逐段审查其分离命题与有限有理可行性程序。
- **A latest-anchor induction with spectrally compact masks** 可作为“来源声称的样本上界”背景。其 latest-anchor、掩码相位归纳及全局分离没有在这里认证；不得由本技能输出高概率重建器或该文的总体界。
- **Quantitative lower bounds for trace reconstruction** 的 Prouhet–Thue–Morse 平滑、恢复/padding 和 product-prior 测试是可审计的局部路线，但在其具体假设和完整证明链复核前，整体 lower bound 仍保持条件性。
