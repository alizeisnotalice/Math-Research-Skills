# Dirichlet L-value span theorem: exact scope

Ludovic Mistiaen, *Linear independence of values of Dirichlet L-functions*, arXiv:2512.02612v2, is a 36-page local preprint with SHA-256 `5a4e375dc4a5ee848780175b61d155875d84d7bf0f7db59f45ef90162013b283`. Theorem 1.0.5 is on physical pp. 2--3; this is not a checked journal publication.

For a character of conductor \(N\), the coefficient field is \(K=\mathbb Q(\exp(2\pi i/\varphi(N)))\), not automatically \(\mathbb Q\). The theorem concerns only parity opposite to the character. Its constants are \(C_N=0.21\) for \(N=1,3\), \(0.21\sqrt2\) for \(N=4\), \(0.42\) for odd \(N\geq5\), and \(0.42\sqrt2\) for \(4\mid N, N\geq8\). There is no conductor \(N\equiv2\pmod4\) for a Dirichlet character.

The proof route was checked locally: pp. 29--31 establish the multiplicity condition through the source's Shidlovskii lemma, while pp. 31--35 state and apply the linear-independence criterion and reduce the periodic-function result to odd/even conductor cases. It remains asymptotic, not a finite computational certificate.
