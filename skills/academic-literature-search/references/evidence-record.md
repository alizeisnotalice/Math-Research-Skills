# 文献记录、检索日志与引用导出

这些字段用于一致地整理文献，不强制每次生成额外 JSON 文件。未知信息用内部空值并注明原因；导出引用时省略未知字段，不填占位符。

## 文献记录

| 字段 | 内容 |
|---|---|
| `paper_id` | 本轮稳定编号，如 L01；聊天、日志与引用映射一致 |
| `title`, `authors`, `year`, `venue`, `publication_type` | 所选版本的题名、完整作者、年份、期刊/会议/仓储与类型 |
| `doi`, `url`, `citation_key` | 已确认 DOI（可缺）、权威题录链接、唯一 BibTeX 键 |
| `verification_status` | `verified` 或 `pending_verification`，不表示研究结论可信度 |
| `verification_sources`, `checked_at` | 核验链接、核对的字段、访问日期；存在冲突时列出差异 |
| `read_scope`, `read_locations`, `snippet_only` | `metadata` / `abstract` / `fulltext`；实际读到的部分；是否只有搜索片段 |
| `relevance_reason`, `limitations` | 与问题的关系，缺字段、阅读限制和适用范围 |
| `versions`, `dedupe_decision` | 关联版本及关系依据，合并/保留理由与原始来源 |

无 DOI 的正式论文可以是 `verified`。有 DOI、但作者或年份无法核对的条目仍是 `pending_verification`。已取得摘要不代表全文已读。只有搜索片段时不从中推断完整作者或补全实验结论。

## search-log.md

记录以下信息，适合人工复查即可：

- 本轮研究问题、时间与时区、语言、数量及筛选条件；用户指定条件与默认值分开说明。
- 实际执行的每个检索式、渠道/工具、筛选参数、执行日期、结果页/返回记录链接。只有接口确实返回数量时才填命中数；否则写未提供，不把搜索引擎估计数当作已筛选量。
- 已执行检索和下一轮建议分列；普通网页搜索、数据库站内检索、直接打开论文页分开记录。
- 纳入和排除的主要理由、最终推荐数、去重与版本处理、编号到引用键的映射。
- 每篇核心字段核验依据、阅读范围及缺项；可链接到已有清单，避免重复长篇内容。
- 阻塞发生在哪一步、实际错误、是否重试、替代路径及剩余缺口。访问受限属于检索事件，不是论文质量等级。

## references.bib

- 只导出 `verified` 条目。优先采用来源提供的 BibTeX，并与所选版本核对；不能无检查地复制搜索引擎或数据库自动生成的引用。
- 按事实使用 `@article`、`@inproceedings`、`@phdthesis`、`@mastersthesis` 或 `@misc` 等标准类型。预印本用 `@misc` 并标明仓储/编号，不冒充已正式发表。
- 期刊论文需有已确认的题名、作者、期刊和年份；会议论文需有题名、作者、会议录名和年份；学位论文还需授予机构。预印本记录题名、作者、年份和可核验仓储链接。缺必需字段先补查，仍缺则跳过导出并说明，不能以换类型隐藏缺项。
- 引用键唯一且稳定，可用 ASCII 作者名、年份与短题名，或 `L01` 等编号；不靠编造英文人名生成键。
- 保留原题名和作者顺序；作者以 `and` 分隔，中文姓名作为完整姓名保护。不要把聊天中的“等”或 `et al.` 当作完整作者表。
- 使用 UTF-8；必要时转义 BibTeX/LaTeX 特殊字符，保护缩写大小写；DOI 写裸标识，URL 单独记录。卷期页码、出版社等可选字段只在确认后填写。
- 在线首发尚无卷期时省略卷期和页码，记录已确认的在线年份与版本说明。预印本 DOI 不转写到正式会议记录。
- 检查文件可解析、引用键无重复、无空占位符，并逐项核对来源。若有现成解析器或文献管理工具，使用它；不要为此强制安装依赖。无已核验条目时使用 BibTeX `%` 注释说明，不伪造空文献。

## 按需主张与证据映射

每条记录包含 `claim_id`、主张、`paper_id`、证据位置（摘要段落、正文章节、页码或图表）、支持关系、实际阅读范围和局限。相同论文可以用于多个主张，每个映射分别核查。

只有题录或搜索片段时，最多作为待查线索；读取摘要后只能表述摘要支持的内容。定量结论和因果主张必须有实际读取的可定位证据，区分作者陈述与智能体推断。不把相关性推荐当作证据支持。
