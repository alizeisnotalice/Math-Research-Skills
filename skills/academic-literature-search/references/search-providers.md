# 渠道选择与访问限制

本文件用于选源、适配查询与处理阻塞。先检查当前工具、CLI 和已有连接；下列来源是选择范围，不是每次都必须调用的清单。不新增强制密钥、付费服务或未安装的依赖。使用 API 前查阅其当前官方文档，确认认证、限额和字段，不硬编码猜测的端点。

## 按用途选源

| 需求 | 可选渠道 | 用法与核验边界 |
|---|---|---|
| 中文研究 | 已安装的 `cnki-search`、中文期刊官网、大学仓储 | 知网负责检索；官网或可信题录补齐核心字段 |
| 跨学科发现 | 可访问的 Google Scholar、OpenAlex、Semantic Scholar，或网页搜索 | 扩展关键词和候选；搜索片段不等于已读摘要 |
| DOI 与发表信息 | 出版方页面、Crossref 等 DOI 注册元数据 | 检查 DOI 对应文献和版本；不是所有论文都有 DOI |
| 计算机与自然语言处理 | ACL Anthology、会议官方论文库、DBLP、arXiv | DBLP 辅助题录；arXiv 需区分预印本与正式版 |
| 生物医学 | PubMed、期刊官网、可访问的 PMC | 索引/摘要与全文访问分别记录 |
| 其他学科 | 对应学科数据库、期刊/会议官网、机构仓储 | 按主题选择，不把某个学科数据库当作全学科来源 |

通过网页搜索限定某数据库域名，只能记录为“网页搜索发现该站点文献”，不能声称执行了数据库站内检索。未实际访问 Google Scholar 时，不把普通网页搜索叫作 Scholar 检索。

## 知网

使用前读取现有 `cnki-search` 技能，遵循其参数及限制。先检查 `cnki --version`；已安装时可使用：

```bash
cnki search '<主题>' --field=topic --sort=relevance --size=20 --format=json
```

仅在用户指定年份或本轮有明确筛选目的时添加年份参数，使用实际年份，不在技能中固定年份区间。串行、小批量检索。详情命令只使用检索返回的 URL，不拼接会话地址；导出的引用仍须通过本技能的核验规则。

CLI 缺失时使用现有浏览工具或期刊官网；没有替代能力则说明缺失，不自动安装。因沙箱网络策略阻塞时使用环境支持的权限流程，不将本地拒绝误报为知网验证码。验证码、登录墙、解析失败和无结果分开记录。

## 查询与补查

- 发现阶段用主题、同义词和方法词；主题跨语言时检索中英文表达，翻译题名只作辅助展示。
- 精确题名补查使用引号，并按来源支持情况设置作者和年份。参考文献与被引关系可用于扩展，但只计入实际读取的记录。
- 优先追踪官方出版记录；没有可访问出版页时，可使用可信学科数据库或机构题录，注明核验依据。出现冲突时回查所选版本；关键冲突无法消除则待核验。
- 若用户限定单一数据库或语言，降级不能悄悄突破该范围；可列出未执行的替代建议。

## 失败与停止

- 无结果：调整一次同义词、字段或过窄检索表达；用户明确的硬性条件不自行放宽。
- 网络瞬时错误：有明确理由时做一次有限重试。登录墙、验证码、付费限制出现后停止该路径，不反复请求或绕过限制。
- 部分渠道失败：保留已有结果，转向范围内的可用来源；记录失败阶段与替代路径，不把一次失败扩展成整个数据库不可用。
- 全部渠道失败：交付未执行的检索方案与阻塞日志，不以模型记忆伪装成实时命中。
- 结束时说明检索覆盖与缺口，不将本流程包装成系统性综述或穷尽性检索。
