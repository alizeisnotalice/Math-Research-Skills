# Gale 例中的有限截断和尾部约束

来源为 Zălinescu，*On the duality gap and Gale's example in conic linear programming*，本机 arXiv:2205.12631v2。SHA-256 为 `08ccea72ef78920ae7913157fd31d551a4bb9c8477f2eeedf3750c3a8c8e9513`。物理页 8，§3，给出 (PG) 与 (PG\(^*\))，并用有限支撑原变量与整个自然数上的对偶约束区分原、对偶值。[期刊版](https://www.sciencedirect.com/science/article/abs/pii/S0022247X22008824)

原问题在非负有限支撑序列上最小化 \(x_0\)，等式为
\[
x_0+\sum_{k\ge1}kx_k=1,\qquad \sum_{k\ge1}x_k=0.
\]
非负性迫使 \(x_k=0\)（\(k\ge1\)），最优值为 1。对偶最大化 \(u\)，约束为 \(u\le1\) 与 \(ku+v\le0\)（所有 \(k\ge1\)）。

- **有限截断。** 取 \(1\le k\le M\) 时，\((u,v)=(1,-M)\) 达到最优值 1。
- **完整约束。** 若 \(u>0\)，充分大的 \(k\) 会违反 \(ku+v\le0\)。因此 \(u\le0\)，且 \((0,0)\) 可行，最优值为 0。
- **扰动序列。** 把第二个等式右端改为 \(1/M\)，取 \(x_M=1/M\)、其余分量为零，得到最优值 0。虽然右端收敛到 \((1,0)\)，极限点的原值仍是 1。这直接给出值函数在该点的下半连续性缺口。

[精确脚本](../scripts/gale_truncation_witness.py)读取正整数 \(M\)。它检查截断最优点在 \(k=M+1\) 的违约值恰为 1，同时给出扰动问题的有限支撑见证。把这组算例用于检查交换法的停止规则以及乘子是否逃逸。对其他问题的完整尾部可行性仍须由真实分离或覆盖界获得。
