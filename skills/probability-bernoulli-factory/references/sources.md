## Appendix C tail check for arXiv:2505.05438v3

In [Proposition 8, equations (85)–(87)](https://arxiv.org/html/2505.05438v3#A3.Thmproposition8), the martingale MGF controls the deviation from the predictable compensator. An unconditional lower bound on expected log cost does not control that compensator. For the abstract implication, let Z be one fair Bernoulli bit and set all r_i=Z. The centered martingale has only one nonzero, bounded increment, but S_n=nZ has a lower-tail atom of mass 1/2. This example tests the abstract implication without asserting realizability in a specific likelihood model.

For a target model with all conditional bounds under a common probability law, a sufficient extra hypothesis is a high-probability lower bound on the compensator. If A_n is at least 3 epsilon n/4 outside an event of probability q_n, then the probability that S_n is at most epsilon n/2 is at most q_n plus the martingale lower-tail bound at epsilon n/4. To obtain exponential decay, prove an exponential bound on q_n as well. Proposition 7's separate Jensen calculation only uses the unconditional mean.
