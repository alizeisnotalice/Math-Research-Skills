## Exact Algorithm and conditions

The target is the unit-volatility diffusion `dX_t=α(X_t)dt+dB_t`, initially `X₀=0`. The paper assumes global weak uniqueness (locally Lipschitz drift with linear growth suffices for the stated setup), Novikov's condition for Girsanov, differentiable `α`, and integrability of the biased endpoint density `∫ exp(A(u)−u²/(2T))du<∞`, where `A'=α`. It defines `φ(u)=(α²(u)+α′(u))/2−k₁` after bounding `(α²+α′)/2` between `k₁,k₂`, and chooses interval length `T≤1/(k₂−k₁)` so `0≤φ≤1/T`. These are material applicability conditions, not automatic for every diffusion.

**Theorem 1 (printed p.2428; PDF p.7).** Given an independent biased-Brownian path `ω∼Z`, an iid sequence of points `(V_i,W_i)` uniform on the area-one rectangle `(0,T)×(0,1/T)`, and an independent `U∼Unif(0,1)`, the paper constructs nested alternating events `E_j` from the point tests `φ(ω(V_i))≥W_i` and factorial thresholds `U≤1/j!`. These are iid uniform rectangle points, not a unit-intensity Poisson process. The increasing/decreasing event limits agree a.s.; the resulting indicator satisfies

`P(I=1 | ω)=exp(−∫₀ᵀ φ(B_t(ω))dt)`.

This event is decided after a finite random Brownian skeleton, so rejection sampling with the biased Brownian proposal yields an exact target-diffusion skeleton. In the proof, conditional on the path and with `H=∫₀ᵀφ(B_t)dt`, the point tests give `P(Γ_n|ω)=H^n/n!`; the shared `U` then yields alternating event probabilities whose increasing/decreasing limits agree and equal `exp(−H)`. Thus the algorithm avoids evaluating the whole path integral. The simulation source is an iid uniform point sequence with a shared factorial-threshold uniform, not a Poisson count construction.

**Efficiency results.** Proposition 4 (printed p.2432; PDF p.11) gives proposal acceptance probability at least `e⁻¹` for an eligible interval and tending to 1 as `T↓0`. Proposition 5 (PDF pp.11–12) defines `N` as the number of alternating events `E_n` tested before deciding a proposed path and proves `E[N]≤e`, using `P(N≥n)≤1/(n−1)!`. This is an event-test count in the iid uniform-point construction, not a Poisson-process count. Proposition 6 (PDF p.12) gives `E[N_l]≤⌈lR⌉e²` for a length-`l` skeleton when `R` is the identifiable range of `(α²+α′)/2` and the maximal legal segment length `T=1/R` is merged; here `N_l` is explicitly the total number of uniformly drawn rectangle points. Neither cost is a Bernoulli-factory p-coin-toss count.
