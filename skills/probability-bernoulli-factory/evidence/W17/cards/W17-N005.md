## Fundamental Theorem of Perfect Simulation

The input is a probabilistic recursive scheme (PRS) Alg(α) with a target distribution πα for every parameter α. Theorem 1 (FTPS, physical pp. 4–7) states: if for every α the recursion terminates in finite time almost surely and the scheme is locally correct, then its output is exactly πα. Local correctness means replacing every recursive subcall by an oracle draw from that subcall’s target distribution makes the current-level algorithm output πα.

Proof mechanism: truncate recursion at depth n, using target-distribution oracles at that depth. Local correctness plus induction implies each truncated output Yₙ∼πα. Couple Yₙ to the actual output X; they coincide on {T≤n}, where T is maximal recursion depth. For any measurable A,

|P(X∈A)−πα(A)|≤P(T>n)→0

by almost-sure finite termination. This is an exactness criterion, not a finite expected runtime bound: T<∞ a.s. does not imply E[T]<∞. The paper applies the criterion to rejection sampling, CFTP and other recursive protocols (pp. 7–11, 14).

## Linear Bernoulli factory

The input is an unknown p-coin and auxiliary known C≥1, 0<ε<1, with Cp<1−ε. BF1 uses a known C/(1+C)-coin B; if B=0, return 0; otherwise flip one p-coin X, return 1 if X=1, and recurse if X=0. Lemma 7 (physical p. 12) follows by local correctness:

P(W=1)=C/(1+C) [p+(1−p)Cp/(1+Cp)]=Cp/(1+Cp).

BF2(C,i,ε) returns Bernoulli((Cp)^i) (Lemma 8, physical pp. 12–13). At i=0, return 1. If i>3.55/ε, set β=(1−ε/2)/(1−ε), draw B₁~Ber(β^(−i)); return 0 on failure, else recurse with (βC,i,ε/2). Since Cp<1−ε, the rescaled input obeys βCp<1−ε/2, and β^(−i)(βCp)^i=(Cp)^i. Otherwise draw B₂~BF1(C) and recurse with i+1−2B₂. The two branches yield

Cp/(1+Cp) (Cp)^(i−1)+1/(1+Cp) (Cp)^(i+1)=(Cp)^i.

Termination is a.s.: at boundary levels the survival probability is at most exp(−3.55/2); in the interior the state has at least 1/2 chance to move toward a boundary. This proves exactness using FTPS; it is not by itself a moment characterization for arbitrary f.

Lemma 11 (physical pp. 14–16) **prints** the following bound on the number T of p-coin draws in BF2(C,1,ε):

E[T]≤C(1+ε^(−1))/[(1−exp(−3.55))(1−2exp(−3.55/2))].

The printed proof does not establish this displayed cost bound as written. On p. 16 its geometric/ceiling sum is followed by “using `ceil(x)≤x+1`,” but that replacement leaves a `3.55/ε` scale in the leading geometric term; it does not yield the displayed `C(1+ε⁻¹)/D` expression with `D=(1−e⁻³·⁵⁵)(1−2e⁻¹·⁷⁷⁵)`. The concluding p. 16 note says `D≤5.53`, which also does not produce the stated `5.53 C/ε` upper bound; `3.55/D≈5.5292` is a derived numerical quantity, not the source's printed inequality. A finite diagnostic at `ε=1/8` gives the displayed proof majorant about `44.9027 C` versus the Lemma 11 RHS about `14.0177 C` (`evidence/W17/experiments/review_point_fixes.py/.out`). Keep Lemma 11's literal display, but do not use its constant or exact cost inequality as proof-verified; this does not invalidate FTPS, the local-correctness exactness proof, or the BF2 recursion algebra. The 3.55 threshold and any `Ω(ε⁻¹C)` comparison remain scoped to the source's stated algorithm class, not arbitrary factories.

The computational model assumes exact floating-point operations on ideal uniforms for the analysis; §4 notes that a probabilistic Turing machine cannot draw an exact uniform in finitely many bits and discusses approximation to a requested tolerance (physical p. 14). The construction is a linear factory and does not settle arbitrary f(p) or endpoint termination.
