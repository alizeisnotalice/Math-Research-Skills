## Model and theorem statements

An `X`-algorithm receives an iid sequence with any law `π∈M₁(X)` plus an independent `U∼Unif(0,1)`, stops at a data-dependent finite index, and returns a nonnegative value. An `f`-factory must, for every such `π`, return a nonnegative unbiased estimator of `f(m₁(π))`. This is a general nonnegative-estimator model, not the Bernoulli-output / unknown-`p` input model.

**Theorem 1.1 (Rhee–Glynn condition, PDF p.3; setup in §1.2).** Let `N` be integer-valued, independent of the sequence `(S_n)`, and able to take arbitrarily large values; with weights `w_n=1/P(N≥n)`, the sufficient summability condition `Σ_{n≥1} w_n E|S−S_{n−1}|²<∞` gives an unbiased random-sum estimator with finite second moment. The increments may be negative; therefore this does not guarantee a nonnegative unbiased estimator. Independence of `N` from `(S_n)` is an explicit hypothesis, not optional.

**Theorem 2.1 (PDF pp.7–9; proof pp.7–9).** If `X=R`, no `f`-factory exists for any nonconstant `f:R→R₊`. Choose distinct fixed means `λ_X,λ_Y` with `f(λ_X)>f(λ_Y)`, and start from an input law `μ_X` of mean `λ_X`. For each small `ε>0`, contaminate it by a rare replacement: `Y_n=B_nX_n + ((λ_Y−λ_X(1−ε))/ε)(1−B_n)`, where iid `B_n` is independent and `P(B_n=1)=1−ε`. Then `E[Y_n]=λ_Y` remains fixed, while any given finite prefix agrees with the X-prefix with probability `(1−ε)^n→1` as `ε↓0`. Coupling both runs with the same auxiliary uniform variable and using the stopping-time events, the proof bounds the nonnegative output on the common-prefix event; as the prefix length grows its expectation approaches `f(λ_X)`, contradicting the required expectation `f(λ_Y)` for ε small enough. The means are deliberately distinct, not matched; the construction changes the law by a rare, potentially large contamination while preserving the two different prescribed mean values.

**Lemma 3.1 (PDF p.10).** For one-sided support `[a,∞)`, an `f`-factory requires `f` to be increasing; for `(-∞,b]`, it requires decreasing `f`. The proof uses contamination/mixing of input laws to perturb the mean while retaining the support and contradict monotonicity if `f` moves in the opposite direction.

**Theorem 3.1 (PDF p.12; necessity proof p.13).** For `X=[a,b]` and continuous `f:[a,b]→R₊` not identically zero, an `f`-factory exists iff some `ε>0` and integer `n≥1` satisfy

`f(x) ≥ ε min((x−a)^n,(b−x)^n)`, for every `x∈[a,b]`.

For sufficiency, choose `γ≥max f` large enough that both `f` and `γ−f` have the required boundary lower bound; normalize to a Bernoulli target on `[0,1]`, simulate a Bernoulli output, and multiply it by `γ`. For necessity, condition expected output on each finite input word and the auxiliary uniform; nonnegativity expresses `f(z)` as a sum `Σ_{p,q≥0}c_{p,q}z^p(1−z)^q` with `c_{p,q}≥0`. The paper's boundary argument gives (3.2). The weaker one-sided condition is appropriate because only a nonnegative real estimator, not a {0,1}-valued output, is required.

Theorem 3.1 concerns nonnegative unbiased estimators for all input laws on a bounded support. It does not say that a Bernoulli-valued factory exists with a particular p-coin stopping-time cost, and its proof provides no `E_p[N^r]` characterization. It is retained only as an auxiliary model-boundary result for C204; transferring it requires a separate output-type, input-law, and cost interface.
