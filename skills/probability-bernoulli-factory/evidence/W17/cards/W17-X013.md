## Construction and exact conclusions

For an iid input stream of Bernoulli(`p`) bits, write `q=1−p`. The first procedure pairs successive input bits, discards equal pairs, and emits the unequal pair’s orientation. Each orientation has unconditional probability `pq`, hence conditional on an unequal pair the two orientations each have probability `1/2`, so every emitted bit is fair. The recursive definition on an even input prefix is more specific: set `u_j=x_{2j−1}⊕x_{2j}` for every pair, and let `v_j=x_{2i_j}` for those indices `i_j` where `x_{2i_j−1}=x_{2i_j}` (the bit retained from each equal pair). Then `Ψ_ν(x)=Ψ_1(x)*Ψ_{ν−1}(u)*Ψ_{ν−1}(v)`, where `*` denotes concatenation. Thus the recursion acts on the XOR/equality-indicator stream `u` and the equal-pair retained-bit stream `v`; it does not recursively treat the already emitted `Ψ_1` fair bits as an input stream. For iid biased inputs, `u_j` are iid Bernoulli(`2pq`), while each retained `v_j` has conditional success probability `p²/(p²+q²)`; the independence claim needed by the rate calculation is proved through the paper’s exchangeability lemma. Proposition 1 establishes uniform finite output strings for exchangeable input bits (including iid biased inputs), so the output stream is iid fair; the construction does not use the unknown value `p`.

**Proposition 2 (printed p.593; physical PDF p.5).** If `r_ν(p)` is the almost-sure asymptotic output-bit rate per original input bit of `Ψ_ν`, then the rates exist and

`r₁(p)=pq`,
`r_ν(p)=pq + ½ r_{ν−1}(p²+q²) + ½(p²+q²) r_{ν−1}(p²/(p²+q²))`, `ν≥2`.

The proof handles even input prefixes, writes the first-pass output count as `K(n)`, applies the strong law to `K(n)/(2n)→pq`, and invokes the induction hypothesis on the output and residual subsequences. The residual subsequence has asymptotic fraction `(p²+q²)/2`, and conditional bias `p²/(p²+q²)`, which supplies the two recursive terms. The rate is an almost-sure long-run ratio, not a bound on an individual output-bit stopping time or its moments.

**Proposition 3 (printed pp.594–595; physical pp.6–7).** For each `ν`, `r_ν(p)≤h(p)` where `h(p)=−p log₂p−q log₂q`; moreover `r_ν→h` uniformly in `p∈[0,1]`. The proof writes the recursion as an operator `T`, uses the entropy identity/bound to show the iterates increase and stay below `h`, then proves uniform convergence by compactness and a positive gap away from the endpoints. Thus the iterated procedure approaches the entropy upper bound as the number of iterations grows; it does not establish finite-depth attainment of entropy.

## Proof coverage and boundary

- JSTOR terms/title sheet, physical p.1: scan identity and use restriction.
- Introduction and first von Neumann procedure, physical pp.2–3 (printed pp.590–591): input model, pair extraction, exact recursive definition through `u_j=x_{2j−1}⊕x_{2j}` and equal-pair retained bits `v_j`, and the restriction that the output rule cannot depend on `p`.
- Proposition 1 statement, physical p.3 (printed p.591), and proof, physical p.4 (printed p.592): exchangeability/conditional-probability argument for uniform output bits; the proof uses the independence of the three recursively combined vectors, not a recursion on the already output fair bits.
- Proposition 2 and proof, physical p.5 (printed p.593): existence and recursion for almost-sure rate using the strong law and the two recursive streams.
- Entropy upper bound and Proposition 3, physical pp.6–7 (printed pp.594–595): monotone operator iteration and uniform convergence to binary entropy.
- Remarks and §5 exchangeable-process extension, physical p.8 (printed p.596): fixed-block/output cautions and de Finetti mixture application (Corollary 4).
- Closing remarks and references, physical p.9 (printed p.597): scope and bibliography.

The paper is a random-bit-extraction result. Its rate measures output bits divided by input bits over long prefixes; it supplies no per-output `r`th input-toss moment bound and no necessary-and-sufficient C204 moment criterion. Any use to implement an auxiliary fair bit inside a Bernoulli factory needs a separate cost/moment conversion.
