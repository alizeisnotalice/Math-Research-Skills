## Theorem 2.3: bounded sample-size criterion

Fix a parameter set `P ⊂ (0,1)`. A success-probability function on `P` is simulable using a fixed finite number `n` of independent `Bernoulli(p)` samples and an independent auxiliary variable with known distribution exactly when its values on `P` agree with a Bernstein polynomial of degree `n` whose Bernstein coefficients `α_j` lie in `[0,1]`:

`f(p) = Σ_{j=0}^n α_j binom(n,j) p^j(1−p)^(n−j)`, `0≤α_j≤1`.

This is a fixed, computable-in-advance input count. It is not a characterization of almost-surely finite random stopping times. The theorem is about the output-probability function on `P`; if the input domain has special structure, the extension away from `P` need not be unique.

## Proof chain

1. **Construction (Algorithm A, PDF p. 3; Proposition 2.1, pp. 3–4).** Toss `n` input coins and an independent `U~Uniform(0,1)`. If the head count is `j`, output `1{U≤α_j}`. The head-count events are disjoint, and independence gives
   `P(output=1)=Σ_j P(U≤α_j)P(Bin(n,p)=j)=Σ_j α_j binom(n,j)p^j(1−p)^(n−j)=f(p)`.
2. **Necessity (Proposition 2.2, pp. 4–5).** For any fixed-`M` procedure, condition on the input word `x∈{0,1}^M`. The auxiliary variable falls in a measurable acceptance set `T(x)` with probability `q_x∈[0,1]`. Group strings by their head count `j`. There are `binom(M,j)` such strings, so their average acceptance probability `α_j=binom(M,j)^{-1}Σ_{x:|x|=j}q_x` lies in `[0,1]`. Summing over input words yields the degree-`M` Bernstein representation. This proof uses only independence of the auxiliary randomness from the input coins and does not require that it be uniform.

## Use and boundary

For A202 this is an auxiliary operational view of the fixed-depth Bernstein-coefficient test. It does not give the maximum `N(m)` for integer-coefficient probability polynomials; Wästlund’s unnormalized integer coefficient criterion is the direct source for that target. For C204, this paper is useful as a contrast between bounded-depth simulation and random stopping. It provides no random stopping-time tail or moment conclusion.
