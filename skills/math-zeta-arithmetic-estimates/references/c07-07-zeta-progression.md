# Vertical arithmetic progression zeta moments

## Verified publication and local source

Li--Radziwiłł, *The Riemann-zeta function on vertical arithmetic progressions*, is published in *International Mathematics Research Notices* 2015(2), 325--354, DOI `10.1093/imrn/rnt197`.  The local file is arXiv:1208.2684v1, SHA-256 `9205544cbe9377fa6d820caa2b16293f82e49071bdeed752e2a8967b26a80b52`, 22 physical pages.  The cited model is on local pp. 1--4; it was checked against the published article's verified bibliographic record, not re-proved here.

For a smooth compactly supported weight \(\phi\subset[1,2]\), \(\alpha>0\), \(\beta\in\mathbb R\), and the source's admissible Dirichlet-polynomial twist \(B\), record separately the discrete and continuous second moments.  The source states, in particular,
\[
 \sum_\ell |\zeta(\tfrac12+i(\alpha\ell+\beta))|^2\phi(\ell/T)
 =\left(1+\delta(\alpha,\beta)+o(1)\right)
 \int |\zeta(\tfrac12+i(\alpha t+\beta))|^2\phi(t/T)\,dt,
\]
where its \(\delta(\alpha,\beta)\) is determined by whether a number \(e^{2\pi\ell/\alpha}\) has the stated rational representation.  Its reusable operation is a *comparison ledger*: retain the sampling lattice, twist length, smoothing, and the Diophantine branch defining \(\delta\).  It does not give a gamma linear form, nor does a finite sample certify the asymptotic or zero-density consequences.
